# `break`, `continue`, and `pass` Statements

## 1. Overview
In Python, `break` and `continue` are **loop control statements** used to alter the normal sequential flow of `for` and `while` loops, while `pass` is a **null statement** used as a syntactic placeholder when no action is required.

---

## 2. The `break` Statement
The `break` statement **immediately terminates** the nearest enclosing loop (`for` or `while`). Program execution jumps directly to the first statement following the loop body.

* **Common Use Case:** Stopping a search as soon as the target item is found, avoiding unnecessary iterations.

### Example
```python
numbers = [10, 25, 30, 45, 50]
target = 30

for num in numbers:
    if num == target:
        print(f"Target {target} found. Stopping search.")
        break
    print(f"Checking: {num}")

print("Loop exited.")
# Output:
# Checking: 10
# Checking: 25
# Target 30 found. Stopping search.
# Loop exited.
```

---

## 3. The `continue` Statement
The `continue` statement **skips the remaining statements** in the current iteration and jumps immediately to the next iteration of the loop.

* In a `for` loop, execution advances to the next item in the iterable.
* In a `while` loop, execution jumps straight back to re-evaluating the loop condition.

### Example (`for` Loop)
```python
scores = [85, -1, 92, -1, 78]  # -1 represents an invalid/absent entry

for score in scores:
    if score < 0:
        continue  # Skip invalid entries
    print(f"Valid score: {score}")

# Output:
# Valid score: 85
# Valid score: 92
# Valid score: 78
```

### Important Caution with `while` Loops
When using `continue` inside a `while` loop, ensure the loop control variable is updated **before** the `continue` statement executes; otherwise, the condition will never change and will cause an infinite loop:
```python
count = 0

while count < 5:
    count += 1        # Increment before 'continue'
    if count == 3:
        continue      # Skips printing 3
    print(count)
```

---

## 4. The `pass` Statement
The `pass` statement is a **no-operation (null) statement**. When executed, nothing happens. Because Python relies on indentation rather than curly braces `{}` to define code blocks, empty blocks raise an `IndentationError`. `pass` satisfies this syntactic requirement.

* **Common Use Cases:** Acting as a placeholder for unimplemented functions, classes, conditional branches, or exception handlers during development.

### Example
```python
# 1. Placeholder inside a conditional block
status = "pending"
if status == "pending":
    pass  # To be implemented later
else:
    print("Request processed.")

# 2. Placeholder for an empty function or class
def calculate_bonus():
    pass

class TraineeProfile:
    pass
```

---

## 5. Behavior in Nested Loops
Both `break` and `continue` affect **only the innermost loop** in which they appear. Outer loops continue running normally.

```python
for outer in range(1, 3):
    for inner in range(1, 5):
        if inner == 3:
            break  # Exits ONLY the inner loop
        print(f"Outer: {outer}, Inner: {inner}")
```

---

## 6. Comparison Summary

| Feature | `break` | `continue` | `pass` |
| :--- | :--- | :--- | :--- |
| **Primary Purpose** | Exit the loop completely | Skip the rest of the current iteration | Do nothing (syntactic placeholder) |
| **Effect on Loop** | Terminates the enclosing loop immediately | Advances to the next iteration | No effect on loop execution |
| **Remaining Code in Iteration** | Not executed | Not executed | Executed normally |
| **Where Allowed** | Inside `for` and `while` loops only | Inside `for` and `while` loops only | Anywhere a statement is valid (`if`, `def`, `class`, loops) |
