# String Methods

## 1. Overview
Python provides a rich set of built-in **string methods** for inspecting, searching, formatting, and transforming text.

* **Immutability Rule:** Because Python strings are **immutable**, string methods **never modify the original string in place**. Instead, they always return a **new** string (or a non-string result such as an `int`, `bool`, or `list`).

```python
text = "python"
upper_text = text.upper()

print(text)        # 'python' (original remains unchanged)
print(upper_text)  # 'PYTHON' (new string returned)
```

---

## 2. Case Conversion Methods
Used to standardize or alter character casing:

```python
s = "hello world, PYTHON"

print(s.lower())       # 'hello world, python' (all lowercase)
print(s.upper())       # 'HELLO WORLD, PYTHON' (all uppercase)
print(s.title())       # 'Hello World, Python' (capitalizes first letter of each word)
print(s.capitalize())  # 'Hello world, python' (capitalizes only the first character)
print(s.swapcase())    # 'HELLO WORLD, python' (inverts uppercase and lowercase)
```

---

## 3. Trimming and Prefix/Suffix Removal
Used to clean leading and trailing whitespace or specific characters:

```python
raw = "   Revature FDE   "

print(raw.strip())     # 'Revature FDE'    (removes leading and trailing whitespace)
print(raw.lstrip())    # 'Revature FDE   ' (removes leading whitespace only)
print(raw.rstrip())    # '   Revature FDE' (removes trailing whitespace only)

# Passing specific characters removes any combination of those characters from both ends
code = "###2026###"
print(code.strip("#")) # '2026'

# Removing exact prefixes or suffixes (Python 3.9+)
filename = "report_final.md"
print(filename.removeprefix("report_"))  # 'final.md'
print(filename.removesuffix(".md"))      # 'report_final'
```

## 4. Searching, Counting, and Boundary Checks
Used to locate substrings, count occurrences, or verify how a string begins or ends:

```python
sentence = "Python is easy and Python is powerful"

# 1. Counting occurrences
print(sentence.count("Python"))      # 2

# 2. Finding substring index
print(sentence.find("easy"))         # 10 (lowest index where substring starts)
print(sentence.find("Java"))         # -1 (returns -1 if not found)
print(sentence.rfind("Python"))      # 19 (highest/last index where substring starts)

# .index() works like .find(), except it raises ValueError when not found
# sentence.index("Java")             # Raises ValueError: substring not found

# 3. Prefix and suffix checks (returns bool)
file = "notes.md"
print(file.startswith("notes"))      # True
print(file.endswith(".md"))          # True
```

## 5. Replacing, Splitting, and Joining

### Replacing Substrings: `.replace()`
```python
msg = "Java is fun. Java is fast."

print(msg.replace("Java", "Python"))     # 'Python is fun. Python is fast.'
print(msg.replace("Java", "Python", 1))  # 'Python is fun. Java is fast.' (replaces first 1 only)
```

### Splitting into a List: `.split()` and `.splitlines()`
```python
# Default split (splits on any whitespace and discards empty strings)
words = "Python   SQL   Git".split()
print(words)  # ['Python', 'SQL', 'Git']

# Splitting by a specific delimiter
csv_line = "Vivek,23,FDE"
print(csv_line.split(","))  # ['Vivek', '23', 'FDE']

# Splitting by line breaks
lines = "Line 1\nLine 2\nLine 3".splitlines()
print(lines)  # ['Line 1', 'Line 2', 'Line 3']
```

### Joining an Iterable into a String: `.join()`
Called on the **separator string**, taking an iterable of strings as its argument:
```python
modules = ["Python", "SQL", "Git"]

print(", ".join(modules))  # 'Python, SQL, Git'
print("-".join(modules))   # 'Python-SQL-Git'
```
*(Note: All elements in the iterable passed to `.join()` must be strings; otherwise, Python raises a `TypeError`.)*

## 6. Validation Methods (`is*`)
Return `True` if all characters in a non-empty string satisfy the condition, and `False` otherwise:

| Method | Condition Checked | Example | Output |
| :--- | :--- | :--- | :--- |
| `.isalpha()` | Only alphabetic letters (`a-z`, `A-Z`) | `"Python".isalpha()` | `True` |
| `.isdigit()` | Only digits (`0-9`) | `"2026".isdigit()` | `True` |
| `.isalnum()` | Only letters and/or digits (no spaces/symbols) | `"FDE2026".isalnum()` | `True` |
| `.isspace()` | Only whitespace characters (`" "`, `\t`, `\n`) | `"   \t".isspace()` | `True` |
| `.islower()` | All cased characters are lowercase | `"python 3".islower()` | `True` |
| `.isupper()` | All cased characters are uppercase | `"FDE 2026".isupper()` | `True` |

---

## 7. Quick Reference

| Method | Purpose | Return Type |
| :--- | :--- | :--- |
| `s.lower()` / `s.upper()` | Converts characters to lowercase / uppercase | `str` |
| `s.strip()` | Removes leading and trailing whitespace | `str` |
| `s.replace(old, new)` | Replaces occurrences of `old` with `new` | `str` |
| `s.split(sep)` | Splits string into a list of substrings using `sep` | `list[str]` |
| `sep.join(iterable)` | Concatenates elements of `iterable` separated by `sep` | `str` |
| `s.find(sub)` | Returns starting index of `sub`, or `-1` if absent | `int` |
| `s.count(sub)` | Counts non-overlapping occurrences of `sub` | `int` |
| `s.startswith(prefix)` / `s.endswith(suffix)` | Checks if string starts or ends with given text | `bool` |
