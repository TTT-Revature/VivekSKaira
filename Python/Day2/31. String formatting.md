# String Formatting

## 1. Overview
**String formatting** is the process of dynamically inserting variables, expressions, and formatted values into a string template. Instead of manually converting types with `str()` and joining pieces using `+`, Python provides four built-in formatting mechanisms:
1. **f-Strings (Formatted String Literals)** — Recommended modern standard (Python 3.6+)
2. **`str.format()` Method** — Flexible placeholder formatting (Python 3.0+)
3. **`%` Operator (Printf-Style)** — Legacy formatting found in older codebases
4. **`string.Template`** — Simplified `$`-based substitution for user-supplied templates

---

## 2. f-Strings (Formatted String Literals)
Prefixing a string with `f` or `F` lets you embed variables and valid Python expressions directly inside curly braces `{}`. f-Strings are the fastest and most readable formatting method in modern Python.

```python
name = "Vivek"
module = "Python"
score = 92.456

# Embedding variables, expressions, and format specifiers
print(f"Trainee: {name} | Module: {module.upper()} | Score: {score:.1f}%")
# Output: Trainee: VIVEK | Module: PYTHON | Score: 92.5%

# Inline arithmetic and debugging (=)
a, b = 15, 25
print(f"{a + b = }")
# Output: a + b = 40
```

---

## 3. The `str.format()` Method
Calls `.format()` on a string containing `{}` placeholders. This is particularly useful when the template string is stored in a variable or configuration file before the values are available.

### Positional, Indexed, and Keyword Placeholders
```python
# 1. Default positional order
print("Role: {}, Track: {}".format("Junior Trainer", "FDE"))

# 2. Explicit positional indices (allows reordering or reusing values)
print("{1} comes before {0}, and {1} is foundational.".format("SQL", "Python"))

# 3. Keyword placeholders
template = "Batch {year}: {count} trainees enrolled."
print(template.format(year=2026, count=45))
```

### Unpacking Collections into `.format()`
```python
data = ["Vivek", "GitHub"]
print("{} uploaded notes to {}.".format(*data))

info = {"user": "Vivek", "status": "Active"}
print("User: {user} ({status})".format(**info))
```

---

## 4. Old-Style Formatting (`%` Operator)
Inspired by C's `printf()`, this legacy approach uses `%` format specifiers inside the string followed by `%` and a single value or tuple of values.

### Common Type Specifiers
* `%s` — String (or any object converted via `str()`)
* `%d` — Signed integer
* `%f` — Floating-point number (`%.2f` for 2 decimal places)

```python
name = "Vivek"
week = 2
accuracy = 88.756

print("Trainee: %s | Week: %d | Accuracy: %.2f%%" % (name, week, accuracy))
# Output: Trainee: Vivek | Week: 2 | Accuracy: 88.76%
```

---

## 5. Template Strings (`string.Template`)
Provided by Python's standard `string` module, `Template` uses `$identifier` or `${identifier}` placeholders. Because it does not evaluate arbitrary Python expressions, it is safer when formatting untrusted or user-provided template strings.

```python
from string import Template

tmpl = Template("Hello $name, your $course task is ${status}d.")
result = tmpl.substitute(name="Vivek", course="Python", status="complete")
print(result)
# Output: Hello Vivek, your Python task is completed.
```
*(Tip: Use `.safe_substitute()` instead of `.substitute()` to leave missing placeholders unchanged rather than raising a `KeyError`.)*

## 6. Common Format Specifiers (`f-strings` & `str.format()`)
Both f-strings and `str.format()` share the same format specification mini-language after a colon (`:`):

| Specifier | Purpose | f-String Example | `str.format()` Example | Output |
| :--- | :--- | :--- | :--- | :--- |
| `:.2f` | Round float to 2 decimal places | `f"{3.14159:.2f}"` | `"{:.2f}".format(3.14159)` | `'3.14'` |
| `:,` | Comma thousands separator | `f"{1000000:,}"` | `"{:,}".format(1000000)` | `'1,000,000'` |
| `:.1%` | Format decimal as percentage | `f"{0.845:.1%}"` | `"{:.1%}".format(0.845)` | `'84.5%'` |
| `:04d` | Zero-pad integer to width 4 | `f"{7:04d}"` | `"{:04d}".format(7)` | `'0007'` |
| `:<8` | Left-align in width 8 | `f"{'Hi':<8}"` | `"{:<8}".format("Hi")` | `'Hi      '` |
| `:>8` | Right-align in width 8 | `f"{'Hi':>8}"` | `"{:>8}".format("Hi")` | `'      Hi'` |
| `:^8` | Center-align in width 8 | `f"{'Hi':^8}"` | `"{:^8}".format("Hi")` | `'   Hi   '` |

---

## 7. Comparison Summary

| Method | Syntax | Python Version | Best Use Case |
| :--- | :--- | :--- | :--- |
| **f-Strings** | `f"Hello {name}"` | 3.6+ | Default choice for inline formatting, expressions, and readability |
| **`str.format()`** | `"Hello {}".format(name)` | 3.0+ | Reusable string templates defined separately from data |
| **`%` Formatting** | `"Hello %s" % name` | All versions | Maintaining or reading legacy Python 2 / early Python 3 code |
| **`string.Template`** | `Template("Hello $name")` | 2.4+ | Safely formatting user-supplied or external text templates |
