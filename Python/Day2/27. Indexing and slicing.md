# Indexing and Slicing

## 1. Overview
**Indexing** and **slicing** are core Python operations used to access or extract elements from **ordered sequences**—such as `str`, `list`, `tuple`, `range`, and `bytes`.

* **Indexing:** Retrieves a single element at a specific position.
* **Slicing:** Extracts a sub-sequence (a portion of elements) using a range of indices.
* **Unsupported Types:** Unordered collections such as `set` and `dict` do not support positional indexing or slicing (raising a `TypeError`).

---

## 2. Indexing
Python uses **zero-based indexing**, meaning the first element is always at position `0`. Python also supports **negative indexing**, which counts backward from the end of the sequence starting at `-1`.

```text
Sequence:   [ 'P',  'Y',  'T',  'H',  'O',  'N' ]
Positive:      0     1     2     3     4     5
Negative:     -6    -5    -4    -3    -2    -1
```

### Accessing Elements by Index
```python
items = ["Python", "SQL", "Git", "Docker", "AWS"]

print(items[0])    # 'Python' (first element)
print(items[2])    # 'Git'    (third element)
print(items[-1])   # 'AWS'    (last element)
print(items[-2])   # 'Docker' (second-to-last element)
```

### Modifying Elements via Index (Mutability)
* **Mutable sequences (`list`):** Support item assignment at a valid index.
* **Immutable sequences (`str`, `tuple`):** Raise a `TypeError` if you attempt to modify an element by index.

```python
scores = [70, 80, 90]
scores[1] = 85
print(scores)  # [70, 85, 90]

coords = (10, 20)
# coords[0] = 99  # Raises TypeError: 'tuple' object does not support item assignment
```

### `IndexError`
Requesting an index outside the valid range (`-len(seq)` to `len(seq) - 1`) raises an `IndexError: list index out of range`.

---

## 3. Slicing
Slicing extracts a subset of elements and returns a **new object of the same sequence type** without altering the original sequence.

### Syntax
```python
sequence[start:stop:step]
```
* **`start` (inclusive):** Index where the slice begins. Defaults to `0` (when `step > 0`).
* **`stop` (exclusive):** Index where the slice ends; the element at `stop` is **not** included. Defaults to `len(sequence)` (when `step > 0`).
* **`step` (optional):** Interval between elements. Defaults to `1`.

### Common Slicing Patterns
```python
nums = [10, 20, 30, 40, 50, 60, 70]

print(nums[1:4])     # [20, 30, 40]        (indices 1, 2, 3)
print(nums[:3])      # [10, 20, 30]        (from start up to index 2)
print(nums[4:])      # [50, 60, 70]        (from index 4 to the end)
print(nums[-3:])     # [50, 60, 70]        (last 3 elements)
print(nums[:-2])     # [10, 20, 30, 40, 50] (all except last 2 elements)
print(nums[::2])     # [10, 30, 50, 70]    (every 2nd element)
print(nums[:])       # [10, 20, 30, 40, 50, 60, 70] (shallow copy of the list)
```

### Negative Step (Reverse Slicing)
When `step` is negative, Python traverses the sequence **from right to left**:
* `start` defaults to the end of the sequence (`-1`).
* `stop` defaults to before the beginning of the sequence.

```python
word = "REVERSE"

print(word[::-1])      # 'ESREVER' (reverses the entire sequence)
print(word[5:1:-1])    # 'SREV'    (from index 5 down to index 2)
print(word[::-2])      # 'ERER'    (every 2nd character in reverse)
```

## 4. Key Slicing Behaviors

### 1. Out-of-Range Slicing Never Raises `IndexError`
Unlike single-element indexing, slicing gracefully clamps out-of-bounds indices to the valid start or end of the sequence:
```python
data = [1, 2, 3]

print(data[0:100])   # [1, 2, 3]
print(data)   # [] (returns an empty sequence)
```

### 2. Slice Assignment (Mutable Sequences Only)
Lists allow replacing, inserting, or deleting multiple elements at once by assigning an iterable to a slice:
```python
letters = ["a", "b", "c", "d", "e"]

# Replace a slice with different-length content
letters[1:3] = ["X", "Y", "Z"]
print(letters)  # ['a', 'X', 'Y', 'Z', 'd', 'e']

# Delete a slice
letters[1:4] = []
print(letters)  # ['a', 'd', 'e']
```

### 3. Named Slice Objects (`slice()`)
The built-in `slice(start, stop, step)` function creates a reusable slice object that can be applied across multiple sequences:
```python
first_three = slice(0, 3)

print("Python"[first_three])        # 'Pyt'
print([10, 20, 30, 40][first_three]) # [10, 20, 30]
```

---

## 5. Quick Reference

| Syntax | Meaning | Example (`s = [0, 1, 2, 3, 4]`) | Result |
| :--- | :--- | :--- | :--- |
| `s[i]` | Element at positive index `i` | `s[1]` | `1` |
| `s[-i]` | Element at `i`-th position from the end | `s[-1]` | `4` |
| `s[a:b]` | Elements from `a` up to `b - 1` | `s[1:4]` | `[1, 2, 3]` |
| `s[:b]` | First `b` elements | `s[:3]` | `[0, 1, 2]` |
| `s[a:]` | Elements from index `a` to the end | `s[2:]` | `[2, 3, 4]` |
| `s[-n:]` | Last `n` elements | `s[-2:]` | `[3, 4]` |
| `s[::k]` | Every `k`-th element | `s[::2]` | `[0, 2, 4]` |
| `s[::-1]` | Reversed copy of the sequence | `s[::-1]` | `[4, 3, 2, 1, 0]` |
