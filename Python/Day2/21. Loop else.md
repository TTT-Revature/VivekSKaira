# Loop `else` Clause

## 1. Overview
In Python, both `for` and `while` loops can have an optional `else` block attached to them. Unlike an `if-else` statement, the `else` block on a loop executes **only when the loop finishes its execution normally**—meaning it was **not** terminated early by a `break` statement.

* **Mental Model:** Think of a loop's `else` clause as **`no_break`**—it runs if and only if no `break` was encountered during iteration.
* **Primary Use Case:** Searching for an item or validating a condition across a sequence without needing a separate boolean flag variable (such as `found = False`).

---

## 2. `for-else` Loop
The `else` block runs once the `for` loop has exhausted all items in the iterable without hitting a `break`.

### Syntax
```python
for item in iterable:
    if condition:
        break
else:
    # Executes only if the loop did NOT encounter 'break'
    pass
```

### Example: Searching for a Target Value
```python
trainees = ["Amit", "Priya", "Vivek", "Sneha"]
search_name = "Rahul"

for name in trainees:
    if name == search_name:
        print(f"{search_name} found in the batch list.")
        break
else:
    print(f"{search_name} was not found in the batch list.")

# Output: Rahul was not found in the batch list.
```

---

## 3. `while-else` Loop
The `else` block runs when the `while` loop's condition naturally evaluates to `False`, provided the loop was not exited prematurely via `break`.

### Syntax
```python
while condition:
    if stop_condition:
        break
else:
    # Executes only when 'condition' becomes False without a 'break'
    pass
```

### Example: Limited Login Attempts
```python
attempts = 0
max_attempts = 3
correct_pin = "4321"

while attempts < max_attempts:
    entered_pin = "0000"  # Simulated user input
    attempts += 1
    if entered_pin == correct_pin:
        print("Access granted.")
        break
else:
    print("Account locked: Maximum attempts exceeded.")

# Output: Account locked: Maximum attempts exceeded.
```

---

## 4. Edge Cases and Execution Rules

1. **Empty Iterable in `for-else`:**
   If the sequence is empty, the loop body runs zero times, no `break` occurs, and the `else` block **executes**.
   ```python
   for item in []:
       print(item)
   else:
       print("Loop finished without break.")  # Executes
   ```

2. **Initially `False` Condition in `while-else`:**
   If the `while` condition is `False` from the start, no `break` occurs, and the `else` block **executes**.
   ```python
   while False:
       print("Inside loop")
   else:
       print("Condition was False; else executed.")  # Executes
   ```

3. **Effect of `continue`:**
   Using `continue` skips the current iteration, not the entire loop. As long as the loop finishes normally afterward, the `else` block **executes**.

4. **Effect of `return` or Exceptions:**
   If a loop exits via a `return` statement or an unhandled exception, the `else` block is **skipped**.

---

## 5. Quick Reference

| Loop Exit Scenario | Does `else` Execute? | Reason |
| :--- | :--- | :--- |
| `for` loop exhausts all items normally | **Yes** | Completed without `break` |
| `while` condition becomes `False` | **Yes** | Completed without `break` |
| Loop receives an empty iterable / starts `False` | **Yes** | Zero iterations, no `break` encountered |
| Loop uses `continue` and finishes normally | **Yes** | `continue` does not abort the loop |
| Loop exits via `break` | **No** | Terminated prematurely |
| Loop exits via `return` or raised exception | **No** | Execution leaves the loop block immediately |
