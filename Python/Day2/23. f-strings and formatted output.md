# f-Strings and Formatted Output

## 1. Overview
**f-Strings** (formatted string literals), introduced in Python 3.6, provide a concise, readable, and fast way to embed Python expressions directly inside string literals.

* **Syntax:** Prefix a string with `f` or `F` (e.g., `f"..."`, `f'...'`, `f"""..."""`) and place variables or expressions inside curly braces `{}`.
* **Runtime Evaluation:** Expressions inside `{}` are evaluated at runtime and automatically converted to strings using their `__format__()` method.

---

## 2. Basic f-String Usage

### Embedding Variables and Expressions
You can place variable names, arithmetic expressions, and method or function calls directly inside `{}`:

```python
name = "Vivek"
score = 42
max_score = 50

print(f"Trainee: {name.upper()}")
print(f"Score: {score}/{max_score} ({score + 8} after bonus)")
# Output:
# Trainee: VIVEK
# Score: 42/50 (50 after bonus)
```

### Multi-Line f-Strings
Use triple quotes (`f"""..."""`) or implicit string concatenation across lines for longer formatted blocks:

```python
role = "Junior Trainer"
track = "FDE"

summary = (
    f"Role: {role}\n"
    f"Track: {track}"
)
print(summary)
```

---

## 3. Format Specifiers
Format specifiers control how a value is displayed (precision, padding, alignment, number base). They follow a colon (`:`) inside the curly braces:

```python
f"{value:format_spec}"
```

### A. Decimal Precision and Percentages
```python
pi = 3.14159265
accuracy = 0.8745

print(f"Pi (2 decimals): {pi:.2f}")       # Pi (2 decimals): 3.14
print(f"Accuracy: {accuracy:.1%}")        # Accuracy: 87.5%
```

### B. Thousands Separators
Use `,` or `_` to format large numbers cleanly:
```python
budget = 1500000

print(f"Budget: {budget:,}")              # Budget: 1,500,000
print(f"Budget (2 decimals): {budget:,.2f}")  # Budget (2 decimals): 1,500,000.00
print(f"Underscore format: {budget:_}")   # Underscore format: 1_500_000
```

### C. Alignment and Width Padding
Specify a minimum field width along with an alignment symbol (`<` left, `>` right, `^` center) and an optional fill character:

```python
label = "Python"

print(f"|{label:<10}|")    # |Python    | (Left-aligned, width 10)
print(f"|{label:>10}|")    # |    Python| (Right-aligned, width 10)
print(f"|{label:^10}|")    # |  Python  | (Centered, width 10)
print(f"|{label:*^10}|")   # |**Python**| (Centered with '*' fill)
```

### D. Number Base Conversions
Format integers into binary (`b`), octal (`o`), or hexadecimal (`x` / `X`):
```python
num = 255

print(f"Binary: {num:b}")       # Binary: 11111111
print(f"Octal: {num:o}")        # Octal: 377
print(f"Hex (lower): {num:x}")  # Hex (lower): ff
print(f"Hex (upper): {num:X}")  # Hex (upper): FF
```

---

## 4. Helpful f-String Features

### Debugging Expressions (`=`)
Adding `=` after an expression (Python 3.8+) prints both the expression text and its evaluated result—useful for quick debugging:
```python
a = 12
b = 8
print(f"{a = }, {b = }, {a + b = }")
# Output: a = 12, b = 8, a + b = 20
```

### Escaping Curly Braces
To display literal curly braces inside an f-string, double them (`{{` and `}}`):
```python
item = "status"
print(f"JSON format: {{'{item}': 'ok'}}")
# Output: JSON format: {'status': 'ok'}
```

---

## 5. Alternative Formatting Methods
While f-strings are the standard approach in modern Python, two older formatting styles still appear in legacy codebases:

1. **`str.format()` Method:**
   ```python
   print("Module: {}, Week: {}".format("Python", 1))
   print("Module: {m}, Week: {w}".format(m="Python", w=1))
   ```

2. **`%` Formatting (Printf-Style):**
   ```python
   print("Name: %s, Score: %.1f" % ("Vivek", 94.5))
   ```

---

## 6. Quick Reference

| Format Specifier | Purpose | Example (`val = 42.567`) | Output |
| :--- | :--- | :--- | :--- |
| `:.2f` | Fixed-point float with 2 decimal places | `f"{val:.2f}"` | `'42.57'` |
| `:.1%` | Multiplies by 100 and adds `%` | `f"{0.856:.1%}"` | `'85.6%'` |
| `:,` | Adds comma thousands separators | `f"{12500:,}"` | `'12,500'` |
| `:05d` | Zero-pads an integer to width 5 | `f"{42:05d}"` | `'00042'` |
| `:<8` | Left-aligns within an 8-character field | `f"{'Hi':<8}"` | `'Hi      '` |
| `:>8` | Right-aligns within an 8-character field | `f"{'Hi':>8}"` | `'      Hi'` |
| `:^8` | Center-aligns within an 8-character field | `f"{'Hi':^8}"` | `'   Hi   '` |
| `{x=}` | Prints both variable/expression and value | `f"{val=}"` | `'val=42.567'` |
