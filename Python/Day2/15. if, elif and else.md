# `if`, `elif`, and `else` Statements

## 1. Overview
Conditional statements allow a program to make decisions and execute different blocks of code depending on whether specified conditions evaluate to `True` or `False`.

* Python uses **colons (`:`)** at the end of condition headers and **indentation (4 spaces)** to define the code block belonging to each branch.
* Conditions do not require surrounding parentheses `()` unless used for grouping complex expressions.

---

## 2. The `if` Statement
Executes a block of code only when the given condition evaluates to `True`. If the condition is `False`, the block is skipped entirely.

```python
score = 85

if score >= 75:
    print("Passed with distinction.")
```

---

## 3. The `if-else` Statement
Provides an alternative block of code to execute when the `if` condition evaluates to `False`. Exactly one of the two branches will run.

```python
attendance = 68

if attendance >= 75:
    print("Eligible for final assessment.")
else:
    print("Not eligible due to low attendance.")
```

---

## 4. The `if-elif-else` Chain
Used when checking multiple mutually exclusive conditions in sequence. `elif` (short for *else if*) checks a new condition only if all preceding conditions were `False`.

* Python evaluates conditions **from top to bottom** and executes **only the first branch** whose condition is `True`, skipping the rest of the chain.
* The trailing `else` block is optional and acts as a fallback default if none of the conditions match.

```python
marks = 82

if marks >= 90:
    grade = "A+"
elif marks >= 80:
    grade = "A"
elif marks >= 70:
    grade = "B"
elif marks >= 60:
    grade = "C"
else:
    grade = "F"

print(f"Assigned Grade: {grade}")  # Assigned Grade: A
```

---

## 5. Nested Conditionals
An `if`, `elif`, or `else` statement can be placed inside another conditional block to check secondary requirements after an initial condition is met.

```python
has_account = True
is_verified = False

if has_account:
    if is_verified:
        print("Access granted to dashboard.")
    else:
        print("Please verify your email address.")
else:
    print("Please register an account first.")
```

*(Best Practice: Avoid nesting more than 2–3 levels deep. Combine conditions using logical operators like `and` / `or` when appropriate to keep code flat and readable.)*

---

## 6. Conditional Expression (Ternary Operator)
For simple single-line assignments or expressions, Python supports an inline conditional syntax:

```python
# Syntax: <value_if_true> if <condition> else <value_if_false>
score = 78
status = "Pass" if score >= 60 else "Fail"
print(status)  # Pass
```

---

## 7. Truthiness in Conditional Statements
Python automatically evaluates non-boolean expressions in `if` and `elif` headers using their truthiness:

* **Falsy values (treated as `False`):** `False`, `None`, `0`, `0.0`, `""`, `[]`, `()`, `{}`, `set()`
* **Truthy values (treated as `True`):** Any non-zero number or non-empty string/collection

```python
pending_tasks = []

# Preferred Pythonic check instead of: if len(pending_tasks) == 0:
if not pending_tasks:
    print("All tasks completed.")
```
