# Creating and Working with Strings

## 1. Overview
In Python, a **string (`str`)** is an ordered, **immutable** sequence of Unicode characters used to store and represent text data.

* **Zero-Based Indexing:** Every character in a string has a fixed position starting from `0`.
* **Immutable:** Once created, individual characters inside a string cannot be changed in place; any modification produces a brand-new string object.

---

## 2. Creating Strings
Python provides multiple ways to define string literals depending on your text formatting needs:

### Single and Double Quotes
Both `'...'` and `"..."` create identical string objects. Use one style to enclose the other without needing escape characters:
```python
single = 'Hello, Python'
double = "Welcome to Revature"

# Embedding quotes cleanly
quote_1 = "It's a great day to code."
quote_2 = 'He said, "Python is readable."'
```

### Triple Quotes (Multi-Line Strings)
Enclosing text in triple single (`'''...'''`) or triple double (`"""..."""`) quotes preserves line breaks and whitespace across multiple lines:
```python
message = """Line 1: Setup environment
Line 2: Write Python script
Line 3: Push to GitHub"""
```

### Raw Strings (`r"..."`)
Prefixing a string with `r` or `R` treats backslashes (`\`) as literal characters rather than escape sequences. This is particularly useful for Windows file paths and regular expressions:
```python
path = r"C:\Users\Vivek\Documents\notes.md"
print(path)  # Output: C:\Users\Vivek\Documents\notes.md
```

### Empty Strings and `str()` Constructor
```python
empty = ""
converted = str(2026)  # Converts non-string objects to '2026'
```

---

## 3. Escape Characters
An **escape character** begins with a backslash (`\`) and represents special non-printable characters or characters that would otherwise conflict with string syntax:

| Sequence | Meaning | Example | Output |
| :--- | :--- | :--- | :--- |
| `\n` | Newline | `"Hello\nWorld"` | Prints on two lines |
| `\t` | Horizontal tab | `"Col1\tCol2"` | `Col1    Col2` |
| `\\` | Literal backslash | `"C:\\Data"` | `C:\Data` |
| `\'` | Single quote | `'It\'s valid'` | `It's valid` |
| `\"` | Double quote | `"Say \"Hi\""` | `Say "Hi"` |

## 4. Indexing and Slicing
Because strings are ordered sequences, individual characters and substrings can be accessed using square brackets `[]`.

```text
Character:   P   Y   T   H   O   N
Positive:    0   1   2   3   4   5
Negative:   -6  -5  -4  -3  -2  -1
```

### Indexing (Single Character)
* **Positive indexing** starts at `0` from the left.
* **Negative indexing** starts at `-1` from the right.
* Accessing an index outside the string's bounds raises an `IndexError`.

```python
word = "PYTHON"

print(word[0])   # 'P' (first character)
print(word[3])   # 'H'
print(word[-1])  # 'N' (last character)
print(word[-2])  # 'O'
```

### Slicing (Substrings)
Slicing extracts a substring using the syntax `string[start:stop:step]`, where `start` is inclusive and `stop` is **exclusive**:

```python
text = "Programming"

print(text[0:7])     # 'Program'   (indices 0 through 6)
print(text[:7])      # 'Program'   (omitting start defaults to 0)
print(text[7:])      # 'ming'      (omitting stop goes to the end)
print(text[-4:])     # 'ming'      (last 4 characters)
print(text[::2])     # 'Pormig'    (every 2nd character)
print(text[::-1])    # 'gnimmargorP' (reverses the string)
```

---

## 5. String Immutability
Attempting to reassign a character at a specific index raises a `TypeError`. To "modify" a string, construct a new one using slicing or concatenation:

```python
greeting = "Jello"

# greeting[0] = "H"  # Raises TypeError: 'str' object does not support item assignment

# Correct approach: create a new string
greeting = "H" + greeting[1:]
print(greeting)  # 'Hello'
```

## 6. Basic String Operations

### Concatenation (`+`) and Repetition (`*`)
```python
first = "Junior"
second = "Trainer"

full_title = first + " " + second  # 'Junior Trainer'
divider = "-" * 10                 # '----------'
```
*(Note: You cannot concatenate a `str` and an `int` directly with `+`; convert numbers using `str()` or use f-strings.)*

### Length (`len()`) and Membership (`in`, `not in`)
```python
topic = "Python Strings"

print(len(topic))               # 14 (counts all characters including spaces)
print("Python" in topic)        # True (case-sensitive check)
print("Java" not in topic)      # True
```

### Iterating Through a String
```python
for char in "FDE":
    print(char, end=" ")  # Output: F D E
```

---

## 7. Quick Reference

| Operation / Syntax | Description | Example (`s = "Revature"`) | Result |
| :--- | :--- | :--- | :--- |
| `len(s)` | Returns total number of characters | `len(s)` | `8` |
| `s[i]` | Accesses character at index `i` | `s[0]`, `s[-1]` | `'R'`, `'e'` |
| `s[a:b]` | Extracts substring from `a` up to `b - 1` | `s[0:4]` | `'Reva'` |
| `s[::-1]` | Returns a reversed copy of the string | `s[::-1]` | `'erutaveR'` |
| `s1 + s2` | Joins two strings together | `"Hi " + s` | `'Hi Revature'` |
| `s * n` | Repeats the string `n` times | `"Go! " * 2` | `'Go! Go! '` |
| `sub in s` | Checks if `sub` exists inside `s` | `"vat" in s` | `True` |
