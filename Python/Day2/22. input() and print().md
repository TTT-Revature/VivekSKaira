# `input()` and `print()`

## 1. Overview
Python provides two built-in functions for basic console interaction (standard I/O):
* **`input()`:** Pauses program execution to read text entered by the user from the keyboard (standard input).
* **`print()`:** Displays text, variables, and expression results to the console screen (standard output).

---

## 2. Reading User Input with `input()`

### Syntax
```python
variable = input(prompt)
```
* **`prompt` (optional):** A string displayed on screen before waiting for user input.
* **Return Type:** `input()` **always returns a `str`** (string), regardless of what the user types.

### Basic Usage
```python
name = input("Enter your name: ")
print(f"Welcome, {name}!")
```

### Converting Numeric Input
Because `input()` returns a string, you must explicitly cast the result using `int()` or `float()` before performing mathematical operations:
```python
age = int(input("Enter your age: "))
score = float(input("Enter your score: "))

print(f"Next year you will be {age + 1}.")
```
*(Note: Passing non-numeric text into `int()` or `float()` raises a `ValueError`.)*

### Reading Multiple Values on One Line
Combine `input()` with `.split()` to capture multiple space-separated values at once:
```python
# Input: 10 20
x, y = input("Enter two numbers separated by space: ").split()
total = int(x) + int(y)
print(f"Sum: {total}")
```

---

## 3. Displaying Output with `print()`

### Syntax
```python
print(*objects, sep=" ", end="\n", file=sys.stdout, flush=False)
```

### Printing Multiple Items
Pass multiple comma-separated values to `print()`. By default, Python converts each item to a string and separates them with a single space:
```python
role = "Junior Trainer"
batch = 2026
print("Role:", role, "| Batch:", batch)
# Output: Role: Junior Trainer | Batch: 2026
```

### Customizing Separator (`sep`)
The `sep` parameter controls the string inserted between multiple arguments (default is `" "`):
```python
print("2026", "11", "18", sep="-")
# Output: 2026-11-18

print("A", "B", "C", sep="")
# Output: ABC
```

### Customizing Line Ending (`end`)
The `end` parameter controls what is printed at the very end of the output (default is `"\n"`, a newline):
```python
print("Loading", end="...")
print("Done!")
# Output: Loading...Done!
```

### Formatted Output with f-Strings
Prefixing a string with `f` lets you embed variables and expressions directly inside curly braces `{}`:
```python
topic = "Python I/O"
progress = 85.678

print(f"Topic: {topic} | Completion: {progress:.1f}%")
# Output: Topic: Python I/O | Completion: 85.7%
```

---

## 4. Quick Reference

| Function / Parameter | Purpose | Default / Return |
| :--- | :--- | :--- |
| `input(prompt)` | Displays prompt and reads a line of user input | Always returns `str` |
| `print(*objects)` | Prints one or more objects to the output stream | Returns `None` |
| `sep="..."` | Sets the delimiter placed between multiple `print()` arguments | Default is `" "` (single space) |
| `end="..."` | Sets the trailing character(s) printed at the end | Default is `"\n"` (newline) |
| `file=...` | Redirects output to a writable file object instead of console | Default is `sys.stdout` |
| `flush=True` | Forces the output buffer to write immediately | Default is `False` |
