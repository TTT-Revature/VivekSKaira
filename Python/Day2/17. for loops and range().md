# `for` Loops and `range()`

## 1. Overview
A `for` loop in Python is used for **definite iteration**—repeating a block of code once for each item in an **iterable** (such as a `list`, `tuple`, `str`, `dict`, `set`, or a `range` object).

Unlike C-style languages that rely on manual index counters and termination conditions, Python's `for` loop directly retrieves items one by one from the iterable until no items remain.

### Basic Syntax
```python
for item in iterable:
    # Indented block executes once for each item
    print(item)
```

---

## 2. Iterating Over Common Iterables

### Strings and Lists
```python
# Iterating over a list
modules = ["Python", "SQL", "Git"]
for module in modules:
    print(f"Studying: {module}")

# Iterating over characters in a string
for char in "FDE":
    print(char)
```

### Dictionaries
By default, iterating over a dictionary yields its **keys**. Use `.values()` or `.items()` to access values or key-value pairs:
```python
scores = {"Python": 90, "SQL": 85}

for subject, marks in scores.items():
    print(f"{subject}: {marks}")
```

## 3. The `range()` Function
The built-in `range()` function generates an immutable sequence of integers. It is **memory-efficient** (lazy evaluation)—instead of storing all numbers in memory at once, it computes each number on demand during iteration.

### Three Signatures of `range()`

#### 1. `range(stop)`
Generates integers starting from `0` up to `stop - 1` (incrementing by `1`).
```python
for i in range(5):
    print(i, end=" ")  # Output: 0 1 2 3 4
```

#### 2. `range(start, stop)`
Generates integers starting from `start` up to `stop - 1` (incrementing by `1`).
```python
for i in range(2, 6):
    print(i, end=" ")  # Output: 2 3 4 5
```

#### 3. `range(start, stop, step)`
Generates integers from `start` up to (but not including) `stop`, incrementing or decrementing by `step`.
```python
# Positive step (even numbers)
for i in range(0, 10, 2):
    print(i, end=" ")  # Output: 0 2 4 6 8

# Negative step (countdown)
for i in range(5, 0, -1):
    print(i, end=" ")  # Output: 5 4 3 2 1
```

### Key Rules for `range()`
* **Exclusive `stop`:** The `stop` value is never included in the generated sequence.
* **Integers Only:** All arguments (`start`, `stop`, `step`) must be `int` values; passing a `float` raises a `TypeError`.
* **Non-Zero `step`:** Passing `0` as the `step` raises a `ValueError`.
* **Viewing Elements:** Wrap `range()` in `list()` to inspect all generated values at once:
  ```python
  print(list(range(1, 6)))  # [1, 2, 3, 4, 5]
  ```

## 4. Common `for` + `range()` Patterns

### Repeating an Action `N` Times
When the loop counter variable is not needed inside the loop body, use an underscore (`_`) by convention:
```python
for _ in range(3):
    print("Retry connection...")
```

### Index-Based Iteration vs. `enumerate()`
While `range(len(sequence))` can access elements by index, Python's built-in `enumerate()` is preferred when you need both the index and the value:
```python
languages = ["Python", "Java", "C++"]

# Using range(len(...))
for i in range(len(languages)):
    print(i, languages[i])

# Preferred Pythonic approach using enumerate()
for index, lang in enumerate(languages):
    print(index, lang)
```

---

## 5. Nested `for` Loops
A `for` loop can be placed inside another `for` loop. The inner loop completes all of its iterations for every single iteration of the outer loop:
```python
for row in range(1, 4):
    for col in range(1, 4):
        print(f"({row}, {col})", end=" ")
    print()  # Newline after each row
```

---

## 6. Quick Reference

| Expression | Generated Sequence | Notes |
| :--- | :--- | :--- |
| `range(4)` | `0, 1, 2, 3` | Starts at `0` by default |
| `range(2, 5)` | `2, 3, 4` | `stop` (`5`) is excluded |
| `range(1, 10, 3)` | `1, 4, 7` | Increments by `3` |
| `range(10, 4, -2)` | `10, 8, 6` | Counts down when `step` is negative |
| `range(5, 2)` | *(empty)* | Returns nothing if `start >= stop` with positive step |
