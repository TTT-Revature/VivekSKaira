# `re.findall()` and `re.sub()`

## 1. Overview
While `re.search()` and `re.match()` stop after finding a single match, Python's built-in `re` module provides `re.findall()` and `re.sub()` to process **all occurrences** of a pattern across an entire string:
* **`re.findall()`:** Scans the whole string and extracts all non-overlapping matches into a `list`.
* **`re.sub()`:** Scans the whole string and replaces matched patterns with a specified replacement string or function output.

---

## 2. `re.findall(pattern, string, flags=0)`
Scans `string` from left to right and returns a `list` containing **all non-overlapping matches** of `pattern`. If no matches are found, it returns an empty list `[]`.

### Basic Usage
```python
import re

text = "Batch FDE-101 scored 88, FDE-102 scored 94, and FDE-103 scored 79."

# Extract all numbers
scores = re.findall(r"\b\d{2}\b", text)
print(scores)  # Output: ['88', '94', '79']

# Extract all batch codes
batches = re.findall(r"FDE-\d{3}", text)
print(batches)  # Output: ['FDE-101', 'FDE-102', 'FDE-103']
```

### How Capturing Groups Affect `re.findall()`
The return structure of `re.findall()` changes depending on whether the pattern contains capturing groups `(...)`:

1. **No Capturing Groups:** Returns a `list[str]` of full matches.
2. **One Capturing Group:** Returns a `list[str]` containing only the text captured inside that group.
3. **Multiple Capturing Groups:** Returns a `list[tuple[str, ...]]`, where each tuple holds the captured substrings for one match.

```python
import re

log = "2026-11-18: INFO | 2026-11-19: ERROR"

# 1. Single group -> returns list of captured strings
levels = re.findall(r"\d{4}-\d{2}-\d{2}: ([A-Z]+)", log)
print(levels)  # Output: ['INFO', 'ERROR']

# 2. Multiple groups -> returns list of tuples
entries = re.findall(r"(\d{4}-\d{2}-\d{2}): ([A-Z]+)", log)
print(entries)  # Output: [('2026-11-18', 'INFO'), ('2026-11-19', 'ERROR')]

# 3. Non-capturing group (?:...) -> returns full matches
full_matches = re.findall(r"\d{4}-\d{2}-\d{2}: (?:INFO|ERROR)", log)
print(full_matches)  # Output: ['2026-11-18: INFO', '2026-11-19: ERROR']
```

*(Tip: If you need full `Match` objects with `.start()` and `.end()` positions instead of plain strings, use `re.finditer(pattern, string)`.)*

---

## 3. `re.sub(pattern, repl, string, count=0, flags=0)`
Returns a **new string** obtained by replacing occurrences of `pattern` in `string` with `repl`. If `pattern` is not found, the original string is returned unchanged.

* **`count` (optional):** Maximum number of occurrences to replace from left to right. The default `0` replaces **all** matches.

### Basic Text Cleaning and Masking
```python
import re

# 1. Collapse multiple spaces into a single space
messy = "Python     SQL    Git"
print(re.sub(r"\s+", " ", messy))
# Output: Python SQL Git

# 2. Mask sensitive digits (replace all except last 4 digits)
card = "4532-8910-2345-6789"
masked = re.sub(r"\d(?=\d{3}-|\d{3}$)", "*", card)
print(masked)
# Output: ****-****-****-6789

# 3. Limit replacements using 'count'
text = "error: disk full, error: timeout, error: auth failed"
print(re.sub(r"error", "WARNING", text, count=2))
# Output: WARNING: disk full, WARNING: timeout, error: auth failed
```

### Using Backreferences in Replacements
You can reference captured groups from `pattern` inside the `repl` string using `\1`, `\2`, or `\g<1>` to rearrange or reformat text:

```python
import re

# Reformat dates from YYYY-MM-DD to DD-MM-YYYY
notes = "Start: 2026-11-18, Review: 2026-12-01"
updated = re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\3-\2-\1", notes)
print(updated)
# Output: Start: 18-11-2026, Review: 01-12-2026
```

### Using a Function as `repl`
`repl` can also be a function that accepts a `re.Match` object and returns the replacement string dynamically:

```python
import re

def double_number(match: re.Match) -> str:
    value = int(match.group())
    return str(value * 2)

sentence = "Points: 10, Bonus: 25"
result = re.sub(r"\d+", double_number, sentence)
print(result)
# Output: Points: 20, Bonus: 50
```

*(Tip: Use `re.subn(pattern, repl, string)` if you want a tuple `(new_string, count_of_replacements)` showing how many substitutions were made.)*

---

## 4. Quick Reference

| Function | Signature | Return Type | Primary Purpose |
| :--- | :--- | :--- | :--- |
| `re.findall()` | `re.findall(pattern, string, flags=0)` | `list` | Extracts all non-overlapping matches (or captured groups) |
| `re.finditer()` | `re.finditer(pattern, string, flags=0)` | `Iterator[Match]` | Yields `Match` objects one by one for all matches |
| `re.sub()` | `re.sub(pattern, repl, string, count=0, flags=0)` | `str` | Replaces matched patterns with a string or function result |
| `re.subn()` | `re.subn(pattern, repl, string, count=0, flags=0)` | `tuple[str, int]` | Same as `re.sub()`, also returning the total replacement count |
