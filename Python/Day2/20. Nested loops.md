# Nested Loops

## 1. Overview
A **nested loop** is a loop placed inside the body of another loop. In Python, any combination of `for` and `while` loops can be nested within one another.

* **Execution Rule:** For **every single iteration** of the outer loop, the inner loop runs completely from start to finish.
* **Total Iterations:** If the outer loop runs $M$ times and the inner loop runs $N$ times, the innermost block executes $M \times N$ times.

---

## 2. Nested `for` Loops
Nested `for` loops are commonly used to work with multi-dimensional data structures (such as matrices or grids) and to generate combinations or patterns.

### Example: Multiplication Table
```python
for i in range(1, 4):        # Outer loop (rows)
    for j in range(1, 4):    # Inner loop (columns)
        print(f"{i * j:2}", end=" ")
    print()                  # Moves to a new line after each outer iteration

# Output:
#  1  2  3
#  2  4  6
#  3  6  9
```

### Example: Traversing a 2D List (Matrix)
```python
matrix = [
    [10, 20, 30],
    [40, 50, 60]
]

for row in matrix:
    for value in row:
        print(value, end=" ")
    print()

# Output:
# 10 20 30
# 40 50 60
```

---

## 3. Nested `while` Loops
When nesting `while` loops, always initialize or reset the inner loop's control variable **inside** the outer loop; otherwise, the inner loop condition will already be `False` on subsequent outer iterations.

```python
outer = 1
while outer <= 3:
    inner = 1  # Must be reset on every outer iteration
    while inner <= 2:
        print(f"Outer: {outer}, Inner: {inner}")
        inner += 1
    outer += 1
```

---

## 4. Mixing `for` and `while` Loops
Python allows placing a `while` loop inside a `for` loop (or vice versa) when outer iteration is over a fixed sequence and inner iteration depends on a dynamic condition.

```python
batches = ["Batch-A", "Batch-B"]

for batch in batches:
    attempt = 1
    while attempt <= 2:
        print(f"{batch} - Attempt {attempt}")
        attempt += 1
```

---

## 5. Loop Control (`break` and `continue`) in Nested Loops
Loop control statements (`break` and `continue`) apply **only to the innermost loop** that directly encloses them.

```python
for i in range(1, 4):
    for j in range(1, 4):
        if j == 2:
            break  # Terminates ONLY the inner loop; outer loop continues
        print(f"({i}, {j})", end=" ")
    print()

# Output:
# (1, 1)
# (2, 1)
# (3, 1)
```

### Breaking Out of Both Loops
To exit both the inner and outer loops at once, use a boolean flag variable or place the nested loops inside a function and use `return`:

```python
found = False

for row in range(3):
    for col in range(3):
        if row == 1 and col == 2:
            found = True
            break
    if found:
        break  # Exits the outer loop
```

---

## 6. Performance Considerations
* **Time Complexity:** Two nested loops that each iterate $n$ times result in $n \times n = O(n^2)$ operations. Adding a third level increases this to $O(n^3)$.
* **Best Practice:** Keep nesting shallow (ideally 2 levels maximum). When processing large datasets, consider using dictionaries, sets, or built-in functions to avoid unnecessary nested iterations.
