# Introduction to Regular Expressions

## 1. Overview
A **regular expression (regex)** is a sequence of characters that defines a search pattern. Regular expressions are used to validate input formats (such as emails or phone numbers), search for substrings, extract structured data, and perform pattern-based text replacements.

* **Built-in Module:** Python supports regular expressions through the standard library `re` module (`import re`).
* **Use Raw Strings (`r"..."`):** Always define regex patterns as raw strings (e.g., `r"\d+"`) so Python does not interpret backslashes (`\`) as standard string escape sequences before passing them to the regex engine.

---

## 2. Core Functions in the `re` Module

### `re.search(pattern, string)`
Scans the **entire string** for the first location where the pattern matches. Returns a `Match` object if found, or `None` if no match exists.
```python
import re

text = "Batch ID: FDE-2026 started on Monday."
match = re.search(r"FDE-\d{4}", text)

if match:
    print(match.group())  # Output: FDE-2026
```

### `re.match(pattern, string)`
Checks for a match **only at the very beginning** of the string. Returns a `Match` object if found at index `0`, otherwise `None`.
```python
import re

print(re.match(r"Python", "Python is great"))  # <re.Match object; span=(0, 6), match='Python'>
print(re.match(r"great", "Python is great"))   # None (not at the start)
```

### `re.findall(pattern, string)`
Finds **all non-overlapping matches** in the string and returns them as a `list` of strings (returns an empty list `[]` if none are found).
```python
import re

log = "Scores: 85, 92, 78, and 95"
numbers = re.findall(r"\d+", log)
print(numbers)  # Output: ['85', '92', '78', '95']
```

### `re.sub(pattern, replacement, string)`
Replaces occurrences of `pattern` in `string` with `replacement` and returns the modified string.
```python
import re

raw = "Python    SQL   Git"
cleaned = re.sub(r"\s+", " ", raw)
print(cleaned)  # Output: Python SQL Git
```

### `re.split(pattern, string)`
Splits the string wherever `pattern` matches and returns a `list` of substrings.
```python
import re

data = "apple, banana; cherry|date"
items = re.split(r"[,;|]\s*", data)
print(items)  # Output: ['apple', 'banana', 'cherry', 'date']
```

### Compiling Reusable Patterns: `re.compile()`
When applying the same pattern repeatedly (such as inside a loop), compile it once into a regex object for cleaner code and better performance:
```python
import re

id_pattern = re.compile(r"^EMP-\d{3}$")

print(bool(id_pattern.match("EMP-104")))  # True
print(bool(id_pattern.match("EMP-12")))   # False
```

## 3. Working with `Match` Objects
Functions like `re.search()` and `re.match()` return a `Match` object when a pattern succeeds:

```python
import re

text = "Exam date: 2026-11-18"
m = re.search(r"\d{4}-\d{2}-\d{2}", text)

if m:
    print(m.group())  # '2026-11-18' (the matched substring)
    print(m.start())  # 11           (starting index of the match)
    print(m.end())    # 21           (ending index of the match)
    print(m.span())   # (11, 21)     (tuple of start and end indices)
```

## 4. Essential Regex Syntax

### Metacharacters
| Symbol | Meaning | Example Pattern | Matches |
| :--- | :--- | :--- | :--- |
| `.` | Any single character except newline (`\n`) | `r"p.t"` | `"pat"`, `"pit"`, `"p9t"` |
| `^` | Start of the string | `r"^Hello"` | `"Hello world"` |
| `$` | End of the string | `r"end$"` | `"The end"` |
| `*` | `0` or more repetitions of preceding token | `r"ab*c"` | `"ac"`, `"abc"`, `"abbc"` |
| `+` | `1` or more repetitions of preceding token | `r"ab+c"` | `"abc"`, `"abbc"` (not `"ac"`) |
| `?` | `0` or `1` repetition (makes preceding token optional) | `r"colou?r"` | `"color"`, `"colour"` |
| `{n}` / `{n,m}` | Exact `n` or between `n` and `m` repetitions | `r"\d{2,4}"` | `"12"`, `"123"`, `"1234"` |
| `[...]` | Character set (matches any single character inside) | `r"[aeiou]"` | Any lowercase vowel |
| `[^...]` | Negated character set (any character NOT inside) | `r"[^0-9]"` | Any non-digit character |
| `\|` | Alternation (logical OR) | `r"cat\|dog"` | `"cat"` or `"dog"` |
| `(...)` | Grouping and capturing sub-patterns | `r"(\d{4})-(\d{2})"` | Captures year and month separately |

### Special Character Sequences
| Sequence | Meaning | Equivalent Set |
| :--- | :--- | :--- |
| `\d` | Any digit (`0`–`9`) | `[0-9]` |
| `\D` | Any non-digit character | `[^0-9]` |
| `\w` | Any word character (letters, digits, underscore) | `[a-zA-Z0-9_]` |
| `\W` | Any non-word character | `[^a-zA-Z0-9_]` |
| `\s` | Any whitespace character (space, tab, newline) | `[ \t\n\r\f\v]` |
| `\S` | Any non-whitespace character | `[^ \t\n\r\f\v]` |
| `\b` | Word boundary (start or end of a word) | N/A |

## 5. Practical Validation Example
```python
import re

def is_valid_username(username: str) -> bool:
    """Allow 4 to 15 alphanumeric characters or underscores, starting with a letter."""
    pattern = r"^[a-zA-Z][a-zA-Z0-9_]{3,14}$"
    return bool(re.match(pattern, username))

print(is_valid_username("vivek_01"))  # True
print(is_valid_username("01_vivek"))  # False (starts with a digit)
print(is_valid_username("ab"))        # False (too short)
```

## 6. Quick Reference

| Function / Flag | Purpose | Return Type |
| :--- | :--- | :--- |
| `re.search(pat, s)` | Finds first match anywhere in `s` | `Match` or `None` |
| `re.match(pat, s)` | Matches `pat` only at the start of `s` | `Match` or `None` |
| `re.findall(pat, s)` | Returns all non-overlapping matches in `s` | `list[str]` |
| `re.sub(pat, repl, s)` | Replaces matches of `pat` with `repl` | `str` |
| `re.split(pat, s)` | Splits `s` at every match of `pat` | `list[str]` |
| `re.compile(pat)` | Compiles `pat` into a reusable `Pattern` object | `re.Pattern` |
| `re.IGNORECASE` (`re.I`) | Optional flag enabling case-insensitive matching | Flag constant |
