# `re.search()`, `re.match()`, and `re.fullmatch()`

## 1. Overview
`re.search()`, `re.match()`, and `re.fullmatch()` are three core functions in Python's built-in `re` module used to test a string against a regular expression pattern.

* **Common Return Behavior:** All three functions return a **`re.Match` object** when the pattern succeeds, or **`None`** when it fails.
* **Key Difference:** They differ strictly in **how much of the string** and **where in the string** the pattern must match.

```text
String:       "Batch FDE-2026 Active"
Pattern:      r"FDE-\d{4}"

re.search()    ---> Matches "FDE-2026" (found anywhere in the string)
re.match()     ---> None (string does not start with "FDE-2026")
re.fullmatch() ---> None (entire string is not "FDE-2026")
```

---

## 2. `re.search(pattern, string, flags=0)`
Scans the **entire string** from left to right and returns a `Match` object for the **first location** where the pattern matches.

* **Best Use Case:** Finding or extracting a substring that can appear anywhere inside a larger text or log line.

```python
import re

text = "Status: Batch FDE-2026 is currently active."
match = re.search(r"FDE-\d{4}", text)

if match:
    print(match.group())  # Output: FDE-2026
    print(match.span())   # Output: (14, 22)
```

---

## 3. `re.match(pattern, string, flags=0)`
Checks for a match **only at the very beginning** of the string (index `0`).

* Once the pattern matches from index `0`, any remaining trailing characters in the string are ignored.
* Even when the `re.MULTILINE` flag is set, `re.match()` still checks **only index `0`** of the entire string—not the start of subsequent lines after `\n`.
* **Best Use Case:** Checking prefixes or verifying how a line/string starts.

```python
import re

# Succeeds because "FDE-2026" is at index 0 (trailing text is ignored)
m1 = re.match(r"FDE-\d{4}", "FDE-2026: Python Track")
print(m1.group() if m1 else None)  # Output: FDE-2026

# Fails because "FDE-2026" is not at index 0
m2 = re.match(r"FDE-\d{4}", "Batch FDE-2026")
print(m2)                          # Output: None
```

---

## 4. `re.fullmatch(pattern, string, flags=0)`
Requires the **entire string**—from the very first character to the very last character—to match the pattern.

* Eliminates the need to manually add start (`^` / `\A`) and end (`$` / `\Z`) anchors to a validation pattern.
* **Best Use Case:** Strict input validation (employee IDs, dates, pin codes, usernames) where partial matches must be rejected.

```python
import re

pattern = r"FDE-\d{4}"

# Succeeds only when the whole string matches the pattern
print(bool(re.fullmatch(pattern, "FDE-2026")))          # True

# Fails if there are extra characters before or after
print(bool(re.fullmatch(pattern, "FDE-2026-EXTRA")))    # False
print(bool(re.fullmatch(pattern, "Batch FDE-2026")))    # False
```

---

## 5. Side-by-Side Comparison
Testing the same pattern `r"\d{4}"` across three different strings highlights how each function behaves:

```python
import re

pattern = r"\d{4}"

samples = [
    "2026",            # Exact 4 digits
    "2026-November",   # Starts with 4 digits, followed by text
    "Year: 2026"       # Contains 4 digits in the middle/end
]

for s in samples:
    print(f"Input: '{s}'")
    print("  search()   :", bool(re.search(pattern, s)))
    print("  match()    :", bool(re.match(pattern, s)))
    print("  fullmatch():", bool(re.fullmatch(pattern, s)))
```

### Output
```text
Input: '2026'
  search()   : True
  match()    : True
  fullmatch(): True
Input: '2026-November'
  search()   : True
  match()    : True
  fullmatch(): False
Input: 'Year: 2026'
  search()   : True
  match()    : False
  fullmatch(): False
```

## 6. Safely Handling `None` Results
Because all three functions return `None` when no match is found, calling `.group()` directly without checking will raise an `AttributeError: 'NoneType' object has no attribute 'group'`. Always guard with an `if` statement:

```python
import re

result = re.fullmatch(r"\d{6}", "110001")

if result is not None:
    print(f"Valid PIN: {result.group()}")
else:
    print("Invalid PIN format.")
```

---

## 7. Quick Reference

| Function | Where Pattern Must Match | Equivalent Anchors | Primary Use Case |
| :--- | :--- | :--- | :--- |
| `re.search(pat, s)` | Anywhere inside `s` (returns first match) | `pat` | Searching or extracting substrings from text |
| `re.match(pat, s)` | At the start of `s` (index `0` only) | `\Apat` | Checking string prefixes or leading tokens |
| `re.fullmatch(pat, s)` | Across the **entire** string `s` | `\Apat\Z` | Validating complete input strings against a format |
