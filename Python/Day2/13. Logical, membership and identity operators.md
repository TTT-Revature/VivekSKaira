# Logical, Membership, and Identity Operators

## 1. Overview
Beyond arithmetic and comparison operations, Python provides three specialized operator groups to combine conditional logic, verify whether an element exists inside a collection, and check whether two variables reference the exact same object in memory.

---

## 2. Logical Operators
Logical operators combine or invert conditional expressions and evaluate operands based on their **truthiness**.

| Operator | Description | Example (`x = True, y = False`) | Output |
| :--- | :--- | :--- | :--- |
| `and` | Returns `True` if **both** operands are truthy | `x and y` | `False` |
| `or` | Returns `True` if **at least one** operand is truthy | `x or y` | `True` |
| `not` | Inverts the boolean state of the operand | `not x` | `False` |

### Key Behaviors to Remember
* **Short-Circuit Evaluation:** Python stops evaluating as soon as the final outcome is determined:
  * In `A and B`, if `A` is falsy, `B` is never evaluated.
  * In `A or B`, if `A` is truthy, `B` is never evaluated.
* **Return Value:** `and` and `or` do not strictly return `True` or `False`—they return the **actual operand** that decided the expression:
  ```python
  print(0 and 10)          # 0 (first falsy operand)
  print(5 and 10)          # 10 (last evaluated truthy operand)
  print("" or "Default")   # 'Default' (first truthy operand)
  ```

---

## 3. Membership Operators
Membership operators test whether a value or item is present inside an iterable or sequence (such as a `str`, `list`, `tuple`, `set`, or `dict`) and always return a `bool`.

| Operator | Description | Example | Output |
| :--- | :--- | :--- | :--- |
| `in` | Returns `True` if the value is found in the sequence | `"py" in "python"` | `True` |
| `not in` | Returns `True` if the value is **not** found in the sequence | `5 not in [1, 2, 3]` | `True` |

### Key Behaviors to Remember
```python
# 1. Strings check for substring matches (case-sensitive)
print("Dev" in "Developer")      # True
print("dev" in "Developer")      # False

# 2. Dictionaries check keys by default, NOT values
user = {"name": "Vivek", "role": "FDE"}
print("role" in user)            # True
print("FDE" in user)             # False
print("FDE" in user.values())    # True
```

---

## 4. Identity Operators
Identity operators compare the **memory locations** (`id()`) of two objects to determine whether both variables point to the exact same object in memory.

| Operator | Description | Example | Output |
| :--- | :--- | :--- | :--- |
| `is` | Returns `True` if both variables point to the same object | `a is b` | `True` / `False` |
| `is not` | Returns `True` if variables point to different objects | `a is not b` | `True` / `False` |

### Best Practice: Checking for `None`
Always use `is` or `is not` (rather than `==` or `!=`) when checking for `None`, because `None` is a singleton object in Python:
```python
result = None

if result is None:
    print("No value assigned yet.")
```

---

## 5. Equality (`==`) vs. Identity (`is`)
* **`==` (Equality):** Checks whether two objects have the **same value**.
* **`is` (Identity):** Checks whether two variables reference the **exact same object** in memory.

```python
list_1 = [10, 20, 30]
list_2 = [10, 20, 30]  # Separate list object with identical contents
list_3 = list_1        # Alias pointing to the same list object as list_1

print(list_1 == list_2)  # True  (values match)
print(list_1 is list_2)  # False (stored at different memory addresses)
print(list_1 is list_3)  # True  (both point to the exact same memory address)
```
