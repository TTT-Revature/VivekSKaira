# Escape Characters and Multiline Strings

## 1. Overview
When working with text in Python, standard single-line quotes (`'...'` or `"..."`) cannot directly contain unescaped matching quotes or literal line breaks. Python solves these formatting requirements using:
* **Escape Characters:** Special sequences starting with a backslash (`\`) that represent non-printable characters (such as newlines and tabs) or literal quote marks.
* **Multiline Strings:** String literals enclosed in triple quotes (`'''...'''` or `"""..."""`) that span multiple lines while preserving line breaks and spacing.

---

## 2. Escape Characters
An **escape sequence** consists of a backslash (`\`) followed by a character that signals the Python interpreter to treat it differently from a normal literal character.

### Common Escape Sequences

| Sequence | Name | Description | Example | Output |
| :--- | :--- | :--- | :--- | :--- |
| `\n` | Newline | Moves the cursor to a new line | `"Line 1\nLine 2"` | Prints on two separate lines |
| `\t` | Horizontal Tab | Inserts a tab space | `"ID\tName"` | `ID      Name` |
| `\\` | Backslash | Inserts a literal backslash character | `"C:\\Users\\Docs"` | `C:\Users\Docs` |
| `\'` | Single Quote | Inserts a single quote inside `'...'` | `'It\'s valid'` | `It's valid` |
| `\"` | Double Quote | Inserts a double quote inside `"..."` | `"He said \"Hi\""` | `He said "Hi"` |
| `\r` | Carriage Return | Moves cursor back to the start of the line | `"12345\rAB"` | `AB345` |
| `\b` | Backspace | Deletes the preceding character | `"Pythonn\b"` | `Python` |

### Code Examples
```python
# 1. Mixing quotes without syntax errors
dialogue = 'She replied, "It\'s ready for deployment."'
print(dialogue)
# Output: She replied, "It's ready for deployment."

# 2. Formatting structured console output with \n and \t
report = "Module\t\tStatus\nPython\t\tCompleted\nSQL\t\tIn Progress"
print(report)
# Output:
# Module          Status
# Python          Completed
# SQL             In Progress
```

---

## 3. Raw Strings (`r"..."`)
Prefixing a string literal with `r` or `R` creates a **raw string**, which tells Python to ignore escape sequences and treat backslashes (`\`) as literal characters.

* **Common Use Cases:** Windows file paths and regular expressions (`regex`).

```python
# Standard string interprets \U and \n as escape sequences (causes errors/unintended breaks)
# path = "C:\Users\new_folder\notes.md"  # SyntaxError due to \U

# Raw string preserves backslashes literally
path = r"C:\Users\new_folder\notes.md"
print(path)
# Output: C:\Users\new_folder\notes.md
```

*(Caution: A raw string cannot end with an odd number of backslashes, such as `r"C:\Data\"`, because the final backslash escapes the closing quote and causes a `SyntaxError`.)*

---

## 4. Multiline Strings
Multiline strings are enclosed in either **triple single quotes (`'''...'''`)** or **triple double quotes (`"""..."""`)**. Everything inside—including newlines, spaces, and single or double quotes—is preserved exactly as written.

### Basic Usage
```python
query = """SELECT id, name, track
FROM trainees
WHERE status = 'Active';"""

print(query)
# Output:
# SELECT id, name, track
# FROM trainees
# WHERE status = 'Active';
```

### Suppressing Unwanted Line Breaks with `\`
If you want to break a long line in your source code for readability without inserting an actual newline character (`\n`) into the string, place a backslash (`\`) at the end of the line:

```python
text = """This is a single continuous sentence \
written across multiple lines in the editor."""

print(text)
# Output: This is a single continuous sentence written across multiple lines in the editor.
```

### Handling Indentation Inside Blocks
Because triple-quoted strings preserve **all** leading whitespace on every line, indenting them inside a function or `if` block includes those extra spaces in the string value.

To write a clean multi-line string inside an indented block without extra leading spaces, use **implicit string concatenation inside parentheses `()`**:

```python
def get_welcome_message(name: str) -> str:
    # Each line is concatenated cleanly without unintended indentation spaces
    message = (
        f"Hello, {name}.\n"
        "Welcome to the Revature FDE training program.\n"
        "Please upload your daily notes to GitHub."
    )
    return message

print(get_welcome_message("Vivek"))
```

---

## 5. Quick Reference

| String Syntax | Processes Escapes (`\n`, `\t`)? | Spans Multiple Lines Directly? | Primary Use Case |
| :--- | :--- | :--- | :--- |
| `'...'` / `"..."` | Yes | No (requires `\n` or `\`) | Standard single-line text |
| `r"..."` / `R"..."` | **No** (`\` is literal) | No | File paths, regular expressions |
| `'''...'''` / `"""..."""` | Yes | **Yes** | SQL queries, templates, multi-line blocks, docstrings |
| `("..." "...")` | Yes | Yes (via implicit joining) | Clean multi-line text inside indented functions/blocks |
