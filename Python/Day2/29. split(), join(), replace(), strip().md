# `split()`, `join()`, `replace()`, and `strip()`

## 1. Overview
`strip()`, `split()`, `join()`, and `replace()` are four core built-in string methods used for cleaning, parsing, modifying, and reconstructing text data in Python.

* **Immutability Reminder:** Because strings are immutable, none of these methods alter the original string in place—they always return a new string (or a `list` of strings in the case of `split()`).

---

## 2. `strip()` — Removing Leading and Trailing Characters
Removes unwanted characters from the **beginning (left)** and **end (right)** of a string.

### Syntax
```python
string.strip([chars])
```
* **`chars` (optional):** A string specifying the set of characters to remove. If omitted or `None`, removes all leading and trailing whitespace (`" "`, `\t`, `\n`, `\r`).
* **Important Rule:** `chars` is treated as a **set of individual characters**, not an exact substring. Python strips characters from both ends until it encounters a character not present in `chars`.

### Variants
* **`lstrip([chars])`:** Strips characters from the **left (leading)** side only.
* **`rstrip([chars])`:** Strips characters from the **right (trailing)** side only.

### Examples
```python
# 1. Default whitespace removal
raw_input = "   \tVivek Singh\n  "
print(raw_input.strip())       # 'Vivek Singh'
print(raw_input.lstrip())      # 'Vivek Singh\n  '
print(raw_input.rstrip())      # '   \tVivek Singh'

# 2. Removing specific edge characters
url = "[www.example.com](https://www.example.com)"
print(url.strip("cmowz."))     # 'example'

banner = "---Python Notes---"
print(banner.strip("-"))       # 'Python Notes'
```

## 3. `split()` — Breaking a String into a List
Divides a string into a `list` of substrings based on a delimiter.

### Syntax
```python
string.split(sep=None, maxsplit=-1)
```
* **`sep` (optional):** The delimiter string on which to split.
  * When `sep=None` (default), Python splits on any consecutive whitespace and automatically discards empty strings from leading/trailing spaces.
  * When an explicit `sep` is provided (e.g., `","`), consecutive delimiters produce empty string elements (`""`) in the resulting list.
* **`maxsplit` (optional):** Maximum number of splits to perform (default `-1` means no limit). The resulting list will have at most `maxsplit + 1` elements.

### Variant
* **`rsplit(sep=None, maxsplit=-1)`:** Works identically to `split()`, except when `maxsplit` is specified, it splits starting from the **right** end of the string.

### Examples
```python
# 1. Default split on arbitrary whitespace
text = "  Python    SQL   Git  "
print(text.split())                 # ['Python', 'SQL', 'Git']

# 2. Splitting with an explicit delimiter
csv_row = "101,Vivek,,FDE"
print(csv_row.split(","))           # ['101', 'Vivek', '', 'FDE']

# 3. Limiting splits with maxsplit
log = "ERROR:2026-11-18:Connection timed out"
print(log.split(":", maxsplit=2))   # ['ERROR', '2026-11-18', 'Connection timed out']

# 4. Splitting from the right with rsplit()
filepath = "src/modules/utils/helper.py"
print(filepath.rsplit("/", 1))      # ['src/modules/utils', 'helper.py']
```

## 4. `join()` — Combining an Iterable into a String
Concatenates elements of an iterable (such as a `list`, `tuple`, or `set`) into a single string, inserting the caller string as a separator between each element.

### Syntax
```python
separator.join(iterable)
```
* **String Elements Required:** Every item in `iterable` **must be a `str`**. Passing non-string items (like `int` or `None`) raises a `TypeError`.

### Examples
```python
# 1. Joining a list of strings
modules = ["Python", "SQL", "Git"]
print(", ".join(modules))       # 'Python, SQL, Git'
print(" -> ".join(modules))     # 'Python -> SQL -> Git'
print("".join(modules))         # 'PythonSQLGit'

# 2. Joining non-string items by converting them first
scores = [88, 92, 95]
# print(", ".join(scores))      # Raises TypeError: sequence item 0: expected str instance, int found
print(", ".join(str(s) for s in scores))  # '88, 92, 95'
```

---

## 5. `replace()` — Substituting Substrings
Returns a copy of the string with occurrences of a target substring replaced by a new substring.

### Syntax
```python
string.replace(old, new, count=-1)
```
* **`old`:** The substring to search for (case-sensitive).
* **`new`:** The replacement substring.
* **`count` (optional):** Maximum number of occurrences to replace from left to right (default `-1` replaces all occurrences).

### Examples
```python
text = "one fish, two fish, red fish"

# 1. Replace all occurrences
print(text.replace("fish", "bird"))     # 'one bird, two bird, red bird'

# 2. Replace only the first 2 occurrences
print(text.replace("fish", "bird", 2))  # 'one bird, two bird, red fish'

# 3. Deleting a substring by replacing with an empty string
phone = "(987) 654-3210"
cleaned_phone = phone.replace("(", "").replace(")", "").replace("-", "").replace(" ", "")
print(cleaned_phone)                    # '9876543210'
```

## 6. Chaining Methods Together
Because `strip()`, `replace()`, and `join()` return strings, they are frequently chained together to clean and normalize messy text data:

```python
raw_tags = "  python ;  sql ; git ;  docker  "

# Clean whitespace -> split on ';' -> strip each tag -> rejoin cleanly
normalized = ", ".join(tag.strip().upper() for tag in raw_tags.strip().split(";"))
print(normalized)  # 'PYTHON, SQL, GIT, DOCKER'
```

## 7. Quick Reference

| Method | Called On | Arguments | Return Type | Primary Purpose |
| :--- | :--- | :--- | :--- | :--- |
| `s.strip()` | Target `str` | `[chars]` | `str` | Removes leading and trailing whitespace or specified characters |
| `s.split()` | Target `str` | `sep=None, maxsplit=-1` | `list[str]` | Splits a string into a list of substrings using a delimiter |
| `sep.join()` | Separator `str` | `iterable` (of `str`) | `str` | Joins elements of an iterable into one string separated by `sep` |
| `s.replace()` | Target `str` | `old, new, count=-1` | `str` | Replaces occurrences of `old` substring with `new` substring |
