# `while` Loops

## 1. Overview
A `while` loop in Python is used for **indefinite iteration**—repeatedly executing a block of code as long as a specified condition evaluates to `True`.

* **Entry-Controlled Loop:** The condition is evaluated *before* every iteration. If the condition is `False` on the very first check, the loop body does not execute at all.
* **When to Use:** Ideal when the exact number of iterations is not known in advance and depends on a dynamic state or condition changing during execution.

---

## 2. Syntax and Execution Flow
A well-structured `while` loop typically consists of three parts:
1. **Initialization:** Set up the control variable before the loop starts.
2. **Condition:** A boolean expression checked prior to each iteration.
3. **Update:** Modify the control variable inside the loop body so the condition eventually becomes `False`.

```python
# 1. Initialization
count = 1

# 2. Condition
while count <= 5:
    print(f"Iteration: {count}")
    # 3. Update
    count += 1

print("Loop finished.")
```

---

## 3. Common `while` Loop Patterns

### A. Counter-Controlled Loop
Used when repeating an action while a numeric counter reaches a target threshold:
```python
num = 5
total = 0

while num > 0:
    total += num
    num -= 1

print(f"Sum: {total}")  # Output: Sum: 15
```

### B. Sentinel / Condition-Controlled Loop
Used when the loop continues until a specific value (called a **sentinel**) or state occurs—such as emptying a list or validating input:
```python
tasks = ["Setup", "Code", "Test"]

while tasks:  # Continues while the list is truthy (non-empty)
    current_task = tasks.pop(0)
    print(f"Completed: {current_task}")
```

---

## 4. Infinite Loops
An **infinite loop** occurs when the loop condition never evaluates to `False`, causing the program to run indefinitely.

### Accidental Infinite Loops
Usually caused by forgetting to update the loop variable or updating it in the wrong direction:
```python
# WARNING: Do not run — 'x' never changes, so condition stays True forever
x = 1
while x < 5:
    print(x)
```
*(Tip: Press `Ctrl + C` in the terminal to force-stop a stuck infinite loop.)*

### Intentional Infinite Loops (`while True`)
Sometimes an infinite loop is created deliberately (e.g., for menu prompts or polling loops) and exited explicitly using a `break` statement once an exit condition is met:
```python
while True:
    command = input("Type 'exit' to quit: ")
    if command.lower() == "exit":
        print("Exiting program.")
        break
    print(f"You entered: {command}")
```

---

## 5. Nested `while` Loops
A `while` loop can be placed inside another `while` loop. The inner loop completes all of its iterations for every single iteration of the outer loop.

*(Important: Always reset the inner loop's control variable inside the outer loop before the inner loop begins again.)*

```python
row = 1
while row <= 3:
    col = 1  # Reset inner counter on each outer iteration
    while col <= 3:
        print(f"({row},{col})", end=" ")
        col += 1
    print()
    row += 1
```

---

## 6. `while` Loop vs. `for` Loop

| Feature | `while` Loop | `for` Loop |
| :--- | :--- | :--- |
| **Iteration Type** | Indefinite (condition-based) | Definite (sequence/iterable-based) |
| **Best Used When** | Number of iterations is unknown beforehand | Iterating over a collection or known `range()` |
| **Counter Management** | Manual initialization and update required | Automatic iteration over items |
| **Infinite Loop Risk** | High if condition never becomes `False` | Very low (ends when iterable is exhausted) |
