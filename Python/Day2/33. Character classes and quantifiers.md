# Character Classes and Quantifiers

## 1. Overview
In regular expressions, **character classes** and **quantifiers** work together to define flexible search patterns:
* **Character Classes:** Specify *which* set of characters is allowed at a single position in the match.
* **Quantifiers:** Specify *how many times* the preceding character, character class, or group must occur to form a match.

---

## 2. Custom Character Classes (`[...]`)
A **character class** (or character set) is enclosed in square brackets `[]` and matches **any single character** listed inside it.

### Basic Sets
```python
import re

# Matches 'bat', 'cat', or 'rat'
print(re.findall(r"[bcr]at", "The bat and cat chased a rat."))
# Output: ['bat', 'cat', 'rat']

# Matches any lowercase vowel
print(re.findall(r"[aeiou]", "Python"))
# Output: ['o']
```

### Character Ranges (`-`)
A hyphen (`-`) inside square brackets defines a continuous range of characters based on ASCII/Unicode order:
* `[a-z]` — Any lowercase letter from `a` to `z`
* `[A-Z]` — Any uppercase letter from `A` to `Z`
* `[0-9]` — Any digit from `0` to `9`
* `[a-zA-Z0-9]` — Any alphanumeric character
* `[0-9a-fA-F]` — Any valid hexadecimal digit

### Negated Character Classes (`[^...]`)
Placing a caret (`^`) as the **very first character** inside square brackets inverts the set, matching any single character that is **not** listed:
```python
import re

# Match any character that is NOT a digit
non_digits = re.findall(r"[^0-9]", "FDE-2026")
print(non_digits)
# Output: ['F', 'D', 'E', '-']
```
*(Note: If `^` appears anywhere other than the first position inside `[...]`, such as `[a^b]`, it is treated as a literal `^` character.)*

### Special Characters Inside Brackets
Inside `[...]`, most regex metacharacters (such as `.`, `*`, `+`, `?`, `(`, `)`) lose their special meaning and match literally:
```python
import re

# [.] matches a literal dot, not "any character"
print(re.findall(r"[.]", "a.b*c.d"))
# Output: ['.', '.']
```

## 3. Predefined (Shorthand) Character Classes
Python's `re` module provides shorthand escape sequences for commonly used character sets:

| Sequence | Matches | Equivalent Custom Class |
| :--- | :--- | :--- |
| `\d` | Any decimal digit | `[0-9]` |
| `\D` | Any non-digit character | `[^0-9]` |
| `\w` | Any word character (letters, digits, underscore) | `[a-zA-Z0-9_]` |
| `\W` | Any non-word character (spaces, punctuation, symbols) | `[^a-zA-Z0-9_]` |
| `\s` | Any whitespace character (space, `\t`, `\n`, `\r`) | `[ \t\n\r\f\v]` |
| `\S` | Any non-whitespace character | `[^ \t\n\r\f\v]` |
| `.` | Any single character except newline (`\n`) | N/A |

```python
import re

text = "User_01: 95%"
print(re.findall(r"\w", text))  # ['U', 's', 'e', 'r', '_', '0', '1', '9', '5']
print(re.findall(r"\W", text))  # [':', ' ', '%']
```

## 4. Quantifiers
**Quantifiers** control repetition. By default, a quantifier applies **only to the single token immediately preceding it** (unless parentheses `()` are used to group multiple characters).

| Quantifier | Meaning | Example Pattern | Matches |
| :--- | :--- | :--- | :--- |
| `*` | `0` or more times | `r"lo*k"` | `"lk"`, `"lok"`, `"look"`, `"loook"` |
| `+` | `1` or more times | `r"lo+k"` | `"lok"`, `"look"` (does not match `"lk"`) |
| `?` | `0` or `1` time (optional) | `r"https?"` | `"http"`, `"https"` |
| `{n}` | Exactly `n` times | `r"\d{4}"` | `"2026"` (any 4 consecutive digits) |
| `{n,}` | `n` or more times | `r"\d{2,}"` | `"12"`, `"123"`, `"12345"` |
| `{n,m}` | Between `n` and `m` times (inclusive) | `r"\w{3,6}"` | Words of length 3 to 6 |

### Quantifying Single Characters vs. Groups
```python
import re

# '+' applies only to 'b'
print(re.findall(r"ab+", "ab abb abab"))
# Output: ['ab', 'abb', 'ab', 'ab']

# '+' applies to the entire group '(ab)'
print(re.findall(r"(?:ab)+", "ab abb abab"))
# Output: ['ab', 'ab', 'abab']
```

---

## 5. Greedy vs. Non-Greedy (Lazy) Quantifiers

### Greedy Matching (Default)
By default, all quantifiers (`*`, `+`, `?`, `{n,m}`) are **greedy**—they consume as many characters as possible while still allowing the overall pattern to match.

### Non-Greedy / Lazy Matching (`?`)
Appending `?` after a quantifier (`*?`, `+?`, `??`, `{n,m}?`) makes it **non-greedy (lazy)**—it matches as *few* characters as possible.

```python
import re

html = "<b>Python</b> and <i>SQL</i>"

# Greedy: matches from the very first '<' to the very last '>'
print(re.findall(r"<.*>", html))
# Output: ['<b>Python</b> and <i>SQL</i>']

# Non-greedy (lazy): stops at the nearest closing '>'
print(re.findall(r"<.*?>", html))
# Output: ['<b>', '</b>', '<i>', '</i>']
```

## 6. Combining Character Classes and Quantifiers

```python
import re

sample = "Colors: #FF5733, #00A86B, #12345, #GGGGGG"

# Match valid 6-digit hexadecimal color codes
hex_colors = re.findall(r"#[0-9A-Fa-f]{6}\b", sample)
print(hex_colors)
# Output: ['#FF5733', '#00A86B']

# Extract all multi-digit integers from a sentence
log = "Batch 12 completed 45 tasks in 300 seconds."
print(re.findall(r"\d+", log))
# Output: ['12', '45', '300']
```
