# Arithmetic, Comparison, and Assignment Operators

## 1. Overview
**Operators** are special symbols in Python that perform operations on values or variables (known as **operands**). Based on the operation performed, operators are grouped into distinct categories—starting with arithmetic, comparison, and assignment operators.

---

## 2. Arithmetic Operators
Arithmetic operators perform standard mathematical operations on numeric types (`int`, `float`, `complex`).

| Operator | Name | Description | Example (`a = 10, b = 3`) | Output |
| :--- | :--- | :--- | :--- | :--- |
| `+` | Addition | Adds two operands | `a + b` | `13` |
| `-` | Subtraction | Subtracts right operand from left | `a - b` | `7` |
| `*` | Multiplication | Multiplies two operands | `a * b` | `30` |
| `/` | Division | Divides left by right (always returns a `float`) | `a / b` | `3.3333333333333335` |
| `//` | Floor Division | Divides and rounds **down** to the nearest integer | `a // b` | `3` |
| `%` | Modulus | Returns the remainder of division | `a % b` | `1` |
| `**` | Exponentiation | Raises left operand to the power of right | `a ** b` | `1000` |

### Key Behaviors to Remember
```python
# 1. True division (/) always returns a float, even when evenly divisible
print(10 / 2)    # 5.0

# 2. Floor division (//) rounds toward negative infinity (not toward zero)
print(7 // 2)    # 3
print(-7 // 2)   # -4

# 3. Division or modulus by zero raises ZeroDivisionError
# print(10 / 0)  # ZeroDivisionError: division by zero
```

## 3. Comparison (Relational) Operators
Comparison operators compare two values and always return a boolean result (`True` or `False`).

| Operator | Name | Description | Example (`x = 15, y = 20`) | Output |
| :--- | :--- | :--- | :--- | :--- |
| `==` | Equal to | True if both operands have equal values | `x == y` | `False` |
| `!=` | Not equal to | True if operands do not have equal values | `x != y` | `True` |
| `>` | Greater than | True if left operand is greater than right | `x > y` | `False` |
| `<` | Less than | True if left operand is less than right | `x < y` | `True` |
| `>=` | Greater than or equal to | True if left is greater than or equal to right | `x >= 15` | `True` |
| `<=` | Less than or equal to | True if left is less than or equal to right | `y <= 10` | `False` |

### Chained Comparisons
Python allows chaining multiple comparison operators together in a single readable expression:
```python
score = 82

# Equivalent to: score >= 60 and score <= 100
is_passing = 60 <= score <= 100
print(is_passing)  # True
```

*(Note: `==` checks whether two objects have the same **value**, whereas `is` checks whether they share the exact same **memory identity**.)*

## 4. Assignment Operators
Assignment operators assign values to variables. **Compound (augmented) assignment operators** combine an arithmetic operation with assignment in a single step.

| Operator | Example | Equivalent To | Description |
| :--- | :--- | :--- | :--- |
| `=` | `x = 10` | `x = 10` | Assigns right-hand value to left-hand variable |
| `+=` | `x += 5` | `x = x + 5` | Adds and assigns |
| `-=` | `x -= 3` | `x = x - 3` | Subtracts and assigns |
| `*=` | `x *= 2` | `x = x * 2` | Multiplies and assigns |
| `/=` | `x /= 4` | `x = x / 4` | Divides and assigns (`float`) |
| `//=` | `x //= 4` | `x = x // 4` | Floor divides and assigns |
| `%=` | `x %= 3` | `x = x % 3` | Computes remainder and assigns |
| `**=` | `x **= 2` | `x = x ** 2` | Raises to power and assigns |

### Example
```python
points = 50
points += 25    # points is now 75
points -= 10    # points is now 65
points *= 2     # points is now 130
points //= 3    # points is now 43
print(points)   # 43
```

### Assignment Expression (`:=` Walrus Operator)
Introduced in Python 3.8, `:=` assigns a value to a variable as part of a larger expression:
```python
# Assigns len(data) to 'n' and checks the condition in one line
data = [10, 20, 30, 40]
if (n := len(data)) > 3:
    print(f"List is too long ({n} elements)")
```
