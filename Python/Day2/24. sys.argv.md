# Command-Line Arguments with `sys.argv`

## 1. Overview
`sys.argv` (short for **argument vector**) is a list provided by Python's built-in `sys` module that stores the **command-line arguments** passed to a Python script when it is executed from the terminal.

* **Module Required:** Must import `sys` (`import sys`).
* **Data Structure:** A standard Python `list` of strings (`list[str]`).
* **Element Types:** Every item in `sys.argv` is stored as a `str`, regardless of whether the user typed numbers or words.

---

## 2. Structure of `sys.argv`
When a script runs from the command line, Python splits the command by whitespace and populates `sys.argv`:

* **`sys.argv[0]`:** The name (or path) of the Python script being executed.
* **`sys.argv[1]`:** The first command-line argument passed by the user.
* **`sys.argv[2]`:** The second command-line argument, and so on.
* **`sys.argv[1:]`:** A slice containing all user-supplied arguments (excluding the script name).

```text
Command:   python deploy.py staging 8080
                  │         │       │
Index:     sys.argv[0]  sys.argv[1] sys.argv[2]
```

---

## 3. Basic Usage Example

### Script (`greet.py`)
```python
import sys

print(f"Script Name: {sys.argv[0]}")
print(f"All Arguments: {sys.argv}")

if len(sys.argv) > 1:
    print(f"Hello, {sys.argv[1]}!")
```

### Terminal Execution
```bash
python greet.py Vivek
```

### Output
```text
Script Name: greet.py
All Arguments: ['greet.py', 'Vivek']
Hello, Vivek!
```

---

## 4. Type Conversion and Argument Validation

### Converting Numeric Arguments
Because all values in `sys.argv` are strings, cast them explicitly before performing arithmetic:

```python
# calc.py
import sys

if len(sys.argv) != 3:
    print("Usage: python calc.py <num1> <num2>")
    sys.exit(1)  # Exit with a non-zero status code to indicate an error

num1 = int(sys.argv[1])
num2 = int(sys.argv[2])
print(f"Sum: {num1 + num2}")
```

```bash
python calc.py 15 25
# Output: Sum: 40
```

### Preventing `IndexError`
Accessing `sys.argv[1]` when no arguments were provided raises an `IndexError: list index out of range`. Always check `len(sys.argv)` before accessing positional indices.

---

## 5. Passing Arguments with Spaces
By default, the terminal splits arguments on spaces. To pass a multi-word value as a single argument, enclose it in quotes:

```bash
python greet.py "Vivek Singh"
# sys.argv -> ['greet.py', 'Vivek Singh']
```

---

## 6. `sys.argv` vs. `argparse`

| Feature | `sys.argv` | `argparse` (Standard Library) |
| :--- | :--- | :--- |
| **Complexity** | Lightweight and minimal setup | Structured parser with extra boilerplate |
| **Argument Parsing** | Manual positional indexing (`sys.argv[1]`) | Supports named flags (`--port 8080`), defaults, and positional args |
| **Type Conversion** | Manual (`int()`, `float()`) | Automatic via `type=int` |
| **Help Messages** | Must be written manually | Auto-generates `--help` / `-h` documentation |
| **Best Use Case** | Simple scripts accepting 1–3 positional inputs | Production CLI tools with optional flags and validation |
