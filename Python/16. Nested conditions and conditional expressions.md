# Nested Conditions and Conditional Expressions

## 1. Overview
Python provides two structured ways to handle dependent or compact decision-making logic:
* **Nested Conditions:** Placing one or more `if`, `elif`, or `else` blocks inside an outer conditional block to evaluate secondary criteria only after an initial condition passes.
* **Conditional Expressions (Ternary Operator):** A single-line expression that evaluates a condition and returns one of two values based on the result.

---

## 2. Nested Conditions
A nested conditional occurs when an inner decision depends on the outcome of an outer decision. Python determines which block each statement belongs to strictly through **indentation levels** (4 spaces per level).

### Example
```python
is_authenticated = True
role = "Trainer"

if is_authenticated:
    if role == "Admin":
        print("Access: Full system control.")
    elif role == "Trainer":
        print("Access: Batch management and grading.")
    else:
        print("Access: Read-only trainee view.")
else:
    print("Access denied: Please log in first.")
```

### Refactoring Deeply Nested Conditions
Deeply nested blocks (often called the "arrow anti-pattern") become hard to read and maintain. You can flatten nested conditions using two common techniques:

#### A. Combining Conditions with Logical Operators
When inner blocks do not require separate `else` branches, combine conditions using `and`:
```python
# Nested version
if age >= 18:
    if has_valid_id:
        print("Entry permitted.")

# Flattened version
if age >= 18 and has_valid_id:
    print("Entry permitted.")
```

#### B. Using Guard Clauses (Early Return)
Inside functions, handle invalid or edge cases first and exit early to keep the primary logic at the top indentation level:
```python
def submit_assignment(is_logged_in: bool, file_attached: bool) -> str:
    if not is_logged_in:
        return "Error: User not logged in."
    if not file_attached:
        return "Error: No file attached."

    return "Assignment submitted successfully."
```

## 3. Conditional Expressions (Ternary Operator)
A **conditional expression** selects between two values in a single line based on a boolean condition.

### Syntax
```python
<value_if_true> if <condition> else <value_if_false>
```

### Key Characteristics
* **Evaluates to a Value:** Unlike a standard `if-else` statement (which controls execution flow), a conditional expression produces a value and can be used anywhere an expression is expected—such as assignments, `return` statements, function arguments, and f-strings.
* **Mandatory `else` Clause:** Both the `if` and `else` branches are required; omitting `else` raises a `SyntaxError`.
* **Short-Circuit Evaluation:** Python evaluates the condition first and only executes the branch that corresponds to the outcome.

### Examples
```python
# 1. Variable assignment
score = 84
result = "Pass" if score >= 60 else "Fail"
print(result)  # Pass

# 2. Directly inside an f-string
items_count = 1
print(f"You have {items_count} {'item' if items_count == 1 else 'items'}.")

# 3. Inside a return statement
def get_discount(is_member: bool) -> float:
    return 0.15 if is_member else 0.0
```

---

## 4. Nested Conditional Expressions
Conditional expressions can be chained together to evaluate multiple conditions inline. Because conditional expressions are **right-associative**, parentheses are recommended to make the evaluation order clear.

```python
num = -5

label = "Positive" if num > 0 else ("Negative" if num < 0 else "Zero")
print(label)  # Negative
```

*(Note: While valid, nesting more than two conditional expressions hurts readability. Use a standard `if-elif-else` block when evaluating three or more conditions.)*

---

## 5. Comparison and Best Practices

| Feature | Standard `if-else` Statement | Conditional Expression |
| :--- | :--- | :--- |
| **Classification** | Control-flow statement | Expression (returns a value) |
| **Syntax** | Multi-line indented blocks | Single-line inline syntax |
| **`else` branch** | Optional | Mandatory |
| **Multiple statements** | Supported inside each block | Not supported (single expressions only) |
| **Best use case** | Complex logic or executing actions | Simple value selection and assignments |

### Guidelines
* **Keep nesting shallow:** Limit nested `if` blocks to 2 levels whenever possible.
* **Use ternary expressions only for values:** Avoid placing function calls with side effects (like `print()` or database writes) inside conditional expressions—use a standard `if-else` block instead.
