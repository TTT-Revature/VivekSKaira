# Nested Dictionaries and Data Structures

## 1. Overview
**Nested data structures** are collections placed inside other collections—such as dictionaries inside dictionaries, lists of dictionaries, or dictionaries containing lists, tuples, and sets.

* **Purpose:** Models real-world hierarchical, multi-dimensional, or semi-structured data (such as JSON API responses, configuration files, database records, and graph adjacency lists).
* **Flexibility:** Any Python collection can hold other collections as values, provided **dictionary keys** and **set elements** remain immutable/hashable.

---

## 2. Common Nested Patterns

### 1. Dictionary of Dictionaries
Useful for representing keyed records or multi-level configurations where each entry has a unique identifier:
```python
trainees = {
    "FDE-101": {
        "name": "Vivek",
        "age": 23,
        "scores": {"Python": 92, "SQL": 88}
    },
    "FDE-102": {
        "name": "Priya",
        "age": 22,
        "scores": {"Python": 95, "SQL": 91}
    }
}
```

### 2. List of Dictionaries
The standard structure for representing tabular rows or JSON arrays of records:
```python
submissions = [
    {"id": 1, "module": "Python Basics", "status": "Completed"},
    {"id": 2, "module": "Regular Expressions", "status": "Completed"},
    {"id": 3, "module": "Data Structures", "status": "In Progress"}
]
```

### 3. Dictionary of Lists, Sets, or Tuples
Useful for grouping multiple items under a single key (e.g., tags, roles, or coordinates):
```python
batch_curriculum = {
    "Week 1": ["Syntax", "Data Types", "Control Flow"],
    "Week 2": ["Strings", "Regex", "Lists", "Tuples"],
    "allowed_extensions": {".py", ".md", ".sql"},
    "hq_coordinates": (28.6139, 77.2090)
}
```

## 3. Accessing Nested Elements

### Chained Indexing
Chain square brackets `[]` from the outermost container inward to reach the target value:
```python
print(trainees["FDE-101"]["name"])             # 'Vivek'
print(trainees["FDE-101"]["scores"]["Python"]) # 92
print(submissions[1]["module"])                # 'Regular Expressions'
print(batch_curriculum["Week 2"][1])           # 'Regex'
```

### Safe Nested Lookup with `.get()`
Chained bracket lookups (`d["a"]["b"]`) raise a `KeyError` if any intermediate key is missing (or a `TypeError` if an intermediate value is `None`). Chain `.get()` with an empty dictionary `{}` as the fallback for intermediate levels:
```python
# Unsafe: raises KeyError if 'FDE-999' or 'Git' does not exist
# score = trainees["FDE-999"]["scores"]["Git"]

# Safe: returns None (or custom default) without crashing
git_score = trainees.get("FDE-999", {}).get("scores", {}).get("Git", "Not Evaluated")
print(git_score)  # 'Not Evaluated'
```

## 4. Modifying, Adding, and Deleting Nested Data

```python
company = {
    "engineering": {
        "lead": "Amit",
        "team": ["Vivek", "Sneha"]
    }
}

# 1. Update an existing nested value
company["engineering"]["lead"] = "Rahul"

# 2. Mutate an inner list using list methods
company["engineering"]["team"].append("Karan")

# 3. Add a new nested dictionary entry
company["devops"] = {"lead": "Neha", "team": ["Rohan"]}

# 4. Delete a nested key
del company["devops"]["team"]
removed_lead = company["devops"].pop("lead")

print(company)
# Output: {'engineering': {'lead': 'Rahul', 'team': ['Vivek', 'Sneha', 'Karan']}, 'devops': {}}
```

## 5. Iterating Over Nested Structures

### Iterating Over a Dictionary of Dictionaries
Use `.items()` at both outer and inner levels to unpack keys and nested dictionaries cleanly:
```python
trainees = {
    "FDE-101": {"name": "Vivek", "track": "Python", "score": 92},
    "FDE-102": {"name": "Priya", "track": "SQL", "score": 95}
}

for trainee_id, details in trainees.items():
    print(f"ID: {trainee_id}")
    for key, value in details.items():
        print(f"  {key}: {value}")
```

### Iterating Over a List of Dictionaries
```python
tasks = [
    {"topic": "Tuples", "done": True},
    {"topic": "Sets", "done": True},
    {"topic": "Dictionaries", "done": False}
]

for task in tasks:
    if not task["done"]:
        print(f"Pending topic: {task['topic']}")
# Output: Pending topic: Dictionaries
```

## 6. Copying Nested Data Structures
Because `.copy()` only performs a **shallow copy**, inner dictionaries and lists remain shared between the original and the copy. Always use `copy.deepcopy()` when duplicating nested structures:

```python
import copy

original = {"user": "Vivek", "skills": ["Python", "SQL"]}

shallow = original.copy()
deep = copy.deepcopy(original)

shallow["skills"].append("Git")  # Mutates inner list in BOTH 'original' and 'shallow'
deep["skills"].append("Docker")  # Mutates inner list ONLY in 'deep'

print(original["skills"])  # ['Python', 'SQL', 'Git']
print(deep["skills"])      # ['Python', 'SQL', 'Docker']
```

## 7. Quick Reference

| Structure Pattern | Example Layout | Access Syntax | Best Use Case |
| :--- | :--- | :--- | :--- |
| **Dict of Dicts** | `{"u1": {"age": 23}}` | `data["u1"]["age"]` | Keyed records, hierarchical configs |
| **List of Dicts** | `[{"id": 1}, {"id": 2}]` | `data[0]["id"]` | Database rows, JSON API response arrays |
| **Dict of Lists** | `{"tags": ["py", "sql"]}` | `data["tags"][0]` | One-to-many groupings, adjacency lists |
| **Safe Nested Read** | `data.get("a", {}).get("b")` | Returns `None` if missing | Avoiding `KeyError` on optional fields |
| **Independent Clone** | `copy.deepcopy(data)` | Creates full recursive copy | Preventing shared inner mutations |
