# List Methods and Sorting

## 1. Overview
Because Python lists are **mutable**, most built-in list methods modify the list **in place** and return `None` rather than returning a new list.

```python
# Common pitfall: assigning the return value of an in-place method
nums = [3, 1, 2]
result = nums.append(4)

print(nums)    # [3, 1, 2, 4] (modified in place)
print(result)  # None
```

---

## 2. Adding Elements

### `.append(item)`
Adds a **single element** to the very end of the list.
```python
modules = ["Python", "SQL"]
modules.append("Git")
print(modules)  # ['Python', 'SQL', 'Git']
```

### `.insert(index, item)`
Inserts an element at a specific `index`, shifting existing elements to the right.
```python
modules = ["Python", "Git"]
modules.insert(1, "SQL")
print(modules)  # ['Python', 'SQL', 'Git']
```

### `.extend(iterable)`
Unpacks an iterable (such as another `list`, `tuple`, or `set`) and appends each of its elements individually to the end of the list.
```python
a = [1, 2]
b = [3, 4]

a.extend(b)
print(a)  # [1, 2, 3, 4]

# Compare with .append(b), which adds the entire list as a single nested element:
# [1, 2, [3, 4]]
```

---

## 3. Removing Elements

### `.remove(value)`
Removes the **first occurrence** of `value` from the list. Raises a `ValueError` if the value is not present.
```python
tools = ["Git", "Docker", "Git", "AWS"]
tools.remove("Git")
print(tools)  # ['Docker', 'Git', 'AWS']
```

### `.pop([index])`
Removes and **returns** the element at `index`. If no index is specified, it removes and returns the **last element** (`index=-1`). Raises an `IndexError` if the list is empty or the index is out of range.
```python
tasks = ["Setup", "Code", "Test"]

last_task = tasks.pop()
print(last_task)  # 'Test'
print(tasks)      # ['Setup', 'Code']

first_task = tasks.pop(0)
print(first_task) # 'Setup'
print(tasks)      # ['Code']
```

### `.clear()`
Removes all elements from the list in place, leaving an empty list `[]`.
```python
temp = [10, 20, 30]
temp.clear()
print(temp)  # []
```

---

## 4. Searching, Counting, and Copying

### `.index(value[, start[, end]])`
Returns the zero-based index of the **first occurrence** of `value`. Raises a `ValueError` if not found.
```python
scores = [85, 92, 78, 92]
print(scores.index(92))     # 1
print(scores.index(92, 2))  # 3 (starts searching from index 2)
```

### `.count(value)`
Returns the total number of times `value` appears in the list (returns `0` if absent).
```python
scores = [85, 92, 78, 92, 92]
print(scores.count(92))  # 3
print(scores.count(50))  # 0
```

### `.copy()`
Returns a **shallow copy** of the list (equivalent to `list[:]`), so modifying top-level elements in the copy does not affect the original list.
```python
original = [1, 2, 3]
cloned = original.copy()

cloned.append(4)
print(original)  # [1, 2, 3]
print(cloned)    # [1, 2, 3, 4]
```

## 5. Reversing Lists

### `.reverse()` vs. `reversed()`
* **`list.reverse()`:** Reverses the elements of the list **in place** and returns `None`.
* **`reversed(sequence)`:** Built-in function that leaves the original list unchanged and returns a reverse iterator (wrap in `list()` to materialize it).

```python
nums = [10, 20, 30]

# 1. In-place reversal
nums.reverse()
print(nums)  # [30, 20, 10]

# 2. Non-destructive reversal
rev_copy = list(reversed(nums))
print(rev_copy)  # [10, 20, 30]
print(nums)      # [30, 20, 10] (unchanged)
```

## 6. Sorting Lists: `.sort()` vs. `sorted()`
Python provides two ways to sort elements in ascending order by default:

| Feature | `list.sort()` | `sorted(iterable)` |
| :--- | :--- | :--- |
| **Behavior** | Modifies the existing list **in place** | Leaves original unchanged; returns a **new list** |
| **Return Value** | `None` | A new sorted `list` |
| **Supported Inputs** | Lists (`list`) only | Any iterable (`list`, `tuple`, `str`, `set`, `dict`) |

### Ascending and Descending Order (`reverse=True`)
```python
marks = [78, 95, 62, 88]

# 1. sorted() creates a new list
asc_marks = sorted(marks)
print(asc_marks)  # [62, 78, 88, 95]
print(marks)      # [78, 95, 62, 88] (original untouched)

# 2. .sort() mutates the list directly
marks.sort(reverse=True)
print(marks)      # [95, 88, 78, 62]
```

### Custom Sorting with the `key` Parameter
Both `.sort()` and `sorted()` accept a `key` function that transforms each element into a comparison value before sorting:

```python
# 1. Sort strings by length
words = ["Python", "SQL", "Docker", "Go"]
print(sorted(words, key=len))
# Output: ['Go', 'SQL', 'Python', 'Docker']

# 2. Case-insensitive alphabetical sort
names = ["vivek", "Amit", "sneha", "Rahul"]
print(sorted(names, key=str.lower))
# Output: ['Amit', 'Rahul', 'sneha', 'vivek']

# 3. Sort a list of tuples by the second element (score)
records = [("Amit", 82), ("Vivek", 94), ("Priya", 89)]
records.sort(key=lambda item: item[1], reverse=True)
print(records)
# Output: [('Vivek', 94), ('Priya', 89), ('Amit', 82)]
```

*(Note: All elements being compared during sorting must be mutually comparable; sorting a mixed list like `[10, "Python"]` raises a `TypeError`.)*

## 7. Quick Reference

| Method / Function | Action | Modifies In Place? | Return Value |
| :--- | :--- | :--- | :--- |
| `lst.append(x)` | Adds `x` to the end | Yes | `None` |
| `lst.insert(i, x)` | Inserts `x` at index `i` | Yes | `None` |
| `lst.extend(iter)` | Appends all items from `iter` | Yes | `None` |
| `lst.remove(x)` | Removes first occurrence of `x` | Yes | `None` |
| `lst.pop([i])` | Removes item at index `i` (default last) | Yes | Removed item |
| `lst.clear()` | Removes all elements | Yes | `None` |
| `lst.index(x)` | Finds first index of `x` | No | `int` |
| `lst.count(x)` | Counts occurrences of `x` | No | `int` |
| `lst.copy()` | Creates a shallow copy | No | New `list` |
| `lst.reverse()` | Reverses element order | Yes | `None` |
| `lst.sort(key=..., reverse=...)` | Sorts elements | Yes | `None` |
| `sorted(iter, key=..., reverse=...)` | Returns sorted copy of any iterable | No | New `list` |
