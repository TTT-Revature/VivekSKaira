# `*args` and `**kwargs`

## 1. Overview
In Python, **`*args`** and **`**kwargs`** allow a function to accept a **variable (arbitrary) number of arguments** without hardcoding a fixed parameter list in advance.

* **`*args` (Arbitrary Positional Arguments):** Packs any number of extra positional arguments into a **`tuple`**.
* **`**kwargs` (Arbitrary Keyword Arguments):** Packs any number of extra keyword (`key=value`) arguments into a **`dict`**.
* **Naming Convention:** The words `args` and `kwargs` are strong PEP 8 conventions, not reserved keywords. The actual functionality comes from the **`*`** and **`**`** operators (e.g., `*numbers` or `**options` works identically).

---

## 2. `*args` (Arbitrary Positional Arguments)
Placing a single asterisk `*` before a parameter name in a function definition collects all unmatched positional arguments into a **`tuple`**.

### Basic Example
```python
def calculate_total(*numbers: float) -> float:
    print(f"Received tuple: {numbers} | Type: {type(numbers)}")
    return sum(numbers)

print(calculate_total(10, 20))           # 30
print(calculate_total(5, 15, 25, 35))    # 80
print(calculate_total())                 # 0 (empty tuple ())
```

### Combining Required Parameters with `*args`
Standard positional parameters must be placed **before** `*args`:
```python
def log_scores(trainee_name: str, *scores: int) -> None:
    avg = sum(scores) / len(scores) if scores else 0.0
    print(f"Trainee: {trainee_name} | Scores: {scores} | Average: {avg:.2f}")

log_scores("Vivek", 88, 92, 95)
# Output: Trainee: Vivek | Scores: (88, 92, 95) | Average: 91.67
```
*(Note: Any parameter placed **after** `*args` automatically becomes a **keyword-only parameter** and must be passed by name.)*

---

## 3. `**kwargs` (Arbitrary Keyword Arguments)
Placing a double asterisk `**` before a parameter name in a function definition collects all unmatched keyword arguments into a **`dict`**, where keys are parameter names (`str`) and values are the passed arguments.

### Basic Example
```python
def print_metadata(**details) -> None:
    print(f"Received dict: {details} | Type: {type(details)}")
    for key, value in details.items():
        print(f"  {key}: {value}")

print_metadata(module="Functions", day=5, completed=True)
# Output:
# Received dict: {'module': 'Functions', 'day': 5, 'completed': True} | Type: <class 'dict'>
#   module: Functions
#   day: 5
#   completed: True
```

### Combining Required Parameters with `**kwargs`
`**kwargs` must always be the **very last parameter** in a function signature:
```python
def create_user(username: str, role: str = "Trainee", **extra_fields) -> dict:
    profile = {"username": username, "role": role}
    profile.update(extra_fields)
    return profile

user = create_user("vivek_k", batch="FDE-01", location="India", active=True)
print(user)
# Output: {'username': 'vivek_k', 'role': 'Trainee', 'batch': 'FDE-01', 'location': 'India', 'active': True}
```

## 4. Combining Standard Parameters, `*args`, and `**kwargs`
When using all parameter types together in one function, Python enforces a strict left-to-right order:

```python
def full_signature(required, default_val="N/A", *args, kw_only=True, **kwargs):
    print(f"required    = {required}")
    print(f"default_val = {default_val}")
    print(f"args        = {args}")
    print(f"kw_only     = {kw_only}")
    print(f"kwargs      = {kwargs}")

full_signature("Python", "Core", 101, 102, kw_only=False, topic="Args", difficulty="Medium")
# Output:
# required    = Python
# default_val = Core
# args        = (101, 102)
# kw_only     = False
# kwargs      = {'topic': 'Args', 'difficulty': 'Medium'}
```

### Summary of Signature Order
1. Standard positional-or-keyword parameters (non-default first, then default)
2. `*args` (collects remaining positional arguments)
3. Keyword-only parameters (placed after `*args`)
4. `**kwargs` (collects remaining keyword arguments)

---

## 5. Packing vs. Unpacking (`*` and `**` in Function Calls)
The `*` and `**` operators perform opposite actions depending on where they appear:

* **In Function Definition (`def f(*args, **kwargs)`):** **Packs** multiple incoming arguments into a `tuple` and `dict`.
* **In Function Call (`f(*seq, **mapping)`):** **Unpacks** an existing iterable or dictionary into separate positional and keyword arguments.

```python
def deploy_app(host: str, port: int, env: str, debug: bool) -> None:
    print(f"Deploying to {host}:{port} [env={env}, debug={debug}]")

# 1. Unpacking a list or tuple with * (positional arguments)
server_args = ["127.0.0.1", 8080]

# 2. Unpacking a dictionary with ** (keyword arguments; keys must match parameter names)
server_kwargs = {"env": "staging", "debug": True}

# Combine both in a single call
deploy_app(*server_args, **server_kwargs)
# Output: Deploying to 127.0.0.1:8080 [env=staging, debug=True]
```

## 6. Common Real-World Use Cases

### 1. Argument Forwarding in Wrapper Functions and Decorators
`*args` and `**kwargs` allow wrapper functions to forward all arguments transparently to an underlying function without needing to know its exact signature:

```python
def trace_call(func, *args, **kwargs):
    print(f"[CALL] Executing {func.__name__} with args={args}, kwargs={kwargs}")
    result = func(*args, **kwargs)
    print(f"[DONE] Result: {result}")
    return result

def multiply(a: int, b: int, scale: int = 1) -> int:
    return a * b * scale

trace_call(multiply, 4, 5, scale=2)
# Output:
# [CALL] Executing multiply with args=(4, 5), kwargs={'scale': 2}
# [DONE] Result: 40
```

### 2. Forwarding Arguments in Class Inheritance (`super()`)
Subclasses frequently accept `*args, **kwargs` in `__init__` to pass parent configuration parameters cleanly to `super().__init__(*args, **kwargs)`.

---

## 7. Quick Reference

| Syntax | Context | Action | Data Structure / Result |
| :--- | :--- | :--- | :--- |
| `def f(*args):` | Function definition | Packs extra positional arguments | `args` is a `tuple` |
| `def f(**kwargs):` | Function definition | Packs extra keyword arguments | `kwargs` is a `dict` |
| `f(*iterable)` | Function call | Unpacks sequence items as positional arguments | Individual positional arguments |
| `f(**dictionary)` | Function call | Unpacks `key: value` pairs as keyword arguments | Individual `key=value` arguments |
| `def f(a, *args, b, **kwargs):` | Combined signature | Enforces standard parameter ordering | `b` is keyword-only; `**kwargs` is last |
