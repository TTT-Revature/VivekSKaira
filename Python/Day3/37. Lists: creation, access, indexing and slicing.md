# Lists: Creation, Access, Indexing, and Slicing

## 1. Overview
A **list (`list`)** is Python's primary built-in sequence collection used to store multiple items in a single variable.

* **Ordered:** Elements maintain the exact order in which they are inserted.
* **Mutable:** Elements can be added, modified, or removed in place after creation without creating a new list object.
* **Heterogeneous:** A single list can hold items of different data types (integers, strings, floats, booleans, or even other lists).
* **Allows Duplicates:** Identical values can appear multiple times at different positions.

---

## 2. Creating Lists

### Using Square Brackets `[]`
```python
# 1. Empty list
empty_list = []

# 2. List of homogeneous items
modules = ["Python", "SQL", "Git", "Docker"]
scores = [85, 90, 78, 92]

# 3. List of mixed (heterogeneous) data types
trainee = ["Vivek", 23, "FDE", True]

# 4. Nested list (2D list / matrix)
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]
```

### Using the `list()` Constructor
Converts any iterable (such as a `str`, `tuple`, `set`, or `range`) into a new list:
```python
from_string = list("FDE")          # ['F', 'D', 'E']
from_range = list(range(1, 6))     # [1, 2, 3, 4, 5]
from_tuple = list((10, 20, 30))    # [10, 20, 30]
```

### Initializing with Repetition (`*`)
```python
zeros = [0] * 5                    # [0, 0, 0, 0, 0]
```

## 3. Accessing Elements (Indexing)
Lists use **zero-based indexing** from the left (`0`, `1`, `2`, ...) and **negative indexing** from the right (`-1`, `-2`, ...).

```text
List:       [ "Python",  "SQL",  "Git",  "Docker" ]
Positive:         0        1       2        3
Negative:        -4       -3      -2       -1
```

### Single-Level Indexing
```python
tools = ["Python", "SQL", "Git", "Docker"]

print(tools[0])    # 'Python' (first element)
print(tools[2])    # 'Git'    (third element)
print(tools[-1])   # 'Docker' (last element)
print(tools[-2])   # 'Git'    (second-to-last element)
```

### Accessing Nested List Elements
Chain multiple square brackets `[][]` to drill down into inner lists:
```python
grid = [
    ["A1", "A2", "A3"],
    ["B1", "B2", "B3"]
]

print(grid[0])      # ['A1', 'A2', 'A3'] (first inner list)
print(grid[0][1])   # 'A2'               (row 0, column 1)
print(grid[1][-1])  # 'B3'               (row 1, last column)
```
*(Note: Accessing an index outside `-len(lst)` to `len(lst) - 1` raises an `IndexError: list index out of range`.)*

## 4. Modifying Elements via Index (Mutability)
Because lists are mutable, you can reassign individual elements directly at any valid index:

```python
languages = ["Python", "Java", "C++"]

languages[1] = "SQL"
print(languages)  # ['Python', 'SQL', 'C++']

languages[-1] = "Go"
print(languages)  # ['Python', 'SQL', 'Go']
```

## 5. List Slicing
Slicing extracts a subset of elements using `list[start:stop:step]` and returns a **new list** without modifying the original list.

* **`start` (inclusive):** Beginning index (defaults to `0`).
* **`stop` (exclusive):** Ending index; the item at `stop` is excluded (defaults to `len(list)`).
* **`step` (optional):** Interval between items (defaults to `1`).

### Extracting Sub-Lists
```python
nums = [10, 20, 30, 40, 50, 60]

print(nums[1:4])     # [20, 30, 40]        (indices 1 through 3)
print(nums[:3])      # [10, 20, 30]        (first 3 elements)
print(nums[3:])      # [40, 50, 60]        (from index 3 to the end)
print(nums[-2:])     # [50, 60]            (last 2 elements)
print(nums[::2])     # [10, 30, 50]        (every 2nd element)
print(nums[::-1])    # [60, 50, 40, 30, 20, 10] (reversed copy)
print(nums[:])       # [10, 20, 30, 40, 50, 60] (shallow copy of the list)
```

### Modifying Lists with Slice Assignment
Because lists are mutable, you can replace, insert, or delete ranges of elements in place by assigning an iterable to a slice:

```python
items = ["a", "b", "c", "d", "e"]

# 1. Replace a slice (replacement does not need to be the same length)
items[1:3] = ["X", "Y", "Z"]
print(items)  # ['a', 'X', 'Y', 'Z', 'd', 'e']

# 2. Delete a slice
items[1:4] = []
print(items)  # ['a', 'd', 'e']
```

## 6. Basic List Operations

```python
a = [1, 2, 3]
b = [4, 5]

# Length of a list
print(len(a))         # 3

# Membership check
print(2 in a)         # True
print(9 not in a)     # True

# Concatenation (+) and Repetition (*)
print(a + b)          # [1, 2, 3, 4, 5]
print(b * 2)          # [4, 5, 4, 5]

# Iterating over elements
for item in a:
    print(item, end=" ")  # 1 2 3
```

## 7. Quick Reference

| Syntax / Operation | Description | Example (`lst = [10, 20, 30, 40]`) | Result |
| :--- | :--- | :--- | :--- |
| `[]` / `list(iter)` | Creates an empty or converted list | `list("AB")` | `['A', 'B']` |
| `len(lst)` | Returns the number of elements | `len(lst)` | `4` |
| `lst[i]` | Accesses element at index `i` | `lst[1]`, `lst[-1]` | `20`, `40` |
| `lst[i] = val` | Updates element at index `i` in place | `lst[0] = 99` | `[99, 20, 30, 40]` |
| `lst[a:b]` | Returns new slice from `a` up to `b - 1` | `lst[1:3]` | `[20, 30]` |
| `lst[::-1]` | Returns a reversed copy of the list | `lst[::-1]` | `[40, 30, 20, 10]` |
| `lst[:]` | Creates a shallow copy of the list | `copy_lst = lst[:]` | `[10, 20, 30, 40]` |
| `x in lst` | Checks whether `x` exists in `lst` | `30 in lst` | `True` |
