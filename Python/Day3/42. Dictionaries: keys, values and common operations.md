# Dictionaries: Keys, Values, and Common Operations

## 1. Overview
A **dictionary (`dict`)** is Python's built-in mapping collection used to store data as **`key: value` pairs**.

* **Ordered:** Preserves the exact order in which keys are inserted (guaranteed since Python 3.7+).
* **Mutable:** Key-value pairs can be added, updated, or removed in place after creation.
* **Unique & Hashable Keys:** Every key in a dictionary must be unique and immutable/hashable (`str`, `int`, `float`, `bool`, or `tuple` of immutables). Mutable types like `list`, `set`, or `dict` cannot be used as keys.
* **Flexible Values:** Values can be of **any data type** (including lists, sets, or nested dictionaries) and can contain duplicates.
* **Fast Lookup:** Backed by a hash table, retrieving, inserting, or deleting a key runs in average $O(1)$ constant time.

---

## 2. Creating Dictionaries

### Standard Literal Syntax `{}` and `dict()`
```python
# 1. Empty dictionary
empty_dict = {}
also_empty = dict()

# 2. Dictionary literal with key-value pairs
trainee = {
    "name": "Vivek",
    "age": 23,
    "track": "FDE",
    "skills": ["Python", "SQL", "Git"]
}

# 3. Using dict() with keyword arguments (keys must be valid identifiers)
config = dict(host="localhost", port=8080, debug=True)

# 4. Using dict() from an iterable of (key, value) pairs
pairs = [("a", 1), ("b", 2), ("c", 3)]
from_pairs = dict(pairs)  # {'a': 1, 'b': 2, 'c': 3}
```

### Initializing Default Values with `dict.fromkeys()`
Creates a new dictionary from an iterable of keys, setting all keys to a shared default value (`None` if omitted):
```python
modules = ["Python", "SQL", "Git"]
status = dict.fromkeys(modules, "Pending")
print(status)
# Output: {'Python': 'Pending', 'SQL': 'Pending', 'Git': 'Pending'}
```
*(Caution: Avoid passing a mutable object like `[]` as the default value in `fromkeys()`, as all keys will reference the exact same list instance.)*

## 3. Rules for Keys and Values

```python
# 1. Duplicate keys overwrite earlier entries
scores = {"Python": 80, "SQL": 85, "Python": 92}
print(scores)  # {'Python': 92, 'SQL': 85}

# 2. Tuples of immutable items are valid keys (e.g., grid coordinates)
locations = {(28.61, 77.20): "New Delhi", (19.07, 72.87): "Mumbai"}

# 3. Mutable types as keys raise TypeError
# invalid = {[1, 2]: "value"}  # TypeError: unhashable type: 'list'
```

## 4. Accessing, Adding, and Updating Items

### Accessing Values: `d[key]` vs. `d.get(key)`
* **`d[key]`:** Direct lookup; raises a **`KeyError`** if `key` does not exist.
* **`d.get(key, default=None)`:** Safe lookup; returns `default` (or `None`) if `key` is missing instead of raising an error.

```python
user = {"username": "vivek_k", "role": "Trainee"}

print(user["username"])               # 'vivek_k'
# print(user["email"])                # Raises KeyError: 'email'

print(user.get("email"))              # None
print(user.get("email", "N/A"))       # 'N/A'
```

### Adding and Updating Pairs
```python
profile = {"name": "Vivek", "score": 85}

# Add a new key-value pair
profile["batch"] = "FDE-01"

# Update an existing key's value
profile["score"] = 92
print(profile)  # {'name': 'Vivek', 'score': 92, 'batch': 'FDE-01'}
```

### `.setdefault(key, default)`
If `key` is already in the dictionary, returns its current value. If `key` is missing, inserts `key` with `default` and returns `default`:
```python
settings = {"theme": "dark"}

print(settings.setdefault("theme", "light"))  # 'dark' (existing value kept)
print(settings.setdefault("font_size", 14))   # 14 (inserted into dictionary)
print(settings)  # {'theme': 'dark', 'font_size': 14}
```

### Merging Dictionaries: `.update()` and `|` Operators
```python
base = {"a": 1, "b": 2}
extra = {"b": 20, "c": 3}

# 1. Merge operator (|) -> returns a new merged dictionary (Python 3.9+)
merged = base | extra
print(merged)  # {'a': 1, 'b': 20, 'c': 3}

# 2. In-place update using .update() or |=
base.update(extra)  # Equivalent to: base |= extra
print(base)    # {'a': 1, 'b': 20, 'c': 3}
```

## 5. Removing Items

* **`del d[key]`:** Deletes the key-value pair in place. Raises `KeyError` if `key` is missing.
* **`d.pop(key[, default])`:** Removes `key` and **returns its value**. Raises `KeyError` if missing and no `default` is supplied.
* **`d.popitem()`:** Removes and returns the **last inserted `(key, value)` tuple** (LIFO order). Raises `KeyError` if the dictionary is empty.
* **`d.clear()`:** Removes all items from the dictionary, leaving `{}`.

```python
tasks = {"t1": "Setup", "t2": "Code", "t3": "Test", "t4": "Deploy"}

del tasks["t1"]
removed_val = tasks.pop("t2")         # 'Code'
safe_val = tasks.pop("t9", "Missing") # 'Missing' (no error)
last_pair = tasks.popitem()           # ('t4', 'Deploy')

print(tasks)                          # {'t3': 'Test'}
tasks.clear()
print(tasks)                          # {}
```

## 6. Dictionary Views and Iteration
Python provides three dynamic **view objects** that automatically reflect changes made to the dictionary:

* **`d.keys()`:** Returns a `dict_keys` view of all keys.
* **`d.values()`:** Returns a `dict_values` view of all values.
* **`d.items()`:** Returns a `dict_items` view of `(key, value)` tuples.

```python
marks = {"Python": 92, "SQL": 88, "Git": 95}

# 1. Iterating over keys (default iteration behavior)
for subject in marks:
    print(subject)

# 2. Iterating over values
for score in marks.values():
    print(score)

# 3. Iterating over key-value pairs using tuple unpacking
for subject, score in marks.items():
    print(f"{subject}: {score}")

# 4. Membership checks
print("SQL" in marks)             # True  (checks keys in O(1) time)
print(88 in marks.values())       # True  (checks values in O(n) time)
```

## 7. Quick Reference

| Syntax / Method | Description | Example (`d = {'a': 1, 'b': 2}`) | Result |
| :--- | :--- | :--- | :--- |
| `d[k]` | Retrieves value for `k` (`KeyError` if absent) | `d['a']` | `1` |
| `d.get(k, default)` | Retrieves value for `k` or returns `default` | `d.get('x', 0)` | `0` |
| `d[k] = v` | Inserts or updates key `k` with value `v` | `d['c'] = 3` | `{'a': 1, 'b': 2, 'c': 3}` |
| `d.setdefault(k, v)` | Returns `d[k]` if present, else sets `d[k] = v` | `d.setdefault('b', 9)` | `2` |
| `d.update(other)` | Updates `d` in place with pairs from `other` | `d.update({'b': 5})` | `{'a': 1, 'b': 5}` |
| `d1 \| d2` | Returns a new dictionary merging `d1` and `d2` | `{'a': 1} \| {'b': 2}` | `{'a': 1, 'b': 2}` |
| `d.pop(k[, default])` | Removes `k` and returns its value | `d.pop('a')` | `1` |
| `d.popitem()` | Removes and returns last `(key, value)` tuple | `d.popitem()` | `('b', 2)` |
| `del d[k]` | Deletes key `k` in place | `del d['a']` | `{'b': 2}` |
| `d.keys()` / `.values()` / `.items()` | Returns dynamic views of keys, values, or pairs | `list(d.keys())` | `['a', 'b']` |
