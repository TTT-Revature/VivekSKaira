# Set and Dictionary Comprehensions

## 1. Overview
Just like list comprehensions, Python supports **set comprehensions** and **dictionary comprehensions** using curly braces `{}` to build sets and dictionaries in a single, readable expression.

* **Set Comprehension:** `{expression for item in iterable}` — produces a `set` with **unique, unordered** elements.
* **Dictionary Comprehension:** `{key_expr: value_expr for item in iterable}` — produces a `dict` of **`key: value` pairs**.
* **Empty Braces Reminder:** `{}` alone creates an empty dictionary, whereas `{x for x in []}` evaluates to an empty set `set()`.

---

## 2. Set Comprehensions
Set comprehensions transform and filter elements from an iterable while **automatically removing duplicates**.

```python
new_set = {expression for item in iterable if condition}
```

### Basic Transformation and Deduplication
```python
raw_tags = ["Python", "sql", "PYTHON", "Git", "SQL", "docker"]

# Normalize case and automatically eliminate duplicates
unique_tags = {tag.lower() for tag in raw_tags}
print(unique_tags)  # {'python', 'sql', 'git', 'docker'}
```

### Filtering (`if`) and Conditional Mapping (`if-else`)
```python
numbers = [1, 2, 2, 3, 4, 4, 5, 6]

# 1. Filter even numbers and square them
even_squares = {n ** 2 for n in numbers if n % 2 == 0}
print(even_squares)  # {16, 4, 36}

# 2. Conditional expression before 'for'
labels = {"Even" if n % 2 == 0 else "Odd" for n in numbers}
print(labels)        # {'Odd', 'Even'}
```

### Constraint on Elements
Every element generated by `expression` must be **hashable (immutable)** (`int`, `str`, `float`, `tuple`, etc.). Generating unhashable items such as lists raises a `TypeError`:
```python
# Invalid: lists cannot be elements of a set
# bad_set = {[x, x + 1] for x in range(3)}  # TypeError: unhashable type: 'list'

# Valid: tuples of immutables are hashable
pairs_set = {(x, x + 1) for x in range(3)}
print(pairs_set)  # {(0, 1), (1, 2), (2, 3)}
```

## 3. Dictionary Comprehensions
Dictionary comprehensions construct a new `dict` by evaluating both a **key expression** and a **value expression** for each item in an iterable.

```python
new_dict = {key_expr: value_expr for item in iterable if condition}
```

### 1. Building a Dictionary from a Single Iterable
```python
modules = ["Python", "SQL", "Git", "Docker"]

# Map each module name to its character length
name_lengths = {m: len(m) for m in modules}
print(name_lengths)
# Output: {'Python': 6, 'SQL': 3, 'Git': 3, 'Docker': 6}
```

### 2. Pairing Two Iterables with `zip()`
```python
keys = ["name", "track", "batch"]
values = ["Vivek", "FDE", "Batch-01"]

profile = {k: v for k, v in zip(keys, values)}
print(profile)
# Output: {'name': 'Vivek', 'track': 'FDE', 'batch': 'Batch-01'}
```

### 3. Transforming and Filtering an Existing Dictionary
Use `.items()` to unpack keys and values when deriving a new dictionary from an existing one:
```python
scores = {"Python": 92, "SQL": 68, "Git": 88, "Docker": 74}

# Filter entries with scores greater than or equal to 75
passed = {subject: mark for subject, mark in scores.items() if mark >= 75}
print(passed)
# Output: {'Python': 92, 'Git': 88}

# Apply a bonus of 5 points (capped at 100) to all scores
boosted = {subject: min(mark + 5, 100) for subject, mark in scores.items()}
print(boosted)
# Output: {'Python': 97, 'SQL': 73, 'Git': 93, 'Docker': 79}
```

### 4. Conditional Expressions (`if-else`) in Dictionaries
```python
scores = {"Python": 92, "SQL": 68, "Git": 88}

status_map = {
    subject: ("Pass" if mark >= 75 else "Retake")
    for subject, mark in scores.items()
}
print(status_map)
# Output: {'Python': 'Pass', 'SQL': 'Retake', 'Git': 'Pass'}
```

### 5. Inverting a Dictionary (Swapping Keys and Values)
```python
country_codes = {"IN": "India", "US": "United States", "UK": "United Kingdom"}

inverted = {country: code for code, country in country_codes.items()}
print(inverted)
# Output: {'India': 'IN', 'United States': 'US', 'United Kingdom': 'UK'}
```
*(Note: Because dictionary keys must be unique and hashable, inverting a dictionary only works if all original values are hashable; if duplicate values exist, later keys overwrite earlier ones.)*

---

## 4. Comparing Comprehension Delimiters
Each delimiter in Python produces a distinct object type:

* **`[x for x in it]`** -> `list` (ordered, allows duplicates)
* **`{x for x in it}`** -> `set` (unordered, unique hashable items)
* **`{k: v for k, v in it}`** -> `dict` (ordered key-value mapping)
* **`(x for x in it)`** -> `generator` object (lazy iterator, **not** a tuple; use `tuple(x for x in it)` to create a tuple)

---

## 5. Quick Reference

| Comprehension Type | Syntax | Example | Output |
| :--- | :--- | :--- | :--- |
| **Set (Basic)** | `{expr for x in it}` | `{x % 3 for x in range(5)}` | `{0, 1, 2}` |
| **Set (Filtered)** | `{expr for x in it if cond}` | `{c for c in "banana" if c != "a"}` | `{'b', 'n'}` |
| **Dict (From Sequence)** | `{k: v for x in it}` | `{x: x ** 2 for x in [2, 3, 4]}` | `{2: 4, 3: 9, 4: 16}` |
| **Dict (Filtered)** | `{k: v for k, v in d.items() if cond}` | `{k: v for k, v in {'a': 1, 'b': 5}.items() if v >= 3}` | `{'b': 5}` |
| **Dict (Inverted)** | `{v: k for k, v in d.items()}` | `{v: k for k, v in {'a': 1, 'b': 2}.items()}` | `{1: 'a', 2: 'b'}` |
