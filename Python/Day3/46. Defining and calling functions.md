# Defining and Calling Functions

## 1. Overview
A **function** is a named, reusable block of code designed to perform a specific, well-defined task.

* **Modularity:** Breaks large, complex programs into smaller, logical, and manageable units.
* **Reusability (DRY Principle):** Eliminates code duplication ("Don't Repeat Yourself") by letting you write logic once and execute it whenever needed.
* **Abstraction:** Hides internal implementation details behind a clear function name and interface.
* **First-Class Objects:** In Python, functions are objects of type `function`—they can be assigned to variables, stored in data structures, and passed as arguments to other functions.

---

## 2. Defining a Function (`def`)
Functions are defined using the `def` keyword, followed by a valid identifier, parentheses `()`, and a colon `:`. The function body must be indented (4 spaces per PEP 8).

### Syntax
```python
def function_name(parameter1, parameter2):
    """Optional docstring describing what the function does."""
    # Function body (indented block)
    return result
```

### Naming Conventions (PEP 8)
* Use `snake_case` (lowercase words separated by underscores), typically starting with a verb (e.g., `calculate_total`, `fetch_records`, `validate_email`).
* Avoid shadowing built-in function names such as `list`, `sum`, `len`, or `print`.

### Basic Function Definition and Stubs (`pass`)
```python
# 1. Function with no parameters
def greet_batch():
    print("Welcome to the Revature FDE Training Program!")

# 2. Function stub using 'pass' as a placeholder during design
def connect_database():
    pass
```

---

## 3. Calling (Invoking) a Function
Defining a function registers it in memory without executing its body. To run the code inside the function, you **call** (invoke) it by writing its name followed by parentheses `()`.

### Definition-Before-Call Rule
Python executes scripts top-to-bottom. A function **must be defined before it is called**; calling it earlier raises a `NameError`.

```python
# Define the function first
def display_banner():
    print("=== Module 1: Python Functions ===")

# Call the function multiple times
display_banner()
display_banner()
```

### Referencing vs. Calling a Function
* **`func` (without parentheses):** References the function object itself without executing it.
* **`func()` (with parentheses):** Executes the function body and evaluates to its return value.

```python
def say_hello():
    return "Hello, World!"

ref = say_hello        # Assigns the function object to 'ref'
print(type(ref))       # <class 'function'>
print(ref())           # Calls the function -> 'Hello, World!'
```

### Functions Calling Other Functions
Functions can invoke other functions, allowing complex workflows to be composed from smaller helper functions:

```python
def format_header(title):
    return f"--- {title.upper()} ---"

def print_report(module_name, score):
    header = format_header(module_name)
    print(header)
    print(f"Score: {score}/100")

print_report("Python Basics", 94)
# Output:
# --- PYTHON BASICS ---
# Score: 94/100
```

## 4. Parameters vs. Arguments
Although often used interchangeably in casual conversation, the two terms have distinct meanings:

* **Parameter:** The variable name listed inside the parentheses in the function **definition** (`def`).
* **Argument:** The actual value supplied inside the parentheses during a function **call**.

```python
# 'name' and 'track' are PARAMETERS
def introduce(name, track):
    print(f"Trainee: {name} | Track: {track}")

# "Vivek" and "FDE" are ARGUMENTS (passed positionally)
introduce("Vivek", "FDE")

# Arguments can also be passed by keyword name
introduce(track="Data Engineering", name="Priya")
```

## 5. Returning Values (`return`)
The `return` statement exits the function immediately and sends a result back to the caller.

### 1. Returning a Single Value
```python
def calculate_area(length, width):
    area = length * width
    return area

result = calculate_area(8, 5)
print(result)  # 40
```

### 2. Implicit `None` Return
If a function has no `return` statement, or uses a bare `return` with no expression, Python automatically returns **`None`**:
```python
def log_message(msg):
    print(f"[LOG]: {msg}")

output = log_message("Server started")
print(output)  # None
```

### 3. Returning Multiple Values (Tuple Packing)
Separating multiple values with commas in a `return` statement packs them into a **`tuple`**, which the caller can unpack directly:
```python
def get_min_max(numbers):
    return min(numbers), max(numbers)

scores = [78, 92, 85, 64, 96]

# Unpack returned tuple into separate variables
lowest, highest = get_min_max(scores)
print(f"Lowest: {lowest}, Highest: {highest}")
# Output: Lowest: 64, Highest: 96
```

### 4. Early Termination Behavior
Any statements placed after an executed `return` inside the same block are unreachable and will never run:
```python
def check_eligibility(score):
    if score < 75:
        return "Retake Required"  # Exits function immediately
    return "Passed"

print(check_eligibility(68))  # 'Retake Required'
print(check_eligibility(88))  # 'Passed'
```

## 6. Docstrings and Type Annotations
Adding **docstrings (PEP 257)** and **type hints (PEP 484)** makes functions self-documenting and easier to debug and maintain:

```python
def calculate_percentage(obtained: float, total: float) -> float:
    """Calculate the percentage score rounded to two decimal places."""
    if total == 0:
        return 0.0
    return round((obtained / total) * 100, 2)

print(calculate_percentage(87, 100))  # 87.0

# Inspect the docstring at runtime
print(calculate_percentage.__doc__)
# Output: Calculate the percentage score rounded to two decimal places.
```

## 7. Quick Reference

| Concept | Syntax | Behavior |
| :--- | :--- | :--- |
| **Function Definition** | `def func_name(params):` | Creates a function object in the current scope |
| **Function Call** | `func_name(args)` | Executes the function body and evaluates to its return value |
| **Function Reference** | `alias = func_name` | References the function object without executing it |
| **Explicit Return** | `return value` | Exits the function and sends `value` back to the caller |
| **Multiple Return** | `return a, b` | Packs values into a `tuple` `(a, b)` for tuple unpacking |
| **Implicit Return** | *(no `return` statement)* | Automatically returns `None` when the function body finishes |
| **Empty Placeholder** | `pass` | Valid no-op body for functions planned for later implementation |
| **Docstring Access** | `func_name.__doc__` or `help(func_name)` | Displays the function's documentation string |
