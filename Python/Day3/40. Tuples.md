# Tuples

## 1. Overview
A **tuple (`tuple`)** is a built-in Python sequence collection used to store multiple items in a single variable.

* **Ordered:** Elements maintain a fixed insertion order and can be accessed by index.
* **Immutable:** Once created, elements cannot be added, modified, or removed in place.
* **Heterogeneous:** Can store items of different data types (`int`, `str`, `float`, `list`, etc.).
* **Allows Duplicates:** Identical values can appear multiple times.
* **Hashable:** Tuples containing only immutable elements can be used as `dict` keys or stored inside a `set`.

---

## 2. Creating Tuples

### Standard Creation
```python
# 1. Empty tuple
empty_tuple = ()

# 2. Tuple with parentheses
coordinates = (28.6139, 77.2090)
trainee = ("Vivek", 23, "FDE", True)

# 3. Tuple without parentheses (tuple packing)
status_codes = 200, 404, 500
print(type(status_codes))  # <class 'tuple'>

# 4. Nested tuple
matrix = ((1, 2), (3, 4))
```

### Single-Element Tuple (Trailing Comma Rule)
To create a tuple with only one item, you **must include a trailing comma**; otherwise, Python treats the parentheses as standard expression grouping:
```python
not_a_tuple = (42)
print(type(not_a_tuple))   # <class 'int'>

single_tuple = (42,)
print(type(single_tuple))  # <class 'tuple'>
```

### Using the `tuple()` Constructor
Converts any iterable (such as a `list`, `str`, `set`, or `range`) into a tuple:
```python
from_list = tuple(["Python", "SQL", "Git"])  # ('Python', 'SQL', 'Git')
from_str = tuple("FDE")                      # ('F', 'D', 'E')
```

---

## 3. Accessing Elements (Indexing and Slicing)
Tuples support zero-based positive indexing, negative indexing, and slicing just like lists and strings:

```python
modules = ("Python", "SQL", "Git", "Docker", "AWS")

# Indexing
print(modules[0])     # 'Python' (first element)
print(modules[-1])    # 'AWS'    (last element)

# Slicing (returns a new tuple)
print(modules[1:4])   # ('SQL', 'Git', 'Docker')
print(modules[:2])    # ('Python', 'SQL')
print(modules[::-1])  # ('AWS', 'Docker', 'Git', 'SQL', 'Python')
```

---

## 4. Tuple Immutability

### Direct Modification Raises `TypeError`
```python
dims = (1920, 1080)
# dims[0] = 1280  # Raises TypeError: 'tuple' object does not support item assignment
```

### Mutable Elements Inside a Tuple
While the tuple's references are fixed, if a tuple holds a mutable object (such as a `list`), the contents of that inner mutable object can still be modified:
```python
record = ("Vivek", [85, 90])

# record[0] = "Amit"     # Raises TypeError (cannot replace tuple element)
record[1].append(95)     # Valid (mutates the inner list in place)
print(record)            # ('Vivek', [85, 90, 95])
```

## 5. Tuple Packing and Unpacking

### Standard Unpacking
Assigning a tuple's elements to multiple variables in a single statement. The number of variables must match the number of elements (otherwise Python raises a `ValueError`):
```python
person = ("Vivek", 23, "FDE")
name, age, track = person

print(name)   # 'Vivek'
print(age)    # 23
print(track)  # 'FDE'
```

### Extended Unpacking (`*`)
Use `*` before a variable name to collect remaining elements as a `list`:
```python
scores = (95, 88, 82, 79, 74)

highest, *middle, lowest = scores
print(highest)  # 95
print(middle)   # [88, 82, 79]
print(lowest)   # 74
```

### Swapping Variables
Python uses tuple packing and unpacking behind the scenes to swap variables cleanly:
```python
a, b = 10, 20
a, b = b, a
print(a, b)  # 20 10
```

## 6. Tuple Methods and Operations
Because tuples are immutable, they have only **two** built-in methods:

```python
nums = (10, 20, 30, 20, 40, 20)

# 1. .count(x) -> returns number of occurrences of x
print(nums.count(20))   # 3

# 2. .index(x) -> returns first index of x (raises ValueError if absent)
print(nums.index(30))   # 2
```

### Common Built-in Operations
```python
t1 = (1, 2, 3)
t2 = (4, 5)

print(len(t1))        # 3
print(2 in t1)        # True
print(t1 + t2)        # (1, 2, 3, 4, 5) (concatenation creates a new tuple)
print(t2 * 3)         # (4, 5, 4, 5, 4, 5)
print(min(t1), max(t1), sum(t1))  # 1 3 6
```

## 7. Tuples vs. Lists

| Feature | Tuple (`tuple`) | List (`list`) |
| :--- | :--- | :--- |
| **Syntax** | Parentheses `(1, 2, 3)` | Square brackets `[1, 2, 3]` |
| **Mutability** | Immutable (cannot be altered) | Mutable (can add, edit, remove items) |
| **Built-in Methods** | 2 methods (`.count()`, `.index()`) | Many methods (`.append()`, `.sort()`, `.pop()`, etc.) |
| **Memory & Speed** | Slightly smaller memory footprint and faster iteration | Slightly more memory overhead for dynamic resizing |
| **Dictionary Key** | Allowed (if all elements are immutable) | Not allowed (unhashable) |
| **Best Use Case** | Fixed records, coordinates, function return values | Dynamic collections that grow, shrink, or change |

## 8. Quick Reference

| Syntax / Method | Description | Example (`t = (10, 20, 30, 20)`) | Result |
| :--- | :--- | :--- | :--- |
| `(x,)` | Single-element tuple | `t1 = (5,)` | `(5,)` |
| `tuple(iter)` | Converts an iterable to a tuple | `tuple([1, 2])` | `(1, 2)` |
| `t[i]` | Accesses element at index `i` | `t[0]`, `t[-1]` | `10`, `20` |
| `t[a:b]` | Extracts a slice as a new tuple | `t[1:3]` | `(20, 30)` |
| `a, b = t` | Unpacks tuple items into variables | `x, y = (1, 2)` | `x=1, y=2` |
| `t.count(x)` | Counts occurrences of `x` | `t.count(20)` | `2` |
| `t.index(x)` | Returns first index of `x` | `t.index(30)` | `2` |
| `len(t)` | Returns total element count | `len(t)` | `4` |
