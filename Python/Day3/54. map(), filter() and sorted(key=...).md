# `map()`, `filter()`, and `sorted(key=...)`

## 1. Overview
`map()`, `filter()`, and `sorted()` are built-in Python **higher-order functions**—functions that accept another function as an argument to customize how an iterable is transformed, filtered, or ordered.

* **Non-Destructive:** None of these functions mutate the original iterable in place.
* **Lazy Iterators vs. Materialized Lists:**
  * `map()` and `filter()` return **lazy iterator objects** (`<class 'map'>` and `<class 'filter'>`) that compute values on demand; wrap them in `list()`, `tuple()`, or `set()` to materialize all results at once.
  * `sorted()` always returns a **new `list`** regardless of the input iterable type.

---

## 2. `map(function, iterable, *iterables)`
Applies `function` to every item in `iterable` and yields the transformed results.

### 1. Transforming with `lambda` and Named Functions
```python
scores = [72, 85, 91, 64]

# 1. Using a lambda expression to add 5 bonus points (capped at 100)
boosted = list(map(lambda s: min(s + 5, 100), scores))
print(boosted)  # [77, 90, 96, 69]

# 2. Using an existing function directly (no lambda wrapper needed)
raw_inputs = ["  Python ", " SQL\n", "  Git  "]
cleaned = list(map(str.strip, raw_inputs))
print(cleaned)  # ['Python', 'SQL', 'Git']

# 3. Parsing string digits into integers
str_nums = ["10", "20", "30"]
int_nums = list(map(int, str_nums))
print(int_nums)  # [10, 20, 30]
```

### 2. Mapping Across Multiple Iterables
When multiple iterables are passed, `function` must accept that many arguments. `map()` processes elements in parallel and **stops as soon as the shortest iterable is exhausted**:

```python
base_scores = [80, 75, 90]
bonus_points = [5, 10, 8, 12]  # Extra element (12) is ignored

final_scores = list(map(lambda a, b: a + b, base_scores, bonus_points))
print(final_scores)  # [85, 85, 98]
```

## 3. `filter(function, iterable)`
Constructs an iterator from elements of `iterable` for which `function(item)` evaluates to truthy (`True`). Elements that evaluate to falsy (`False`) are discarded.

### 1. Filtering with `lambda` and Named Predicate Functions
```python
marks = [58, 82, 94, 71, 88, 65]

# 1. Using a lambda expression to keep passing scores (>= 75)
passed = list(filter(lambda m: m >= 75, marks))
print(passed)  # [82, 94, 88]

# 2. Using a named predicate function
def is_python_file(filename: str) -> bool:
    return filename.endswith(".py") and not filename.startswith("test_")

files = ["main.py", "test_main.py", "utils.py", "README.md"]
source_files = list(filter(is_python_file, files))
print(source_files)  # ['main.py', 'utils.py']
```

### 2. Filtering Falsy Values with `filter(None, iterable)`
Passing `None` as the first argument removes all falsy values (`""`, `0`, `0.0`, `None`, `False`, `[]`, `{}`) from the iterable:

```python
entries = ["Vivek", "", None, "FDE", 0, "Batch-01", []]

valid_entries = list(filter(None, entries))
print(valid_entries)  # ['Vivek', 'FDE', 'Batch-01']
```

## 4. `sorted(iterable, *, key=None, reverse=False)`
Returns a new sorted `list` from the elements of any iterable (`list`, `tuple`, `set`, `str`, `dict`).

* **How `key` Works:** `key` accepts a single-argument function (`key_func`). Before comparing elements, Python calls `key_func(item)` **once per element** to compute a comparison proxy, then sorts the original items based on those proxy values.
* **Stable Sort:** Python's Timsort algorithm preserves the relative order of elements whose sort keys are equal.

### 1. Using Built-In Functions as `key`
```python
words = ["Python", "sql", "Docker", "go", "AWS"]

# Sort by string length
print(sorted(words, key=len))
# Output: ['go', 'sql', 'AWS', 'Python', 'Docker']

# Case-insensitive alphabetical sort
print(sorted(words, key=str.lower))
# Output: ['AWS', 'Docker', 'go', 'Python', 'sql']
```

### 2. Sorting Dictionaries and Tuples with `lambda`
```python
trainees = [
    {"name": "Amit", "score": 88, "age": 24},
    {"name": "Vivek", "score": 94, "age": 23},
    {"name": "Priya", "score": 94, "age": 22}
]

# Single-field sort: descending by score
by_score = sorted(trainees, key=lambda t: t["score"], reverse=True)
print([t["name"] for t in by_score])
# Output: ['Vivek', 'Priya', 'Amit']

# Multi-level sort using a tuple key:
# Primary: highest score first (-t["score"])
# Secondary (tie-breaker): youngest age first (t["age"])
ranked = sorted(trainees, key=lambda t: (-t["score"], t["age"]))
print([(t["name"], t["score"], t["age"]) for t in ranked])
# Output: [('Priya', 94, 22), ('Vivek', 94, 23), ('Amit', 88, 24)]
```

### 3. Using `operator.itemgetter`
For extracting tuple indices or dictionary keys without writing a `lambda`, Python's standard `operator` module provides `itemgetter()`:

```python
from operator import itemgetter

records = [("SQL", 88), ("Python", 95), ("Git", 91)]

# Sort by index 1 (score) in descending order
sorted_records = sorted(records, key=itemgetter(1), reverse=True)
print(sorted_records)
# Output: [('Python', 95), ('Git', 91), ('SQL', 88)]
```

## 5. `map()` and `filter()` vs. List Comprehensions
Both `map()`/`filter()` and list comprehensions solve transformation and filtering tasks, but each shines in specific scenarios:

```python
nums = [1, 2, 3, 4, 5, 6]

# Equivalent transformation + filtering:
# 1. Functional style (chaining map and filter)
res_func = list(map(lambda x: x ** 2, filter(lambda x: x % 2 == 0, nums)))

# 2. List comprehension style (more readable when combining both steps)
res_comp = [x ** 2 for x in nums if x % 2 == 0]
```

* **Prefer `map()` / `filter()` when:** You already have a named or built-in function (e.g., `map(int, data)` or `filter(None, data)`), or when you want **lazy evaluation** without building an entire list in memory.
* **Prefer Comprehensions when:** You need to combine filtering and transformation in one step, or when using inline expressions where a `lambda` would add visual clutter.

---

## 6. Quick Reference

| Function | Signature | Return Type | Evaluation | Primary Use Case |
| :--- | :--- | :--- | :--- | :--- |
| `map()` | `map(func, iter1, *iters)` | `map` (lazy iterator) | Lazy (on iteration) | Applies `func` to every element across one or more iterables |
| `filter()` | `filter(func \| None, iter)` | `filter` (lazy iterator) | Lazy (on iteration) | Keeps elements where `func(item)` is truthy (or truthy items if `None`) |
| `sorted()` | `sorted(iter, *, key=None, reverse=False)` | `list` (new copy) | Eager (full list) | Returns a newly ordered list ranked by the `key` function |
