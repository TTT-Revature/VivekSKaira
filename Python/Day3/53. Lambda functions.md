# Lambda Functions

## 1. Overview
A **lambda function** is a small, **anonymous** (unnamed) function defined in a single line using the `lambda` keyword instead of `def`.

* **Single-Expression Body:** A lambda can contain only **one expression**, which is evaluated and **implicitly returned** (the `return` keyword is neither needed nor allowed).
* **First-Class Function Object:** Produces a standard Python `function` object (`<class 'function'>`) that can be passed as an argument to other functions.
* **Primary Purpose:** Designed for short, throwaway operations passed directly into higher-order functions such as `sorted()`, `map()`, and `filter()`.

---

## 2. Syntax and Basic Usage
```python
lambda parameters: expression
```

### Standard `def` vs. `lambda`
```python
# 1. Standard named function using 'def'
def add_numbers(a: int, b: int) -> int:
    return a + b

# 2. Equivalent anonymous lambda expression
add_lambda = lambda a, b: a + b

print(add_numbers(10, 20))  # 30
print(add_lambda(10, 20))   # 30
print(type(add_lambda))     # <class 'function'>
```

### Parameter Variations
Lambdas support the same parameter forms as `def` functions (positional, default, keyword, `*args`, and `**kwargs`):

```python
# 1. Zero parameters
get_status = lambda: "System Operational"
print(get_status())  # 'System Operational'

# 2. Single parameter
square = lambda x: x ** 2
print(square(6))     # 36

# 3. Default parameter
apply_tax = lambda amount, rate=0.18: round(amount * (1 + rate), 2)
print(apply_tax(100))        # 118.0
print(apply_tax(100, 0.05))  # 105.0

# 4. Variable-length arguments (*args)
total_sum = lambda *nums: sum(nums)
print(total_sum(10, 20, 30))  # 60

# 5. Immediately Invoked Lambda Expression (IIFE)
result = (lambda x, y: x * y)(4, 5)
print(result)  # 20
```

## 3. Common Use Cases with Built-In Functions
Lambdas are most idiomatic when passed inline as callback or key functions.

### 1. Custom Sorting with `sorted()` and `list.sort()`
Use `key=lambda ...` to sort complex structures (such as lists of tuples or dictionaries) by a specific field:

```python
trainees = [
    {"name": "Amit", "score": 82},
    {"name": "Vivek", "score": 94},
    {"name": "Priya", "score": 89}
]

# Sort dictionaries by 'score' in descending order
ranked = sorted(trainees, key=lambda t: t["score"], reverse=True)
print(ranked)
# Output: [{'name': 'Vivek', 'score': 94}, {'name': 'Priya', 'score': 89}, {'name': 'Amit', 'score': 82}]

# Sort tuples by length of the module name
modules = [(1, "Python"), (2, "SQL"), (3, "Docker")]
modules.sort(key=lambda item: len(item[1]))
print(modules)
# Output: [(2, 'SQL'), (1, 'Python'), (3, 'Docker')]
```

### 2. Transforming Data with `map()`
`map(function, iterable)` applies a function to every element in an iterable and returns a lazy `map` iterator:

```python
prices = [100, 250, 400]

# Apply a 10% discount to every price
discounted = list(map(lambda p: round(p * 0.9, 2), prices))
print(discounted)  # [90.0, 225.0, 360.0]
```

### 3. Filtering Data with `filter()`
`filter(function, iterable)` retains only the elements for which the function evaluates to `True`:

```python
scores = [62, 88, 95, 71, 84, 59]

# Keep only scores greater than or equal to 75
passed = list(filter(lambda s: s >= 75, scores))
print(passed)  # [88, 95, 84]
```

## 4. Conditional Expressions Inside Lambdas
Because multi-line `if-elif-else` blocks are not allowed inside a lambda, use Python's inline conditional (ternary) expression (`value_if_true if condition else value_if_false`):

```python
evaluate = lambda score: "Pass" if score >= 75 else "Retake"

print(evaluate(85))  # 'Pass'
print(evaluate(68))  # 'Retake'
```

## 5. Limitations and Best Practices (PEP 8)

### Key Limitations
* **No Statements:** Statements such as `return`, `pass`, `raise`, `assert`, `for`, `while`, or standard variable assignments (`=`) raise a `SyntaxError` inside a lambda.
* **No Docstrings or Type Annotations:** Lambdas cannot contain docstrings (`"""..."""`) or parameter/return type hints (`x: int -> int`).
* **Generic Traceback Names:** In error stack traces, all lambda functions appear generically as `<lambda>`, making complex debugging harder.

### PEP 8 Guidelines
1. **Do Not Bind Lambdas to Variables (PEP 8 E731):** Always use `def` instead of assigning a lambda expression to an identifier. Assigning a lambda to a variable defeats its purpose as an anonymous function and hurts traceback readability:
   ```python
   # Discouraged (PEP 8 E731)
   double = lambda x: x * 2

   # Recommended
   def double(x: int) -> int:
       return x * 2
   ```
2. **Prefer Comprehensions Over Complex `map()`/`filter()` Lambdas:** When combining transformations and filters, a list comprehension is generally cleaner and easier to read:
   ```python
   nums = [1, 2, 3, 4, 5, 6]

   # Less readable
   res1 = list(map(lambda x: x ** 2, filter(lambda x: x % 2 == 0, nums)))

   # More Pythonic
   res2 = [x ** 2 for x in nums if x % 2 == 0]
   ```

## 6. Quick Reference

| Pattern | Syntax Example | Purpose / Result |
| :--- | :--- | :--- |
| **Basic Lambda** | `lambda x, y: x + y` | Creates an anonymous single-expression function |
| **Default Argument** | `lambda x, y=10: x + y` | Supports default values just like `def` |
| **Conditional Logic** | `lambda x: "Even" if x % 2 == 0 else "Odd"` | Evaluates inline ternary condition |
| **Custom Sorting** | `sorted(items, key=lambda x: x[1])` | Extracts sort key dynamically |
| **Inline Mapping** | `list(map(lambda x: x * 2, nums))` | Applies transformation across an iterable |
| **Inline Filtering** | `list(filter(lambda x: x > 0, nums))` | Selects elements matching a predicate |
