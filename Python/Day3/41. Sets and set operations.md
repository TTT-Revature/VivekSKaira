# Sets and Set Operations

## 1. Overview
A **set (`set`)** is a built-in Python collection used to store multiple unique items in a single variable.

* **Unordered:** Elements have no fixed position; sets do **not** support indexing (`s[0]`) or slicing (`s[1:3]`).
* **Unique Elements:** Duplicate values are automatically discarded upon creation or insertion.
* **Mutable Container:** Elements can be added or removed in place after the set is created.
* **Hashable Elements Only:** Every item stored inside a set must be **immutable/hashable** (such as `int`, `float`, `str`, `bool`, or `tuple`). Mutable objects like `list`, `dict`, or another `set` cannot be elements of a set.
* **Fast Membership Testing:** Backed by a hash table, checking `x in my_set` runs in average $O(1)$ constant time.

---

## 2. Creating Sets

### Using Curly Braces `{}` vs. `set()`
* **Empty Set Rule:** Empty curly braces `{}` create an empty **dictionary (`dict`)**, not a set. Always use `set()` to create an empty set.

```python
# 1. Empty set
empty_set = set()
print(type(empty_set))  # <class 'set'>

# 2. Set with initial elements (duplicates are automatically removed)
tags = {"Python", "SQL", "Git", "Python", "SQL"}
print(tags)             # {'Python', 'SQL', 'Git'}

# 3. Creating a set from an iterable (common way to deduplicate a list)
scores = [85, 90, 85, 92, 90]
unique_scores = set(scores)
print(unique_scores)    # {85, 90, 92}

# 4. Invalid: mutable elements raise TypeError
# bad_set = {[1, 2], [3, 4]}  # TypeError: unhashable type: 'list'
```

---

## 3. Adding and Removing Elements

### Adding Elements
* **`.add(elem)`:** Adds a single element to the set (has no effect if the element already exists).
* **`.update(iterable)`:** Adds all elements from one or more iterables (`list`, `tuple`, `str`, `set`) into the set.

```python
modules = {"Python", "SQL"}

modules.add("Git")
modules.add("Python")           # Ignored since 'Python' is already present
modules.update(["Docker", "AWS"])

print(modules)                  # {'Python', 'SQL', 'Git', 'Docker', 'AWS'}
```

### Removing Elements
* **`.remove(elem)`:** Removes `elem` from the set. Raises a **`KeyError`** if `elem` is not found.
* **`.discard(elem)`:** Removes `elem` if present; **does nothing** (no error) if `elem` is absent.
* **`.pop()`:** Removes and returns an **arbitrary** element from the set. Raises a `KeyError` if the set is empty.
* **`.clear()`:** Removes all elements from the set, leaving `set()`.

```python
tools = {"Git", "Docker", "AWS"}

tools.remove("Docker")
# tools.remove("Jenkins")  # Raises KeyError: 'Jenkins'

tools.discard("Jenkins")   # Safe removal: no error raised
removed = tools.pop()      # Removes and returns one element
tools.clear()              # Empties the set completely
```

## 4. Mathematical Set Operations
Python supports standard mathematical set operations using both **symbolic operators** and **built-in methods**.

* **Operator vs. Method Difference:** Operators (`|`, `&`, `-`, `^`) require **both operands to be sets**, whereas methods (`.union()`, `.intersection()`, etc.) accept **any iterable** (such as a `list` or `tuple`) as an argument.

```python
batch_a = {"Amit", "Priya", "Vivek", "Sneha"}
batch_b = {"Vivek", "Sneha", "Rahul", "Karan"}
```

### 1. Union (`|` or `.union()`)
Combines all unique elements from both sets.
```python
print(batch_a | batch_b)
print(batch_a.union(batch_b))
# Output: {'Amit', 'Priya', 'Vivek', 'Sneha', 'Rahul', 'Karan'}
```

### 2. Intersection (`&` or `.intersection()`)
Returns only the elements common to **both** sets.
```python
print(batch_a & batch_b)
print(batch_a.intersection(batch_b))
# Output: {'Vivek', 'Sneha'}
```

### 3. Difference (`-` or `.difference()`)
Returns elements present in the **first set** (`batch_a`) that are **not** in the second set (`batch_b`).
```python
print(batch_a - batch_b)
print(batch_a.difference(batch_b))
# Output: {'Amit', 'Priya'}
```

### 4. Symmetric Difference (`^` or `.symmetric_difference()`)
Returns elements present in **either** set, **excluding** elements common to both.
```python
print(batch_a ^ batch_b)
print(batch_a.symmetric_difference(batch_b))
# Output: {'Amit', 'Priya', 'Rahul', 'Karan'}
```

### In-Place Update Operations
To modify the original set directly instead of returning a new set, use augmented assignment operators or `*_update()` methods:
* **Union update:** `a |= b` or `a.update(b)`
* **Intersection update:** `a &= b` or `a.intersection_update(b)`
* **Difference update:** `a -= b` or `a.difference_update(b)`
* **Symmetric difference update:** `a ^= b` or `a.symmetric_difference_update(b)`

## 5. Set Relationships and Comparisons

```python
core = {"Python", "SQL"}
full_stack = {"Python", "SQL", "Git", "Docker"}
cloud = {"AWS", "Azure"}
```

* **Subset (`<=` or `.issubset()`):** `True` if every element of `core` is in `full_stack`.
  ```python
  print(core <= full_stack)          # True
  print(core.issubset(full_stack))   # True
  print(core < full_stack)           # True (proper subset: core != full_stack)
  ```
* **Superset (`>=` or `.issuperset()`):** `True` if `full_stack` contains every element of `core`.
  ```python
  print(full_stack >= core)          # True
  print(full_stack.issuperset(core)) # True
  ```
* **Disjoint (`.isdisjoint()`):** `True` if two sets share **no** common elements (their intersection is empty).
  ```python
  print(core.isdisjoint(cloud))      # True
  print(core.isdisjoint(full_stack)) # False
  ```

## 6. Immutable Sets (`frozenset`)
A **`frozenset`** is an immutable version of a Python set. Because its contents cannot be changed after creation, a `frozenset` is **hashable** and can be used as a dictionary key or stored inside another set.

```python
fs = frozenset(["Python", "SQL", "Git"])
# fs.add("Docker")  # Raises AttributeError: 'frozenset' object has no attribute 'add'

# Valid as a dictionary key or set member
nested_sets = {frozenset({1, 2}), frozenset({3, 4})}
```

## 7. Quick Reference

| Operation | Operator | Method | Description |
| :--- | :--- | :--- | :--- |
| **Union** | `a \| b` | `a.union(b)` | All unique elements from both `a` and `b` |
| **Intersection** | `a & b` | `a.intersection(b)` | Elements present in both `a` and `b` |
| **Difference** | `a - b` | `a.difference(b)` | Elements in `a` that are not in `b` |
| **Symmetric Difference** | `a ^ b` | `a.symmetric_difference(b)` | Elements in `a` or `b`, but not in both |
| **Subset** | `a <= b` | `a.issubset(b)` | `True` if all elements of `a` exist in `b` |
| **Superset** | `a >= b` | `a.issuperset(b)` | `True` if `a` contains all elements of `b` |
| **Disjoint** | — | `a.isdisjoint(b)` | `True` if `a` and `b` have zero elements in common |
| **Membership** | `x in a` | — | Checks if `x` exists in `a` in $O(1)$ average time |
