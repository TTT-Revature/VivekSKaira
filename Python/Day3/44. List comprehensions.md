# List Comprehensions

## 1. Overview
A **list comprehension** provides a concise, readable, and Pythonic syntax for creating a **new `list`** by transforming and/or filtering items from any iterable (`list`, `tuple`, `str`, `range`, `set`, `dict`).

* **Concise:** Replaces multi-line `for` loops and `.append()` calls with a single expressive line.
* **Non-Destructive:** Leaves the original iterable unchanged and returns a brand-new list.
* **Performant:** Optimized internally in CPython, making it faster than building a list iteratively with `.append()`.

---

## 2. Basic Syntax (Transformation)
```python
new_list = [expression for item in iterable]
```

### Traditional `for` Loop vs. List Comprehension
```python
numbers = [1, 2, 3, 4, 5]

# Traditional loop approach
squares_loop = []
for n in numbers:
    squares_loop.append(n ** 2)

# List comprehension approach
squares_comp = [n ** 2 for n in numbers]

print(squares_comp)  # [1, 4, 9, 16, 25]
```

### Transforming Strings
```python
modules = ["python", "sql", "git", "docker"]
upper_modules = [m.upper() for m in modules]
print(upper_modules)  # ['PYTHON', 'SQL', 'GIT', 'DOCKER']
```

---

## 3. Filtering Elements (`if` at the End)
Add an `if` clause at the end of the comprehension to include only elements that satisfy a condition:

```python
new_list = [expression for item in iterable if condition]
```

### Examples
```python
scores = [62, 88, 95, 71, 84, 59, 91]

# 1. Keep only passing scores (>= 75)
passed = [s for s in scores if s >= 75]
print(passed)  # [88, 95, 84, 91]

# 2. Multiple conditions (using 'and' or chained 'if' clauses)
high_even = [s for s in scores if s >= 80 and s % 2 == 0]
print(high_even)  # [88, 84]

# 3. Filter and transform simultaneously
files = ["notes.md", "app.py", "schema.sql", "test.py"]
py_names = [f.removesuffix(".py") for f in files if f.endswith(".py")]
print(py_names)  # ['app', 'test']
```

---

## 4. Conditional Expressions (`if-else` Before `for`)
To choose between two output values for every item (without filtering items out), place a conditional (ternary) expression **before** the `for` keyword:

```python
new_list = [expr_if_true if condition else expr_if_false for item in iterable]
```

### Syntax Placement Rule
* **`if` only (filtering):** Placed **after** the `for` clause.
* **`if-else` (value mapping):** Placed **before** the `for` clause.

```python
marks = [92, 68, 81, 54, 77]

results = ["Pass" if m >= 75 else "Retake" for m in marks]
print(results)  # ['Pass', 'Retake', 'Pass', 'Retake', 'Pass']
```

## 5. Nested Loops and 2D Lists

### 1. Flattening a Nested List (Multiple `for` Clauses)
When chaining multiple `for` clauses, they execute in the **exact same order** as standard nested `for` loops (outer loop first, inner loop second):

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

# Equivalent to:
# for row in matrix:
#     for num in row:
#         flat.append(num)
flat = [num for row in matrix for num in row]
print(flat)  # [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

### 2. Generating Pairs (Cartesian Product)
```python
tracks = ["Python", "SQL"]
levels = ["Basic", "Advanced"]

modules = [f"{t} - {l}" for t in tracks for l in levels]
print(modules)
# Output: ['Python - Basic', 'Python - Advanced', 'SQL - Basic', 'SQL - Advanced']
```

### 3. Nested List Comprehensions (Creating a 2D Matrix)
Placing a list comprehension inside the expression slot builds a list of lists:
```python
# Create a 3x3 grid initialized to 0
grid = [[0 for _ in range(3)] for _ in range(3)]
print(grid)  # [[0, 0, 0], [0, 0, 0], [0, 0, 0]]
```

---

## 6. Best Practices and Limitations

* **Prioritize Readability:** Avoid nesting more than two `for` clauses or packing complex boolean logic into a single comprehension; use a standard `for` loop if the line becomes hard to read.
* **Avoid Side Effects:** Do not use list comprehensions solely to call functions with side effects (such as `[print(x) for x in items]`), as it wastes memory building a list of `None` values. Use a regular `for` loop instead.
* **Large Datasets:** A list comprehension materializes the entire list in memory at once. When iterating over huge sequences where you only need one item at a time, use a **generator expression** with parentheses `(x ** 2 for x in range(10_000_000))`.

---

## 7. Quick Reference

| Pattern | Syntax | Example | Output |
| :--- | :--- | :--- | :--- |
| **Transform** | `[expr for x in it]` | `[x * 2 for x in [1, 2, 3]]` | `[2, 4, 6]` |
| **Filter** | `[expr for x in it if cond]` | `[x for x in [1, 2, 3, 4] if x % 2 == 0]` | `[2, 4]` |
| **If-Else Map** | `[a if cond else b for x in it]` | `["E" if x % 2 == 0 else "O" for x in [1, 2]]` | `['O', 'E']` |
| **Flatten 2D** | `[x for row in m for x in row]` | `[x for r in [[1, 2], [3]] for x in r]` | `[1, 2, 3]` |
| **2D Matrix** | `[[expr for c in it1] for r in it2]` | `[[r + c for c in range(2)] for r in range(2)]` | `[[0, 1], [1, 2]]` |
