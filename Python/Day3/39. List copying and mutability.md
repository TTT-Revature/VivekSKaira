# List Copying and Mutability

## 1. Overview
In Python, **lists are mutable**—meaning their contents can be changed **in place** (by adding, removing, or updating elements) without creating a new list object in memory.

Because variables in Python store **references** to objects rather than copies of data, understanding how mutability interacts with assignment and copying is essential to prevent unintended side effects in your programs.

```python
scores = [80, 85, 90]
print(id(scores))  # e.g., 2104567891200

scores[0] = 88     # Mutates the existing list in place
scores.append(95)  # Still mutating the exact same object
print(id(scores))  # Same memory ID (2104567891200)
```

---

## 2. Reference Assignment (Aliasing)
Assigning an existing list to a new variable using `=` **does not create a copy**. Instead, it creates an **alias**—both variables point to the exact same list object in memory.

* Modifying the list through one variable immediately affects the other.

```python
original = ["Python", "SQL", "Git"]
alias = original  # Both variables reference the same list object

alias.append("Docker")

print(original)          # ['Python', 'SQL', 'Git', 'Docker']
print(alias)             # ['Python', 'SQL', 'Git', 'Docker']
print(original is alias) # True (identical memory address)
```

---

## 3. Shallow Copy
A **shallow copy** constructs a **new outer list object** and populates it with references to the same elements found in the original list.

### Ways to Create a Shallow Copy
1. **`.copy()` method:** `new_list = original.copy()`
2. **Slicing (`[:]`):** `new_list = original[:]`
3. **`list()` constructor:** `new_list = list(original)`
4. **`copy.copy()` function:** `import copy; new_list = copy.copy(original)`

### Behavior on Flat Lists (1D Lists)
When a list contains only immutable elements (such as `int`, `float`, `str`, or `tuple`), a shallow copy is completely independent of the original:

```python
original = [10, 20, 30]
shallow = original.copy()

shallow.append(40)
shallow[0] = 99

print(original)             # [10, 20, 30] (unaffected)
print(shallow)              # [99, 20, 30, 40]
print(original is shallow)  # False (two distinct outer list objects)
```

### Limitation with Nested Lists (2D+ Lists)
Because a shallow copy only duplicates the outer container, **nested mutable objects (such as inner lists) are still shared** between the original and the copy:

```python
matrix = [[1, 2], [3, 4]]
shallow_matrix = matrix.copy()

# Modifying a nested inner list affects BOTH variables
shallow_matrix[0][0] = 999

print(matrix)          # [[999, 2], [3, 4]] (inner list was shared)
print(shallow_matrix)  # [[999, 2], [3, 4]]
```

---

## 4. Deep Copy
A **deep copy** creates a **new outer list** and **recursively duplicates every nested object** inside it. Changes made at any depth in a deep copy never affect the original list.

* Requires Python's built-in `copy` module (`import copy`).

```python
import copy

matrix = [[1, 2], [3, 4]]
deep_matrix = copy.deepcopy(matrix)

# Modifying a nested inner list affects ONLY the deep copy
deep_matrix[0][0] = 999

print(matrix)       # [[1, 2], [3, 4]]   (original remains completely intact)
print(deep_matrix)  # [[999, 2], [3, 4]]
```

---

## 5. Mutability When Passing Lists to Functions
Because Python passes object references to functions, mutating a list parameter inside a function modifies the caller's original list:

```python
def add_bonus(marks: list[int]) -> None:
    # Mutates the caller's list directly
    for i in range(len(marks)):
        marks[i] += 5

trainee_marks = [75, 80, 85]
add_bonus(trainee_marks)
print(trainee_marks)  # [80, 85, 90]
```
*(Best Practice: If a function should compute a modified result without altering the input list, copy the list first or return a new list.)*

---

## 6. Comparison Summary

| Technique | Syntax | New Outer List? | Copies Nested Mutables? | Original Affected on Nested Edit? |
| :--- | :--- | :--- | :--- | :--- |
| **Assignment (Alias)** | `b = a` | No (`a is b` is `True`) | No | Yes (all changes affect both) |
| **Shallow Copy** | `b = a.copy()` / `a[:]` / `list(a)` | Yes (`a is b` is `False`) | No (shares inner references) | Yes (nested mutations affect both) |
| **Deep Copy** | `b = copy.deepcopy(a)` | Yes (`a is b` is `False`) | Yes (recursively duplicated) | No (fully independent) |
