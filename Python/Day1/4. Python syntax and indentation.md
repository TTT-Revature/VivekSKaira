# Python Syntax and Indentation

## 1. Python Syntax Overview
Python syntax is designed to be clean, readable, and close to plain English. Unlike languages such as C, C++, or Java, Python does not use curly braces `{}` to define code blocks or semicolons `;` to terminate statements.

* **Newline Termination:** A new line marks the end of a statement.
* **Colons (`:`):** Used at the end of header lines (such as `if`, `for`, `while`, `def`, and `class`) to introduce an indented block of code.
* **Case Sensitivity:** Python is strictly case-sensitive (`score`, `Score`, and `SCORE` are treated as three distinct identifiers).

---

## 2. Indentation Rules
In Python, **indentation is a core syntax requirement**, not just a formatting preference. It defines which statements belong to a specific block of code.

### Standard Convention
* The official Python style guide (**PEP 8**) specifies **4 spaces per indentation level**.
* All statements within the same block must have the exact same indentation.

```python
# Valid indentation
score = 85

if score >= 60:
    print("Status: Passed")
    if score >= 80:
        print("Grade: Distinction")
print("Evaluation complete.")
```

### Common Indentation Errors
* **`IndentationError`:** Raised when a block lacks expected indentation or when lines within the same block have mismatched spacing.
* **`TabError`:** Raised when tabs and spaces are mixed inconsistently in the same source file. (Always configure your editor to insert 4 spaces when pressing `Tab`.)

```python
# Invalid: raises IndentationError
if True:
print("Missing indentation")
```
