# Installing Python and Setting Up the Development Environment

## 1. Installing Python
1. **Download:** Visit the official Python website ([python.org](https://www.python.org/downloads/)) and download the latest stable Python 3 installer for your operating system.
2. **Windows Setup:** Run the installer and check the box **"Add python.exe to PATH"** before clicking Install Now. This allows running Python directly from the terminal.
3. **macOS Setup:** Run the `.pkg` installer from python.org, or install via Homebrew:
   ```bash
   brew install python
   ```
4. **Linux (Ubuntu/Debian) Setup:** Use the system package manager:
   ```bash
   sudo apt update
   sudo apt install python3 python3-pip python3-venv
   ```

---

## 2. Verifying the Installation
Open a terminal (Command Prompt, PowerShell, or Terminal) and check the installed versions of Python and `pip` (Python's package installer):

```bash
# Check Python version (use python3 on macOS/Linux if python points to an older version)
python --version

# Check pip version
pip --version
```

---

## 3. Virtual Environments (`venv`)
A **virtual environment** is an isolated workspace that keeps project-specific dependencies separate from the global Python installation, preventing version conflicts across projects.

### Creating a Virtual Environment
Navigate to your project folder and run:
```bash
python -m venv venv
```

### Activating the Virtual Environment
* **Windows (Command Prompt):**
  ```cmd
  venv\Scripts\activate
  ```
* **Windows (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
* **macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```
*(Once active, `(venv)` appears before your terminal prompt.)*

### Deactivating
```bash
deactivate
```

---

## 4. Managing Packages with `pip`
With the virtual environment activated, use `pip` to install and track external libraries:

```bash
# Install a package
pip install requests

# List installed packages in the current environment
pip list

# Export dependencies to a requirements file
pip freeze > requirements.txt

# Install all dependencies from an existing requirements file
pip install -r requirements.txt
```

---

## 5. Configuring the IDE (VS Code)
1. **Install VS Code:** Download and install Visual Studio Code from [code.visualstudio.com](https://code.visualstudio.com/).
2. **Install the Python Extension:** Open the Extensions view (`Ctrl+Shift+X` or `Cmd+Shift+X`), search for **Python** (by Microsoft), and install it.
3. **Select the Interpreter:**
   * Open the Command Palette (`Ctrl+Shift+P` or `Cmd+Shift+P`).
   * Type and select **Python: Select Interpreter**.
   * Choose the interpreter located inside your project's `venv` folder.

---

## 6. Verifying the Environment
Create a file named `hello.py` in your project directory:
```python
print("Development environment is ready.")
```
Run the script from the integrated terminal:
```bash
python hello.py
```
