# Comments and Docstrings

## 1. Comments
Comments are non-executable lines in Python source code that are completely ignored by the Python interpreter. They are used to explain complex logic, clarify intent, and improve code readability for other developers.

### Types of Comments

#### Single-Line Comments
Begin with a hash symbol (`#`). Everything after `#` on that line is ignored.
```python
# Calculate the final score after applying bonus points
final_score = base_score + 5
```

#### Inline Comments
Placed on the same line as a statement. Per **PEP 8**, separate an inline comment from the code by at least **two spaces**.
```python
max_retries = 3  # Limit connection attempts to prevent timeout loops
```

#### Multi-Line Comments
Python does not have a dedicated multi-line comment delimiter (like `/* ... */` in C or Java). The standard convention is to prefix each line with `#`.
```python
# Validate user credentials before granting access.
# Check both token expiration and active role permissions
# before proceeding to the dashboard.
```

## 2. Docstrings (Documentation Strings)
A **docstring** is a string literal enclosed in triple quotes (`"""..."""` or `'''...'''`) placed as the **very first statement** inside a module, class, function, or method.

Unlike regular comments, docstrings are **not ignored** by the interpreter—they are stored at runtime in the object's `__doc__` attribute and used by IDEs and documentation generators.

### One-Line Docstrings
Used for simple, self-explanatory functions where the summary fits on a single line.
```python
def square(n):
    """Return the square of a given number."""
    return n * n
```

### Multi-Line Docstrings
Used for complex functions, classes, and modules. Per **PEP 257**, they consist of a one-line summary, a blank line, and a detailed description of parameters, return values, and exceptions.
```python
def calculate_percentage(obtained, total):
    """
    Calculate the percentage score from obtained and total marks.

    Args:
        obtained (float): Marks scored by the candidate.
        total (float): Maximum possible marks.

    Returns:
        float: The calculated percentage rounded to two decimal places.
    """
    if total == 0:
        return 0.0
    return round((obtained / total) * 100, 2)
```

---

## 3. Accessing Docstrings at Runtime
Docstrings can be inspected programmatically using the `__doc__` attribute or the built-in `help()` function:

```python
# Access raw docstring text
print(calculate_percentage.__doc__)

# Display formatted documentation in the console
help(calculate_percentage)
```

---

## 4. Comments vs. Docstrings

| Feature | Comments (`#`) | Docstrings (`"""..."""`) |
| :--- | :--- | :--- |
| **Purpose** | Explain *how* or *why* specific lines of code work | Document *what* a module, class, or function does |
| **Placement** | Anywhere in the file | First statement inside a module, class, or function |
| **Interpreter Handling** | Stripped and ignored during execution | Retained in memory as the `__doc__` attribute |
| **Accessible via `help()`** | No | Yes |
| **Style Standard** | PEP 8 | PEP 257 |
