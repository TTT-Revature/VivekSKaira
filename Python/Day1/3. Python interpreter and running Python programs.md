# Python Interpreter and Running Python Programs

## 1. What is the Python Interpreter?
The **Python interpreter** is the program that reads, translates, and executes Python code. Unlike compiled languages (such as C or C++) that convert the entire source file into machine code before execution, the Python interpreter processes and runs code dynamically at runtime.

* **CPython** is the default and most widely used implementation of the Python interpreter (written in C).

---

## 2. How the Interpreter Processes Code
Behind the scenes, running a Python program involves two internal stages handled automatically by the interpreter:

1. **Compilation to Bytecode:** The interpreter parses the human-readable `.py` source file and compiles it into low-level, platform-independent instructions called **bytecode** (`.pyc` files, cached inside a `__pycache__` folder for faster subsequent runs).
2. **Execution via PVM:** The **Python Virtual Machine (PVM)**—the runtime engine of the interpreter—reads the bytecode instructions one by one and executes them on the host machine's CPU.

```text
Source Code (.py) ---> Interpreter Compiler ---> Bytecode (.pyc) ---> PVM ---> Output
```

---

## 3. Ways to Run Python Programs

### A. Interactive Mode (REPL)
REPL stands for **Read-Eval-Print Loop**. It lets you execute single statements immediately without saving a file, making it useful for quick testing and debugging.

1. Open a terminal and type `python` (or `python3` on macOS/Linux).
2. Write commands at the primary prompt (`>>>`):
   ```python
   >>> 10 + 25
   35
   >>> print("Testing REPL")
   Testing REPL
   ```
3. Exit interactive mode using `exit()`, `quit()`, or pressing `Ctrl+D` (macOS/Linux) / `Ctrl+Z` then `Enter` (Windows).

---

### B. Script Mode
Script mode is the standard way to run complete programs saved in files with a `.py` extension.

1. Save your code in a file (e.g., `app.py`):
   ```python
   name = "Revature"
   print(f"Running script for {name}")
   ```
2. Navigate to the file's directory in the terminal and run:
   ```bash
   python app.py
   ```

---

### C. Useful Interpreter Command-Line Options
The interpreter accepts flags to alter how code is executed from the terminal:

* **Execute an inline command (`-c`):** Runs a short snippet directly without a file.
  ```bash
  python -c "print(5 * 12)"
  ```
* **Run a library module as a script (`-m`):** Executes a standard or installed module directly.
  ```bash
  python -m venv my_env
  ```
* **Inspect interactively after running (`-i`):** Runs a `.py` script and drops straight into the `>>>` prompt afterward so you can inspect variables.
  ```bash
  python -i app.py
  ```

---

### D. Running via IDEs and Notebooks
* **IDEs (VS Code, PyCharm):** Clicking the **Run** button simply triggers `python <filename>.py` in the integrated terminal behind the scenes.
* **Notebooks (Jupyter, Google Colab):** Execute code in isolated blocks (cells) using an IPython kernel, retaining variable state in memory between cell runs.
