# Basic Data Types

## 1. Overview
In Python, every value is an object that belongs to a specific data type. **Basic (primitive) data types** represent single, simple values rather than collections of items.

* **Dynamic Typing:** Python automatically determines a variable's data type when a value is assigned.
* **Immutability:** All basic data types (`int`, `float`, `complex`, `str`, `bool`, `NoneType`) are **immutable**—once created, their value in memory cannot be modified in place; reassigning creates a new object.

---

## 2. Numeric Types

### Integer (`int`)
Represents whole numbers (positive, negative, or zero) without a fractional component. Python integers have **arbitrary precision**, meaning they can grow as large as available memory allows.
```python
count = 42
temperature = -10
population = 1_400_000_000  # Underscores improve readability for large numbers
```

### Floating-Point (`float`)
Represents real numbers with a decimal point or written in scientific notation (`e` or `E` for powers of 10).
```python
price = 99.95
pi = 3.14159
avogadro = 6.022e23  # 6.022 * 10^23
```

### Complex (`complex`)
Represents complex numbers in the form `real + imaginary`, using `j` to denote the imaginary unit.
```python
z = 3 + 4j
print(z.real)  # 3.0
print(z.imag)  # 4.0
```

---

## 3. Text Type

### String (`str`)
Represents an ordered sequence of Unicode characters enclosed in single quotes (`'...'`), double quotes (`"..."`), or triple quotes (`'''...'''` / `"""..."""`) for multi-line text.
```python
role = 'Junior Trainer'
track = "FDE Training"
bio = """Line one
Line two"""
```

---

## 4. Boolean Type

### Boolean (`bool`)
Represents logical truth values and can hold only one of two constants: `True` or `False` (must start with a capital letter).
```python
is_active = True
has_graduated = False
```
*Internally, `bool` is a subclass of `int`, where `True` behaves as `1` and `False` behaves as `0`.*

---

## 5. None Type

### None (`NoneType`)
`None` is a special constant representing the **absence of a value** or a null reference. It is commonly used as a placeholder before an actual value is assigned.
```python
result = None
```

---

## 6. Inspecting Data Types

### Using `type()`
Returns the exact data type (class) of an object:
```python
score = 95.5
print(type(score))  # <class 'float'>
```

### Using `isinstance()`
Checks whether an object is an instance of a specified data type (or tuple of types) and returns a boolean:
```python
age = 23
print(isinstance(age, int))           # True
print(isinstance(age, (int, float)))  # True
```
