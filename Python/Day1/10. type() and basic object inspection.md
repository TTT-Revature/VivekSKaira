# `type()` and Basic Object Inspection

## 1. Overview
In Python, every value is an object that possesses three fundamental properties:
1. **Identity:** Where the object lives in memory (`id()`).
2. **Type:** What kind of object it is and what operations it supports (`type()`).
3. **Value:** The actual data stored inside the object.

Python provides built-in introspection functions that allow you to inspect an object's type, memory identity, available attributes, and documentation at runtime.

---

## 2. Checking Object Types

### `type(object)`
Returns the exact class (data type) of an object.
```python
x = 42
name = "Revature"
items = [1, 2, 3]

print(type(x))      # <class 'int'>
print(type(name))   # <class 'str'>
print(type(items))  # <class 'list'>

# Direct type comparison
print(type(x) is int)  # True
```

### `isinstance(object, classinfo)`
Checks whether an object is an instance of a specified type (or any subclass of that type) and returns `True` or `False`. It also accepts a **tuple of types** to check multiple possibilities at once.
```python
score = 92.5

print(isinstance(score, float))          # True
print(isinstance(score, (int, float)))   # True (matches either int or float)
```

### `type()` vs. `isinstance()`
`isinstance()` is generally preferred for type checking because it accounts for inheritance, whereas `type()` checks only for an exact class match.
```python
flag = True  # bool is a subclass of int in Python

print(type(flag) is int)        # False (exact type is bool, not int)
print(isinstance(flag, int))    # True  (bool inherits from int)
```

## 3. Inspecting Object Identity: `id()`
Returns a unique integer representing the object's identity during its lifetime (in CPython, this is the object's memory address).

```python
a = [10, 20]
b = a
c = [10, 20]

print(id(a))       # e.g., 140234891234560
print(id(b))       # Same ID as 'a'
print(id(c))       # Different ID (separate list object in memory)

print(a is b)      # True  (same identity)
print(a is c)      # False (different identities, even though values match)
```

## 4. Exploring Attributes and Methods

### `dir([object])`
Returns a sorted list of strings containing all valid attribute and method names available on an object (including built-in "dunder" methods like `__len__`).
```python
text = "python"
print(dir(text))
# Output includes: [..., 'capitalize', 'lower', 'replace', 'split', 'upper', ...]
```
*Calling `dir()` with no arguments lists all names defined in the current local scope.*

### `hasattr()` and `getattr()`
Used to safely check for or retrieve an attribute by name as a string without raising an `AttributeError`.
```python
sample = "Hello"

print(hasattr(sample, "upper"))              # True
print(hasattr(sample, "append"))             # False
print(getattr(sample, "non_existent", None)) # None (returns fallback default)
```

### `vars([object])`
Returns the `__dict__` attribute of an object—a dictionary containing its writable instance attributes. (Works on custom class instances and modules, not primitive types like `int` or `str`.)
```python
class Trainee:
    def __init__(self, name, track):
        self.name = name
        self.track = track

t = Trainee("Vivek", "FDE")
print(vars(t))  # {'name': 'Vivek', 'track': 'FDE'}
```

---

## 5. Viewing Built-In Documentation: `help()`
Invokes Python's built-in help system to display an object's docstring, method signatures, and class hierarchy.
```python
# Inspect documentation for a data type or specific method
help(str.split)
```

---

## 6. Quick Reference

| Function | Purpose | Return Value |
| :--- | :--- | :--- |
| `type(obj)` | Identifies the exact class of an object | Class/type object (e.g., `<class 'int'>`) |
| `isinstance(obj, T)` | Checks if `obj` is an instance or subclass of `T` | `bool` (`True` or `False`) |
| `id(obj)` | Retrieves the unique memory identity of an object | `int` |
| `dir(obj)` | Lists all attributes and methods of an object | `list` of `str` |
| `hasattr(obj, name)` | Checks if an object has a specific attribute | `bool` (`True` or `False`) |
| `getattr(obj, name, default)` | Retrieves an attribute value dynamically | Attribute value or `default` |
| `vars(obj)` | Displays writable attributes of an object | `dict` |
| `help(obj)` | Displays formatted documentation and docstrings | Prints to console (`None`) |
