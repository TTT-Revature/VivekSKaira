# Type Conversion

## 1. Overview
**Type conversion** is the process of converting a value from one data type to another. In Python, type conversion falls into two categories:
1. **Implicit Type Conversion (Type Coercion):** Performed automatically by the Python interpreter.
2. **Explicit Type Conversion (Type Casting):** Performed manually by the developer using built-in functions.

---

## 2. Implicit Type Conversion (Type Coercion)
Python automatically converts smaller or narrower data types into larger or wider data types during mixed-type operations to prevent data loss.

```python
num_int = 10        # int
num_float = 2.5     # float

result = num_int + num_float
print(result)        # 12.5
print(type(result))  # <class 'float'> (int automatically promoted to float)

# Boolean to Integer coercion (True = 1, False = 0)
total = 5 + True
print(total)         # 6
```

*Because Python is **strongly typed**, it will not implicitly convert between incompatible types such as `int` and `str`:*
```python
# Raises TypeError: unsupported operand type(s) for +: 'int' and 'str'
# print(10 + "20")
```

---

## 3. Explicit Type Conversion (Type Casting)
In explicit conversion, the programmer uses Python's built-in type constructor functions to convert an object to a required data type.

### Primitive Type Conversions

#### `int()` — Convert to Integer
Converts floats (by truncating the decimal part toward zero), booleans, or numeric strings into integers.
```python
print(int(3.99))      # 3 (truncates decimal, does not round)
print(int("42"))      # 42
print(int(True))      # 1
print(int("101", 2))  # 5 (converts base-2 binary string to base-10 int)
```

#### `float()` — Convert to Floating-Point
Converts integers, booleans, or numeric strings into floating-point numbers.
```python
print(float(7))        # 7.0
print(float("19.75"))  # 19.75
print(float(False))    # 0.0
```

#### `str()` — Convert to String
Converts almost any Python object into its string representation.
```python
score = 95
message = "Final Score: " + str(score)
print(message)        # Final Score: 95
print(type(str(3.5))) # <class 'str'>
```

#### `bool()` — Convert to Boolean
Evaluates an object's truthiness and returns either `True` or `False`.
* **Falsy values (evaluate to `False`):** `0`, `0.0`, `0j`, `""` (empty string), `[]`, `()`, `{}`, `set()`, `None`, `False`
* **Truthy values (evaluate to `True`):** All non-zero numbers and non-empty sequences/collections.

```python
print(bool(0))        # False
print(bool(""))       # False
print(bool([]))       # False
print(bool(-1))       # True
print(bool("False"))  # True (non-empty string)
```

---

### Collection Type Conversions
Built-in functions can also convert between sequence and collection types:

```python
text = "ABC"
print(list(text))     # ['A', 'B', 'C']
print(tuple(text))    # ('A', 'B', 'C')

nums = [1, 2, 2, 3]
print(set(nums))      # {1, 2, 3} (removes duplicates)

pairs = [("a", 1), ("b", 2)]
print(dict(pairs))    # {'a': 1, 'b': 2}
```

---

## 4. Common Conversion Errors (`ValueError` & `TypeError`)

1. **Invalid String Format (`ValueError`):**
   ```python
   # int("hello")   # Raises ValueError: invalid literal for int()
   ```
2. **Float String Directly to Integer (`ValueError`):**
   `int()` cannot parse a string containing a decimal point directly; convert to `float` first.
   ```python
   # int("12.5")         # Raises ValueError
   val = int(float("12.5"))  # Works -> 12
   ```
3. **Incompatible Collection to Dictionary (`TypeError` / `ValueError`):**
   `dict()` requires an iterable of key-value pairs (each element must have length 2).
   ```python
   # dict([1, 2, 3])     # Raises TypeError: cannot convert dictionary update sequence
   ```

---

## 5. Quick Reference

| Function | Target Type | Example | Output |
| :--- | :--- | :--- | :--- |
| `int(x)` | `int` | `int("25")` | `25` |
| `float(x)` | `float` | `float(10)` | `10.0` |
| `str(x)` | `str` | `str(100)` | `'100'` |
| `bool(x)` | `bool` | `bool(0)` | `False` |
| `list(x)` | `list` | `list((1, 2))` | `[1, 2]` |
| `tuple(x)` | `tuple` | `tuple([1, 2])` | `(1, 2)` |
| `set(x)` | `set` | `set([1, 1, 2])` | `{1, 2}` |
| `dict(x)` | `dict` | `dict([("k", "v")])` | `{'k': 'v'}` |
