# `sum()`, `sorted()`, `min()`, `max()`, and `reversed()` in Python

## 1. Overview
Python's built-in sequence and aggregation functions—**`sum()`**, **`sorted()`**, **`min()`**, **`max()`**, and **`reversed()`**—perform common reduction, ordering, and traversal operations without mutating the original input collection.

* **No Imports Required:** All five functions belong to Python's built-in `builtins` namespace.
* **Non-Destructive:** Unlike in-place methods such as `list.sort()` or `list.reverse()`, these built-ins leave the source iterable untouched.

---

## 2. `sum()` — Numeric Aggregation
**`sum(iterable, start=0)`** adds `start` and the items of an `iterable` from left to right and returns the total.

### Syntax and Parameters
* **`iterable`:** An iterable yielding numeric values (`int`, `float`, `bool`, `Decimal`, `Fraction`).
* **`start`:** Initial accumulator value added to the sum (defaults to `0`; can be passed positionally or as a keyword argument in Python 3.8+).

### Practical Examples
```python
import math

expenses = [1200.50, 450.25, 349.25]

# 1. Basic summation
total = sum(expenses)
print(total)  # 2000.0

# 2. Providing a non-zero starting balance
opening_balance = 5000.0
closing_balance = sum(expenses, start=opening_balance)
print(closing_balance)  # 7000.0

# 3. Counting items matching a condition (True == 1, False == 0)
scores = [85, 42, 91, 67, 74]
passed_count = sum(1 for score in scores if score >= 60)
print(passed_count)  # 4

# 4. High-precision floating-point summation with math.fsum()
floats = [0.1] * 10
print(sum(floats))        # 0.9999999999999999 (binary float rounding drift)
print(math.fsum(floats))  # 1.0 (exact compensated summation)
```

## 3. `sorted()` — Non-Mutating Sorting
**`sorted(iterable, *, key=None, reverse=False)`** consumes any iterable and returns a **new sorted `list`** using Python's **Timsort** algorithm ($O(n \log n)$ worst/average time, $O(n)$ best time).

### Syntax and Parameters
* **`iterable`:** Any iterable (`list`, `tuple`, `set`, `dict`, `str`, generator).
* **`key`:** Keyword-only 1-argument callable that extracts a comparison key from each element before sorting.
* **`reverse`:** Keyword-only `bool`; if `True`, sorts in descending order (defaults to `False`).

### Practical Examples
```python
from operator import itemgetter

# 1. Sorting strings case-insensitively
names = ["vivek", "Aarav", "rashi", "Karan"]
print(sorted(names, key=str.lower))
# ['Aarav', 'Karan', 'rashi', 'vivek']

# 2. Sorting records by a specific dictionary field using itemgetter
trainees = [
    {"name": "Vivek", "score": 92, "attempts": 1},
    {"name": "Aarav", "score": 95, "attempts": 2},
    {"name": "Rashi", "score": 92, "attempts": 2},
]

by_score_desc = sorted(trainees, key=itemgetter("score"), reverse=True)
print([t["name"] for t in by_score_desc])
# ['Aarav', 'Vivek', 'Rashi']

# 3. Multi-criteria sorting: highest score first, then fewest attempts ascending
ranked = sorted(trainees, key=lambda t: (-t["score"], t["attempts"]))
print([t["name"] for t in ranked])
# ['Aarav', 'Rashi', 'Vivek']
```

### Sort Stability
Python's `sorted()` is **guaranteed to be stable**: when multiple records share the exact same sort key, their original relative order is preserved (as seen with `"Vivek"` remaining ahead of `"Rashi"` in `by_score_desc` above).

### `sorted()` vs. `list.sort()`

| Feature | `sorted(iterable)` | `list.sort()` |
| :--- | :--- | :--- |
| **Supported Inputs** | Any iterable (`list`, `tuple`, `set`, `dict`, generator) | `list` objects only |
| **Mutation** | Non-mutating (leaves original unchanged) | Mutates the list **in place** |
| **Return Value** | A new `list` | `None` |
| **Memory Overhead** | Allocates a new list ($O(n)$ extra space) | Sorts in place ($O(1)$ auxiliary space) |

## 4. `min()` and `max()` — Finding Extremes
**`min()`** and **`max()`** return the smallest or largest item in an iterable, or among two or more positional arguments.

### Two Call Signatures
```python
# Form 1: Single iterable (supports keyword-only `default`)
min(iterable, *, key=None, default=...)
max(iterable, *, key=None, default=...)

# Form 2: Two or more positional arguments
min(arg1, arg2, *args, key=None)
max(arg1, arg2, *args, key=None)
```

### Practical Examples
```python
# 1. Comparing positional values (useful for clamping bounds)
raw_value = 125
clamped_value = max(0, min(raw_value, 100))
print(clamped_value)  # 100

# 2. Finding extreme objects using `key` (returns the original object, not the key)
words = ["python", "api", "architecture", "cli"]
longest_word = max(words, key=len)
shortest_word = min(words, key=len)
print(longest_word, shortest_word)  # architecture api

# 3. Safe handling of potentially empty iterables using `default`
empty_readings: list[float] = []
peak_reading = max(empty_readings, default=0.0)
print(peak_reading)  # 0.0

# 4. Finding dictionary key with the highest value
latency_ms = {"auth_service": 42, "billing_service": 118, "search_service": 65}
slowest_service = max(latency_ms, key=latency_ms.__getitem__)
print(slowest_service)  # billing_service
```

* **Tie-Breaking Behavior:** If multiple items share the minimum or maximum value, `min()` and `max()` always return the **first** matching item encountered.

## 5. `reversed()` — Reverse Sequence Iteration
**`reversed(seq)`** returns a **reverse iterator** that yields elements from back to front on demand without copying the underlying sequence.

### Requirements for `reversed()`
An object passed to `reversed()` must implement either:
1. The **`__reversed__()`** special method (supported by `list`, `tuple`, `str`, `range`, `bytes`, and Python 3.7+ `dict` / `dict.keys()` / `dict.values()` / `dict.items()`), **or**
2. The sequence protocol: both **`__len__()`** and integer-indexed **`__getitem__()`** starting at `0`.

*(Unordered collections like `set` and single-pass generators do not support `reversed()` directly.)*

### Practical Examples
```python
checkpoints = ["init", "build", "test", "deploy"]

# 1. Lazy backward traversal in a loop
for stage in reversed(checkpoints):
    print(stage)
# Output: deploy -> test -> build -> init

# 2. Reversing a string into a new string
word = "Revature"
reversed_word = "".join(reversed(word))
print(reversed_word)  # erutaveR

# 3. Reversing a range without allocating a list
countdown = list(reversed(range(1, 6)))
print(countdown)  # [5, 4, 3, 2, 1]

# 4. Iterating over dictionary insertion order in reverse
status_codes = {200: "OK", 404: "Not Found", 500: "Server Error"}
for code, label in reversed(status_codes.items()):
    print(f"{code}: {label}")
```

### `reversed(seq)` vs. Slicing (`seq[::-1]`)

| Aspect | `reversed(seq)` | `seq[::-1]` |
| :--- | :--- | :--- |
| **Return Type** | Lazy iterator (`reversed` / `list_reverseiterator`) | Full shallow copy of the same sequence type |
| **Auxiliary Memory** | $O(1)$ (yields one item at a time) | $O(n)$ (duplicates all element references) |
| **Supported Types** | Sequences with `__reversed__()` or `__len__` + `__getitem__`, plus `dict` views | Sliceable sequences (`list`, `tuple`, `str`, `bytes`, `range`) |
| **Best Use Case** | Iterating backward once over large sequences | Creating a new reversed `list`, `tuple`, or `str` |

## 6. Common Pitfalls and Best Practices

1. **Using `sum()` to Concatenate Strings or Flatten Large Lists:**
   Calling `sum(["a", "b"], "")` raises `TypeError: sum() can't sum strings [use ''.join(seq) instead]`. Similarly, `sum(list_of_lists, [])` exhibits quadratic $O(n^2)$ time complexity because it allocates a new intermediate list on every step. Use `"".join(strings)` for strings and `itertools.chain.from_iterable(lists)` for flattening nested iterables.
2. **Assigning the Return Value of `list.sort()` Instead of `sorted()`:**
   `items = items.sort()` sets `items` to `None` because `.sort()` mutates in place and returns `None`. Use `items = sorted(items)` when you need a returned list, or call `items.sort()` as a standalone statement.
3. **Calling `min()` or `max()` on an Empty Iterable Without `default`:**
   Passing an empty list or exhausted generator to `min([])` or `max([])` raises `ValueError: max() iterable argument is empty`. Always provide `default=...` whenever the input iterable may be empty.
4. **Comparing Unorderable Types in Python 3:**
   Calling `sorted([1, "two", 3])` or `min([None, 5])` raises `TypeError: '<' not supported between instances of ...`. Ensure all elements (or all values produced by `key=...`) are mutually comparable.
5. **Treating `reversed(seq)` as a List or Reusing It Twice:**
   `reversed([1, 2, 3])` returns an iterator object, not `[3, 2, 1]`. Wrap it in `list(...)` or `tuple(...)` if you need indexing, length checks, or multiple iterations.

## 7. Quick Reference

| Function | Signature | Returns | Auxiliary Memory | Key Options |
| :--- | :--- | :--- | :--- | :--- |
| **`sum()`** | `sum(iterable, start=0)` | Numeric total (`int` / `float`) | $O(1)$ | `start` initial offset |
| **`sorted()`** | `sorted(iterable, *, key=None, reverse=False)` | New `list` (stable Timsort) | $O(n)$ | `key` extractor, `reverse=True` |
| **`min()`** | `min(iterable, *, key=None, default=...)` | Smallest element | $O(1)$ | `key` extractor, `default` fallback |
| **`max()`** | `max(iterable, *, key=None, default=...)` | Largest element | $O(1)$ | `key` extractor, `default` fallback |
| **`reversed()`** | `reversed(seq)` | Reverse iterator | $O(1)$ | Requires `__reversed__()` or sequence protocol |
