# Working with Filesystem Paths (`pathlib`)

## 1. Overview
Introduced in Python 3.4 (PEP 428), the built-in **`pathlib`** module provides an **object-oriented interface** for working with filesystem paths, replacing legacy string-based path manipulation (`os.path`).

* **Path Objects Over Raw Strings:** Represents file and directory paths as rich `Path` objects rather than plain strings, exposing intuitive methods and properties directly on the path instance.
* **Cross-Platform Portability:** Automatically handles forward slashes (`/`) on POSIX systems (Linux, macOS) and backslashes (`\`) on Windows via `PosixPath` and `WindowsPath` subclasses.
* **Unified API:** Combines path parsing, directory traversal, metadata inspection, and simple file I/O into a single module.

---

## 2. Creating and Joining `Path` Objects

### Instantiating Paths
```python
from pathlib import Path

# 1. Relative path
rel_path = Path("data/reports/summary.csv")

# 2. Current working directory and user home directory
cwd = Path.cwd()
home = Path.home()

print("CWD :", cwd)
print("Home:", home)

# 3. Expanding '~' to the user's home directory
config_path = Path("~/projects/fde_notes/README.md").expanduser()
```

### Joining Paths with the `/` Operator
`Path` overloads the division operator (`/`) to join path segments safely across operating systems (at least one operand must be a `Path` object):

```python
from pathlib import Path

base_dir = Path("/var/log")
app_log = base_dir / "services" / "auth" / "error.log"

print(app_log)        # /var/log/services/auth/error.log
print(type(app_log))  # <class 'pathlib.PosixPath'> (or WindowsPath on Windows)
```

### Resolving Absolute Paths (`.resolve()`)
`.resolve()` converts a relative path into a canonical **absolute path**, eliminating redundant segments (`.` and `..`) and resolving symbolic links:

```python
from pathlib import Path

p = Path("data/../notes/python_pathlib.md")
print(p.is_absolute())  # False
print(p.resolve())      # e.g., /Users/vivek/fde_notes/notes/python_pathlib.md
```

## 3. Inspecting Path Components
Every `Path` object exposes read-only properties that dissect a path into its constituent parts without manual string splitting:

```text
Path:   /home/vivek/projects/archive.tar.gz
        |----------||-------| |-----||------|
          .parent    .stem     |     .suffix
                      (for single ext)
                    |---------------|
                         .name
```

```python
from pathlib import Path

file_path = Path("/home/vivek/projects/report_2026.csv")

print(file_path.name)       # 'report_2026.csv'   (final path component)
print(file_path.stem)       # 'report_2026'       (filename without final suffix)
print(file_path.suffix)     # '.csv'              (final file extension)
print(file_path.parent)     # PosixPath('/home/vivek/projects')
print(file_path.anchor)     # '/'                 (root/drive prefix, e.g., 'C:\\' on Windows)
print(file_path.parts)      # ('/', 'home', 'vivek', 'projects', 'report_2026.csv')

# Multiple extensions (.suffixes)
archive = Path("backup.tar.gz")
print(archive.suffix)       # '.gz'
print(archive.suffixes)     # ['.tar', '.gz']

# Climbing ancestor directories (.parents)
print(file_path.parents[0]) # PosixPath('/home/vivek/projects')
print(file_path.parents[1]) # PosixPath('/home/vivek')
```

## 4. Modifying Path Names and Extensions
`Path` objects are **immutable**. Methods that alter a filename or extension return a **new `Path` object** without modifying the original path or renaming files on disk:

```python
from pathlib import Path

src = Path("data/raw_scores.csv")

# 1. Replace the entire filename (.with_name)
renamed = src.with_name("cleaned_scores.csv")
print(renamed)      # data/cleaned_scores.csv

# 2. Replace only the file stem, keeping the extension (.with_stem - Python 3.9+)
versioned = src.with_stem("raw_scores_v2")
print(versioned)    # data/raw_scores_v2.csv

# 3. Replace or add a file extension (.with_suffix)
json_copy = src.with_suffix(".json")
print(json_copy)    # data/raw_scores.json
```

## 5. Checking Path Status and File Metadata
Before reading, creating, or deleting files, inspect filesystem state directly on the `Path` object:

```python
from pathlib import Path

target = Path("notes.md")

print(target.exists())      # True if path points to an existing file or directory
print(target.is_file())     # True if path exists and is a regular file
print(target.is_dir())      # True if path exists and is a directory
print(target.is_symlink())  # True if path is a symbolic link

# Retrieve OS metadata (size in bytes, modification timestamp)
if target.is_file():
    info = target.stat()
    print(f"Size: {info.st_size} bytes")
    print(f"Last modified (epoch): {info.st_mtime}")
```

## 6. Reading and Writing Files with `Path`

### One-Step Convenience Methods
For small-to-medium files, `Path` provides concise methods that open, read/write, and close the file automatically in a single call:

```python
from pathlib import Path

note_file = Path("summary.txt")

# 1. Write and read UTF-8 text
note_file.write_text("Module: pathlib\nStatus: Completed\n", encoding="utf-8")
content = note_file.read_text(encoding="utf-8")
print(content)

# 2. Write and read raw bytes
bin_file = Path("sample.bin")
bin_file.write_bytes(b"\x00\x01\x02\x03")
raw_data = bin_file.read_bytes()
print(raw_data)  # b'\x00\x01\x02\x03'
```

### Streaming Large Files with `.open()`
For large files or line-by-line iteration, use `path.open()` inside a `with` context manager:

```python
from pathlib import Path

log_path = Path("application.log")
with log_path.open(mode="r", encoding="utf-8") as f:
    for line in f:
        if "ERROR" in line:
            print(line.rstrip("\n"))
```

## 7. Directory Operations, Traversal, and Pattern Matching

### Creating, Renaming, and Deleting
```python
from pathlib import Path

# 1. Create nested directories safely
# parents=True creates missing parent folders; exist_ok=True avoids FileExistsError
output_dir = Path("build/reports/2026")
output_dir.mkdir(parents=True, exist_ok=True)

# 2. Create an empty file
temp_file = output_dir / "draft.txt"
temp_file.touch(exist_ok=True)

# 3. Rename or move a file (.replace overwrites destination if it exists)
final_file = output_dir / "final.txt"
temp_file.replace(final_file)

# 4. Delete a file (.unlink) and an empty directory (.rmdir)
final_file.unlink(missing_ok=True)  # missing_ok=True (Python 3.8+) prevents FileNotFoundError
output_dir.rmdir()                  # Removes directory (must be empty)
```

### Listing Contents and Globbing (`.iterdir()`, `.glob()`, `.rglob()`)
All directory traversal methods return **lazy generators** yielding `Path` objects:

```python
from pathlib import Path

project_dir = Path(".")

# 1. List immediate children (files and subdirectories)
for entry in project_dir.iterdir():
    kind = "DIR " if entry.is_dir() else "FILE"
    print(f"[{kind}] {entry.name}")

# 2. Match files in the current directory using wildcard patterns (.glob)
md_files = list(project_dir.glob("*.md"))

# 3. Recursively match files across all subdirectories (.rglob)
all_py_files = list(project_dir.rglob("*.py"))
print(f"Found {len(all_py_files)} Python files recursively.")
```

## 8. `pathlib.Path` vs. Legacy `os.path`

| Task | Legacy `os` / `os.path` | Modern `pathlib.Path` |
| :--- | :--- | :--- |
| **Join paths** | `os.path.join(base, "sub", "a.py")` | `base / "sub" / "a.py"` |
| **Current directory** | `os.getcwd()` | `Path.cwd()` |
| **Absolute path** | `os.path.abspath(p)` | `p.resolve()` |
| **Filename & stem** | `os.path.basename(p)`, `os.path.splitext(p)[0]` | `p.name`, `p.stem` |
| **File extension** | `os.path.splitext(p)[1]` | `p.suffix` |
| **Parent directory** | `os.path.dirname(p)` | `p.parent` |
| **Existence check** | `os.path.exists(p)`, `os.path.isfile(p)` | `p.exists()`, `p.is_file()` |
| **Create nested dirs** | `os.makedirs(p, exist_ok=True)` | `p.mkdir(parents=True, exist_ok=True)` |
| **Delete file** | `os.remove(p)` | `p.unlink(missing_ok=True)` |
| **Recursive search** | `glob.glob("**/*.py", recursive=True)` | `p.rglob("*.py")` |

## 9. Quick Reference

| Member / Method | Type | Description |
| :--- | :--- | :--- |
| `Path(str_or_path)` | Constructor | Creates a platform-appropriate `Path` object |
| `p1 / p2` | Operator | Joins path segments cleanly |
| `p.name` / `p.stem` / `p.suffix` | Properties | Extracts full filename, name without extension, and extension |
| `p.parent` / `p.parents` | Properties | Accesses immediate parent directory or indexed ancestors |
| `p.with_name()` / `.with_suffix()` | Methods | Returns a new `Path` with updated filename or extension |
| `p.exists()` / `.is_file()` / `.is_dir()` | Methods | Checks filesystem existence and entry type |
| `p.read_text()` / `.write_text()` | Methods | Reads or writes entire UTF-8 text file in a single call |
| `p.mkdir(parents=True, exist_ok=True)` | Method | Creates directory and any missing parent directories |
| `p.iterdir()` / `.glob()` / `.rglob()` | Methods | Yields child `Path` entries directly or via wildcard matching |
| `p.unlink(missing_ok=True)` | Method | Deletes a file or symbolic link |
