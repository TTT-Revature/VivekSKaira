# Working with Dates and Times (`datetime`, `date`, `time`, `timedelta`)

## 1. Overview
Python's built-in **`datetime`** module provides object-oriented classes for representing, manipulating, formatting, and performing arithmetic on dates, times, and durations.

* **Core Classes:**
  * **`date`:** Represents a calendar date (`year`, `month`, `day`) in the idealized Gregorian calendar.
  * **`time`:** Represents a time of day (`hour`, `minute`, `second`, `microsecond`, `tzinfo`) independent of any specific date.
  * **`datetime`:** Combines both `date` and `time` attributes into a single timestamp object.
  * **`timedelta`:** Represents a duration—the difference between two `date`, `time`, or `datetime` instances.
* **Immutability:** All `date`, `time`, `datetime`, and `timedelta` objects are **immutable** and hashable (they can be used as dictionary keys or set elements). Operations like `.replace()` or addition return new objects rather than modifying existing ones in place.
* **Naive vs. Aware Objects:**
  * **Naive:** Has no timezone information (`tzinfo is None`). Easier to construct, but ambiguous across regions or Daylight Saving Time (DST) transitions.
  * **Aware:** Includes a `tzinfo` object (such as `timezone.utc` or `zoneinfo.ZoneInfo`), unambiguously pinpointing an exact moment in universal time.

---

## 2. The `date` Class (`datetime.date`)
A `date` object stores `year` (`1` to `9999`), `month` (`1` to `12`), and `day` (`1` to days in that month).

### Creating and Inspecting Dates
```python
from datetime import date

# 1. Explicit construction
joined_date = date(2026, 11, 2)

# 2. Current local calendar date
today = date.today()

# 3. Parsing an ISO 8601 string ('YYYY-MM-DD')
parsed_date = date.fromisoformat("2026-11-22")

print(parsed_date.year, parsed_date.month, parsed_date.day)  # 2026 11 22
print(parsed_date.isoformat())                                # '2026-11-22'

# Day of the week:
# .weekday()    -> Monday is 0 ... Sunday is 6
# .isoweekday() -> Monday is 1 ... Sunday is 7
print("weekday()   :", parsed_date.weekday())     # 6 (Sunday)
print("isoweekday():", parsed_date.isoweekday())  # 7 (Sunday)

# Creating a modified copy with .replace()
next_year = parsed_date.replace(year=2027)
print(next_year)  # 2027-11-22
```

---

## 3. The `time` Class (`datetime.time`)
A `time` object stores `hour` (`0`–`23`), `minute` (`0`–`59`), `second` (`0`–`59`), `microsecond` (`0`–`999999`), and optional `tzinfo`. All arguments default to `0` (or `None` for `tzinfo`).

```python
from datetime import time

# 1. Explicit construction (24-hour clock)
standup = time(hour=9, minute=30, second=0)

# 2. Parsing an ISO 8601 time string
cutoff = time.fromisoformat("17:45:30")

print(standup.hour, standup.minute, standup.second)  # 9 30 0
print(cutoff.isoformat())                            # '17:45:30'

# Creating a modified copy
updated_standup = standup.replace(minute=45)
print(updated_standup)  # 09:45:00
```

## 4. The `datetime` Class (`datetime.datetime`)
A `datetime` object is a subclass of `date` that includes all attributes of both `date` and `time`.

### Creating and Extracting Components
```python
from datetime import date, time, datetime, timezone

# 1. Explicit construction
session_start = datetime(2026, 11, 22, 10, 0, 0)

# 2. Current local naive datetime vs. timezone-aware UTC datetime
local_now = datetime.now()
utc_now = datetime.now(timezone.utc)

# 3. Combining separate date and time objects
d = date(2026, 11, 22)
t = time(14, 30)
combined = datetime.combine(d, t)

# 4. Extracting date, time, and POSIX Unix timestamp
print(combined.date())       # 2026-11-22
print(combined.time())       # 14:30:00
print(utc_now.timestamp())   # Float seconds since 1970-01-01T00:00:00Z
```

### Working with Named Timezones (`zoneinfo.ZoneInfo`)
Python's standard **`zoneinfo`** module (Python 3.9+) provides access to the IANA timezone database so you can convert between regions accurately:

```python
from datetime import datetime, timezone
from zoneinfo import ZoneInfo

utc_dt = datetime(2026, 11, 22, 17, 30, tzinfo=timezone.utc)

# Convert UTC datetime to Indian Standard Time (Asia/Kolkata)
ist_dt = utc_dt.astimezone(ZoneInfo("Asia/Kolkata"))
print("UTC:", utc_dt.isoformat())  # 2026-11-22T17:30:00+00:00
print("IST:", ist_dt.isoformat())  # 2026-11-22T23:00:00+05:30
```
*(Note: Never mix naive and aware `datetime` objects in comparisons or subtraction—doing so raises `TypeError: can't subtract offset-naive and offset-aware datetimes`.)*

## 5. Formatting and Parsing (`strftime` vs. `strptime`)
Python uses C-style format codes to convert between date/time objects and custom text representations:

* **`obj.strftime(fmt)` ("string format time"):** Formats a `date`, `time`, or `datetime` object **into a `str`**.
* **`datetime.strptime(text, fmt)` ("string parse time"):** Parses a formatted `str` **into a `datetime` object**.

```python
from datetime import datetime

now = datetime(2026, 11, 22, 22, 59, 0)

# 1. Formatting a datetime into a human-readable string
formatted = now.strftime("%A, %d %b %Y at %I:%M %p")
print(formatted)  # 'Sunday, 22 Nov 2026 at 10:59 PM'

# 2. Parsing a custom date string back into a datetime object
log_timestamp = "22/11/2026 14:15:05"
parsed = datetime.strptime(log_timestamp, "%d/%m/%Y %H:%M:%S")
print(repr(parsed))  # datetime.datetime(2026, 11, 22, 14, 15, 5)
```

### Common Format Specifiers

| Directive | Meaning | Example Output |
| :--- | :--- | :--- |
| `%Y` | 4-digit year | `2026` |
| `%y` | 2-digit year (zero-padded) | `26` |
| `%m` | Month as zero-padded decimal (`01`–`12`) | `11` |
| `%B` / `%b` | Full / abbreviated month name | `November` / `Nov` |
| `%d` | Day of the month (`01`–`31`) | `22` |
| `%A` / `%a` | Full / abbreviated weekday name | `Sunday` / `Sun` |
| `%H` | Hour on 24-hour clock (`00`–`23`) | `22` |
| `%I` | Hour on 12-hour clock (`01`–`12`) | `10` |
| `%p` | Locale AM or PM indicator | `PM` |
| `%M` | Minute (`00`–`59`) | `59` |
| `%S` | Second (`00`–`59`) | `05` |
| `%f` | Microsecond (`000000`–`999999`) | `450000` |
| `%z` | UTC offset (`+HHMM` or `-HHMM`) | `+0530` |
| `%Z` | Timezone name | `IST` or `UTC` |

*(Tip: When working with standard ISO 8601 strings such as `"2026-11-22T22:59:00+05:30"`, prefer `datetime.fromisoformat()` and `.isoformat()` over `strptime`/`strftime`—they are faster and handle variable fractional seconds and timezone offsets automatically.)*

## 6. Duration and Date Arithmetic (`datetime.timedelta`)
A **`timedelta`** object represents a span of time. You can initialize it using any combination of `weeks`, `days`, `hours`, `minutes`, `seconds`, `milliseconds`, and `microseconds`.

### Internal Normalization
Internally, `timedelta` normalizes all arguments into just three attributes: **`days`**, **`seconds`** (`0` to `86399`), and **`microseconds`** (`0` to `999999`). Use **`.total_seconds()`** to obtain the entire duration expressed as a single `float` in seconds.

```python
from datetime import datetime, timedelta

# Creating a timedelta
sprint_length = timedelta(weeks=2, days=1, hours=4, minutes=30)
print("Normalized days   :", sprint_length.days)            # 15
print("Normalized seconds:", sprint_length.seconds)         # 16200 (4h 30m)
print("Total seconds     :", sprint_length.total_seconds()) # 1312200.0
```

### Supported Arithmetic Operations

| Operation | Result Type | Example |
| :--- | :--- | :--- |
| `datetime + timedelta` | `datetime` | Shifts timestamp forward by duration |
| `datetime - timedelta` | `datetime` | Shifts timestamp backward by duration |
| `datetime2 - datetime1` | `timedelta` | Computes exact elapsed duration between two timestamps |
| `date2 - date1` | `timedelta` | Computes exact number of days between two dates |
| `timedelta1 + timedelta2` | `timedelta` | Adds two durations together |
| `timedelta * int` (or `float`) | `timedelta` | Scales a duration by a numeric factor |
| `timedelta1 / timedelta2` | `float` | Computes the ratio between two durations |

```python
from datetime import date, datetime, timedelta

# 1. Calculating future deadlines and past dates
today = date(2026, 11, 22)
deadline = today + timedelta(days=90)
print("90-day FDE target date:", deadline)  # 2027-02-20

# 2. Measuring elapsed duration between two datetimes
start = datetime(2026, 11, 22, 9, 0, 0)
end = datetime(2026, 11, 22, 17, 45, 30)
elapsed = end - start

print("Elapsed:", elapsed)                        # 8:45:30
print("Hours worked:", elapsed / timedelta(hours=1))  # 8.758333333333333
```

*(Note: `timedelta` does not accept `months` or `years` because calendar months and years vary in length—28 to 31 days and 365 vs. 366 days.)*

## 7. Quick Reference

| Class / Method | Purpose | Key Notes |
| :--- | :--- | :--- |
| `date(y, m, d)` / `date.today()` | Represents a calendar date | `.weekday()` is `0`–`6` (Mon–Sun); `.isoweekday()` is `1`–`7` |
| `time(h, m, s, us, tzinfo)` | Represents time of day | Independent of date; defaults to `00:00:00` |
| `datetime(y, m, d, h, m, s)` | Represents combined date and time | Supports `.date()`, `.time()`, `.timestamp()`, `.astimezone()` |
| `datetime.now(timezone.utc)` | Returns current timezone-aware UTC datetime | Prefer over deprecated `datetime.utcnow()` |
| `timedelta(days=..., hours=...)` | Represents a time duration | Stores `days`, `seconds`, `microseconds`; use `.total_seconds()` |
| `obj.strftime(fmt)` | Formats `date`/`time`/`datetime` to `str` | Uses `%Y`, `%m`, `%d`, `%H`, `%M`, `%S`, etc. |
| `datetime.strptime(s, fmt)` | Parses formatted `str` to `datetime` | Raises `ValueError` if string does not match `fmt` |
| `.isoformat()` / `.fromisoformat()` | Converts to/from ISO 8601 strings | Standard format for APIs, logs, and JSON serialization |
