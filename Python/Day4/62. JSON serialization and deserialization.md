# JSON Serialization and Deserialization

## 1. Overview
**JSON (JavaScript Object Notation)** is a lightweight, human-readable, language-independent data interchange format widely used in REST APIs, configuration files, and data pipelines. Python provides built-in support for JSON via the standard library **`json`** module.

* **Serialization (Encoding):** Converting in-memory Python objects (such as dictionaries and lists) into a JSON-formatted string or writing them to a file/stream (`json.dumps()`, `json.dump()`).
* **Deserialization (Decoding):** Parsing a JSON-formatted string or file/stream back into native Python objects (`json.loads()`, `json.load()`).

*(Memory Aid: Functions ending in **`s`**—`dumps` and `loads`—operate on **strings**; functions without `s`—`dump` and `load`—operate on **file streams**.)*

---

## 2. Python-to-JSON Type Conversion Table
When serializing and deserializing data, Python maps native data types to JSON types according to the following rules:

| Python Type | JSON Type | Notes on Round-Trip Conversion |
| :--- | :--- | :--- |
| `dict` | `object` | JSON keys must be strings; non-string keys (`int`, `float`, `bool`) are converted to `str` |
| `list`, `tuple` | `array` | Both serialize to a JSON array `[...]`, which always deserializes back as a Python `list` |
| `str` | `string` | Always enclosed in double quotes `""` in JSON |
| `int`, `float` | `number` | `NaN`, `Infinity`, and `-Infinity` are non-standard JSON (disallowed if `allow_nan=False`) |
| `True` / `False` | `true` / `false` | Lowercase in JSON |
| `None` | `null` | Lowercase `null` in JSON |

```python
import json

# Demonstrating round-trip loss of tuple and integer dictionary keys
original = {1: ("Python", "SQL"), 2: ("Git", "Docker")}
json_str = json.dumps(original)
restored = json.loads(json_str)

print(json_str)  # '{"1": ["Python", "SQL"], "2": ["Git", "Docker"]}'
print(restored)  # {'1': ['Python', 'SQL'], '2': ['Git', 'Docker']}
```

## 3. Serialization (`json.dumps()` and `json.dump()`)

### 1. Serializing to a String (`json.dumps()`)
Converts a Python object into a JSON-formatted `str`.

* **`indent`:** Formats output with pretty-printed indentation (e.g., `indent=2` or `indent=4`).
* **`sort_keys`:** Sorts dictionary keys alphabetically when set to `True`.
* **`ensure_ascii`:** Defaults to `True` (escapes non-ASCII characters as `\uXXXX`); set to `False` to preserve Unicode characters directly.
* **`separators`:** Tuple `(item_separator, key_separator)`—use `(",", ":")` to strip whitespace for compact payloads.

```python
import json

trainee = {
    "id": 101,
    "name": "Vivek",
    "track": "FDE",
    "active": True,
    "certifications": None,
    "skills": ["Python", "SQL", "Git"]
}

# Compact JSON string (default)
compact_json = json.dumps(trainee)
print(compact_json)

# Pretty-printed JSON string for readability or logging
pretty_json = json.dumps(trainee, indent=4, sort_keys=True)
print(pretty_json)
```

### 2. Serializing Directly to a File (`json.dump()`)
Writes serialized JSON directly to an open text file stream using a `with` context manager:

```python
import json
from pathlib import Path

records = [
    {"module": "Functions", "score": 92},
    {"module": "File I/O", "score": 95}
]

output_path = Path("scores.json")
with output_path.open(mode="w", encoding="utf-8") as f:
    json.dump(records, f, indent=4)
```

## 4. Deserialization (`json.loads()` and `json.load()`)

### 1. Deserializing from a String (`json.loads()`)
Parses a JSON `str` (or UTF-8 `bytes`) and returns the corresponding Python object:

```python
import json

raw_payload = '{"id": 101, "name": "Vivek", "completed": true, "score": 94.5}'
data = json.loads(raw_payload)

print(type(data))       # <class 'dict'>
print(data["name"])     # 'Vivek'
print(data["score"])    # 94.5
```

### 2. Deserializing from a File (`json.load()`)
Reads JSON content from an open file object and converts it into Python objects:

```python
import json
from pathlib import Path

input_path = Path("scores.json")
with input_path.open(mode="r", encoding="utf-8") as f:
    loaded_records = json.load(f)

for item in loaded_records:
    print(f"{item['module']}: {item['score']}")
```

### Handling Malformed JSON (`json.JSONDecodeError`)
If the input string or file contains invalid JSON syntax (such as single quotes, trailing commas, or truncated text), `json.loads()` and `json.load()` raise **`json.JSONDecodeError`** (a subclass of `ValueError`):

```python
import json

invalid_json = "{'name': 'Vivek',}"  # Single quotes and trailing comma are invalid in JSON

try:
    parsed = json.loads(invalid_json)
except json.JSONDecodeError as err:
    print(f"Invalid JSON at line {err.lineno}, column {err.colno}: {err.msg}")
```

## 5. Handling Non-Serializable Types
By default, `json.dumps()` only supports basic built-in types (`dict`, `list`, `tuple`, `str`, `int`, `float`, `bool`, `None`). Passing types such as `set`, `datetime`, `Path`, `Decimal`, or custom class instances raises a **`TypeError: Object of type ... is not JSON serializable`**.

### 1. Custom Serialization with the `default` Function
Pass a `default` callback function to `json.dumps()` or `json.dump()`. Python invokes `default(obj)` whenever it encounters an object it does not natively know how to serialize:

```python
import json
from datetime import date, datetime
from pathlib import Path

def custom_serializer(obj):
    if isinstance(obj, (date, datetime)):
        return obj.isoformat()
    if isinstance(obj, set):
        return sorted(obj)
    if isinstance(obj, Path):
        return str(obj)
    raise TypeError(f"Object of type {type(obj).__name__} is not JSON serializable")

event = {
    "title": "FDE Assessment",
    "date": date(2026, 11, 22),
    "tags": {"python", "json", "serialization"},
    "report_path": Path("reports/assessment.json")
}

print(json.dumps(event, default=custom_serializer, indent=2))
```

### 2. Custom Deserialization with `object_hook`
Pass an `object_hook` function to `json.loads()` or `json.load()`. Python passes every decoded JSON object (`dict`) through `object_hook` so you can reconstruct specialized Python types:

```python
import json
from datetime import date

def decode_dates(dct: dict) -> dict:
    if "date" in dct and isinstance(dct["date"], str):
        dct["date"] = date.fromisoformat(dct["date"])
    return dct

payload = '{"title": "FDE Assessment", "date": "2026-11-22"}'
parsed_event = json.loads(payload, object_hook=decode_dates)

print(parsed_event["date"], type(parsed_event["date"]))
# Output: 2026-11-22 <class 'datetime.date'>
```

## 6. Quick Reference

| Function / Class | Direction | Input / Output | Common Parameters |
| :--- | :--- | :--- | :--- |
| `json.dumps(obj, ...)` | Serialize | Python object -> JSON `str` | `indent`, `sort_keys`, `ensure_ascii`, `default`, `separators` |
| `json.dump(obj, fp, ...)` | Serialize | Python object -> File stream `fp` | `indent`, `sort_keys`, `ensure_ascii`, `default` |
| `json.loads(s, ...)` | Deserialize | JSON `str` / `bytes` -> Python object | `object_hook`, `parse_float`, `parse_int` |
| `json.load(fp, ...)` | Deserialize | File stream `fp` -> Python object | `object_hook`, `parse_float`, `parse_int` |
| `json.JSONDecodeError` | Exception | Raised on malformed JSON input | Exposes `.msg`, `.lineno`, `.colno`, `.pos` |
