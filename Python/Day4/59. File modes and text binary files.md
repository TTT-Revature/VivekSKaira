# File Modes and Text/Binary Files

## 1. Overview
When opening a file with Python's built-in `open(file, mode="r", ...)` function, the **`mode`** string tells the operating system and Python interpreter two things:

1. **Access Operation:** Whether the file is opened for reading (`'r'`), writing (`'w'`), appending (`'a'`), exclusive creation (`'x'`), or simultaneous read/write (`'+'`).
2. **Data Representation:** Whether the file contents are processed as decoded text strings (`'t'`, default) or raw byte sequences (`'b'`).

```python
# Combining access mode ('w') and format mode ('b')
with open("output.bin", mode="wb") as f:
    f.write(b"\x89PNG\r\n\x1a\n")
```

---

## 2. Primary Access Modes (`r`, `w`, `a`, `x`)

### 1. Read Mode (`'r'` — Default)
* **Behavior:** Opens an existing file for reading only.
* **Pointer Position:** Start of the file (offset `0`).
* **Errors:** Raises `FileNotFoundError` if the file does not exist; raises `io.UnsupportedOperation` if you attempt to write to it.

### 2. Write Mode (`'w'`)
* **Behavior:** Opens a file for writing. If the file already exists, it is **immediately truncated to zero bytes** (all prior content is erased). If it does not exist, a new empty file is created.
* **Pointer Position:** Start of the file (offset `0`).

### 3. Append Mode (`'a'`)
* **Behavior:** Opens a file for writing without erasing existing content. If the file does not exist, a new file is created.
* **Pointer Position:** End of the file (EOF). Every `.write()` call appends data strictly at the end of the file, even if `.seek()` was called beforehand.

### 4. Exclusive Creation Mode (`'x'`)
* **Behavior:** Creates a brand-new file and opens it for writing **only if the file does not already exist**.
* **Errors:** Raises `FileExistsError` if a file at that path already exists—preventing accidental data loss from overwriting.

```python
# 1. Create a new file safely ('x')
with open("audit.log", mode="x", encoding="utf-8") as f:
    f.write("2026-11-22: Log initialized\n")

# 2. Append subsequent entries without erasing prior lines ('a')
with open("audit.log", mode="a", encoding="utf-8") as f:
    f.write("2026-11-22: Batch job completed\n")

# 3. Read back all contents ('r')
with open("audit.log", mode="r", encoding="utf-8") as f:
    print(f.read())
```

---

## 3. Read/Write Combined Modes (`+` Modifier)
Appending **`+`** to any primary mode enables **both reading and writing** on the same open file stream (`'r+'`, `'w+'`, `'a+'`). Despite sharing read/write capability, their initial behavior differs significantly:

### `'r+'` (Read and Write — No Truncation)
* Requires the file to exist (`FileNotFoundError` otherwise).
* Preserves existing content and places the cursor at the beginning (`0`). Writing overwrites existing bytes/characters starting at the current cursor position.

### `'w+'` (Write and Read — Truncates First)
* Creates the file if missing, or **erases all existing content** immediately upon opening.
* Places the cursor at `0`. After writing data, you must call `.seek(0)` to rewind the cursor before reading back what you wrote.

### `'a+'` (Append and Read — Writes Always at EOF)
* Creates the file if missing and preserves existing content.
* Places the initial cursor at the **end of the file** (EOF). To read existing content, you must call `.seek(0)` first. Any subsequent `.write()` automatically jumps back to the end of the file.

```python
# Demonstrating 'r+' in-place overwrite vs. 'a+' reading
with open("sample.txt", mode="w+", encoding="utf-8") as f:
    f.write("Hello World")
    f.seek(0)                   # Rewind to read
    print(f.read())             # 'Hello World'

with open("sample.txt", mode="r+", encoding="utf-8") as f:
    f.seek(6)                   # Move cursor to index 6 ('W')
    f.write("Python")           # Overwrites 'World' -> 'Hello Python'
    f.seek(0)
    print(f.read())             # 'Hello Python'
```

## 4. Text Files vs. Binary Files (`'t'` vs. `'b'`)
Every file on disk is ultimately stored as a sequence of bytes. Python's `'t'` and `'b'` modes control whether Python translates those bytes into human-readable characters or exposes them directly.

### Comparison Table

| Feature | Text Mode (`'t'`, default) | Binary Mode (`'b'`) |
| :--- | :--- | :--- |
| **Mode Strings** | `'r'`, `'rt'`, `'w'`, `'wt'`, `'a'`, `'r+'` | `'rb'`, `'wb'`, `'ab'`, `'xb'`, `'rb+'`, `'wb+'`, `'ab+'` |
| **Data Type Returned / Accepted** | `str` (Unicode text strings) | `bytes` (raw 8-bit byte sequences) |
| **Character Encoding** | Decodes bytes on read and encodes `str` on write using `encoding` | None (passing `encoding` raises `ValueError`) |
| **Newline Translation** | Converts platform line endings (`\r\n`, `\r`) to `\n` on read, and `\n` to OS default on write | None (preserves every `\r` and `\n` byte literally) |
| **Line-Oriented Methods** | `.readline()` and `for line in f:` split on text newlines | Splits strictly on byte `b"\n"` |
| **Typical File Types** | `.txt`, `.py`, `.md`, `.csv`, `.json`, `.sql`, `.log` | `.png`, `.jpg`, `.pdf`, `.mp3`, `.zip`, `.exe`, `.pkl` |

### Text Mode Example (`'rt'` / `'wt'`)
```python
# Text mode works exclusively with 'str' objects
with open("notes.txt", mode="wt", encoding="utf-8") as f:
    f.write("Line 1: Python\nLine 2: SQL\n")

with open("notes.txt", mode="rt", encoding="utf-8") as f:
    data = f.read()
    print(type(data))  # <class 'str'>
```

### Binary Mode Example (`'rb'` / `'wb'`)
```python
# Binary mode works exclusively with 'bytes' objects
raw_bytes = b"\x48\x65\x6c\x6c\x6f"  # ASCII bytes for 'Hello'

with open("data.bin", mode="wb") as f:
    f.write(raw_bytes)

with open("data.bin", mode="rb") as f:
    content = f.read()
    print(type(content))        # <class 'bytes'>
    print(content)              # b'Hello'
    print(content.decode("utf-8"))  # 'Hello'
```

*(Note: Passing a `str` to a file opened in `'wb'` mode, or passing `bytes` to a file opened in `'w'` mode, raises `TypeError`.)*

## 5. Practical Binary File Operations

### 1. Copying a Binary File in Chunks (Memory-Safe)
For large binary files (such as videos, archives, or model checkpoints), read and write fixed-size byte chunks (e.g., 4 KB or 64 KB) instead of loading the entire file into RAM:

```python
def copy_binary_file(source_path: str, dest_path: str, chunk_size: int = 4096) -> None:
    with open(source_path, mode="rb") as src, open(dest_path, mode="wb") as dst:
        while chunk := src.read(chunk_size):
            dst.write(chunk)
```

### 2. Inspecting File Signatures ("Magic Bytes")
Many binary formats start with specific header bytes that identify the file type regardless of its filename extension:

```python
with open("diagram.png", mode="rb") as f:
    header = f.read(8)

if header == b"\x89PNG\r\n\x1a\n":
    print("Verified valid PNG image header.")
```

## 6. Controlling Encoding and Newlines in Text Mode

### 1. Explicit UTF-8 Encoding and Error Handling
If `encoding` is omitted, Python uses `locale.getpreferredencoding()`, which varies across operating systems (for example, `cp1252` on some Windows setups vs. `UTF-8` on Linux/macOS). Always specify `encoding="utf-8"`:

```python
# Handling files that may contain malformed byte sequences
with open("legacy_export.txt", mode="r", encoding="utf-8", errors="replace") as f:
    # Unrecognized bytes are replaced with '\ufffd' instead of raising UnicodeDecodeError
    safe_text = f.read()
```

### 2. The `newline` Parameter
In text mode, `newline=""` disables universal newline translation while still decoding text characters—required when using Python's built-in `csv` module so embedded newlines inside quoted fields are preserved accurately:

```python
import csv

with open("records.csv", mode="w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["id", "name", "track"])
    writer.writerow([101, "Vivek", "FDE"])
```

## 7. Quick Reference: Complete File Mode Matrix

| Mode | Binary Variant | Read? | Write? | Creates File? | Truncates Existing? | Initial Cursor |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `'r'` / `'rt'` | `'rb'` | Yes | No | No (`FileNotFoundError`) | No | Beginning (`0`) |
| `'r+'` / `'rt+'` | `'rb+'` | Yes | Yes | No (`FileNotFoundError`) | No | Beginning (`0`) |
| `'w'` / `'wt'` | `'wb'` | No | Yes | Yes | Yes (erases all) | Beginning (`0`) |
| `'w+'` / `'wt+'` | `'wb+'` | Yes | Yes | Yes | Yes (erases all) | Beginning (`0`) |
| `'a'` / `'at'` | `'ab'` | No | Yes | Yes | No | End (EOF) |
| `'a+'` / `'at+'` | `'ab+'` | Yes | Yes | Yes | No | End (EOF) |
| `'x'` / `'xt'` | `'xb'` | No | Yes | Yes (`FileExistsError` if present) | N/A (new file) | Beginning (`0`) |
| `'x+'` / `'xt+'` | `'xb+'` | Yes | Yes | Yes (`FileExistsError` if present) | N/A (new file) | Beginning (`0`) |
