# Working with CSV Files (`csv` Module)

## 1. Overview
**CSV (Comma-Separated Values)** is a plain-text tabular file format where each line represents a data record and fields within a record are separated by a delimiter (typically a comma `,`). Python's built-in **`csv`** module provides dedicated readers and writers for parsing and generating CSV files safely.

* **Why Use `csv` Over `line.split(",")`?**
  * Properly handles fields containing **embedded commas** (e.g., `"Chennai, Tamil Nadu"`).
  * Preserves **multi-line fields** enclosed in quotation marks.
  * Automatically escapes and unescapes internal quote characters.
* **Critical `newline=""` Rule:** Always pass `newline=""` to `open()` (or `path.open()`) when reading or writing CSV files. This prevents Python's universal newline translation from corrupting embedded newlines inside quoted fields or inserting blank rows on Windows.

## 2. Reading CSV Files (`csv.reader` vs. `csv.DictReader`)

### 1. Reading Rows as Lists (`csv.reader`)
`csv.reader()` returns an iterator that yields each row as a **`list[str]`**. Every value is read as a string regardless of whether it looks like a number.

```python
import csv
from pathlib import Path

csv_path = Path("trainees.csv")

with csv_path.open(mode="r", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)

    # Extract header row safely (returns None if the file is empty)
    header = next(reader, None)
    print("Columns:", header)

    for row in reader:
        # row is a list[str], e.g., ['101', 'Vivek', 'FDE', '94.5']
        trainee_id, name, track, score = row
        print(f"ID: {trainee_id} | Name: {name} | Score: {float(score):.1f}")
```

### 2. Reading Rows as Dictionaries (`csv.DictReader`)
`csv.DictReader()` maps each row to a **`dict[str, str]`**, using the first row of the file as dictionary keys by default (access column names via `.fieldnames`).

```python
import csv
from pathlib import Path

csv_path = Path("trainees.csv")

with csv_path.open(mode="r", encoding="utf-8", newline="") as f:
    dict_reader = csv.DictReader(f)
    print("Detected headers:", dict_reader.fieldnames)

    for row in dict_reader:
        # Access columns by header name instead of positional index
        if row["track"] == "FDE":
            print(f"{row['name']} -> {row['score']}")
```

*(Note: If a CSV file has no header row, pass `fieldnames=["id", "name", "track", "score"]` explicitly to `csv.DictReader()`. If a row has fewer columns than `fieldnames`, missing keys default to `restval=None`.)*

## 3. Writing CSV Files (`csv.writer` vs. `csv.DictWriter`)

### 1. Writing Rows from Sequences (`csv.writer`)
`csv.writer()` converts iterables (such as lists or tuples) into delimited strings and writes them to the file stream.

* **`.writerow(row)`:** Writes a single record.
* **`.writerows(rows)`:** Writes multiple records from an iterable of sequences in one call.

```python
import csv
from pathlib import Path

headers = ["id", "name", "track", "score"]
records = [
    [101, "Vivek", "FDE", 94.5],
    [102, "Rashi", "Data Science", 91.0],
    [103, "Lakshya", "AI/ML", 89.5],
]

output_path = Path("results.csv")
with output_path.open(mode="w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(headers)
    writer.writerows(records)
```

### 2. Writing Rows from Dictionaries (`csv.DictWriter`)
`csv.DictWriter()` serializes dictionaries into CSV rows. You **must** specify the `fieldnames` sequence to define column order, and call **`.writeheader()`** explicitly if you want the header line written.

* **`extrasaction="raise"` (default):** Raises `ValueError` if a dictionary contains a key not listed in `fieldnames`.
* **`extrasaction="ignore"`:** Silently ignores any extra dictionary keys not in `fieldnames`.
* **`restval=""`:** Default value written if a dictionary is missing a key from `fieldnames`.

```python
import csv
from pathlib import Path

fieldnames = ["id", "name", "track"]
trainees = [
    {"id": 101, "name": "Vivek", "track": "FDE", "city": "Greater Noida"},
    {"id": 102, "name": "Rashi", "track": "Data Science"},
]

output_path = Path("roster.csv")
with output_path.open(mode="w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(
        f,
        fieldnames=fieldnames,
        extrasaction="ignore",
        restval="N/A",
    )
    writer.writeheader()
    writer.writerows(trainees)
```

## 4. Delimiters, Quoting Rules, and Dialects

### 1. Custom Delimiters (TSV, Semicolon, Pipe)
Pass the `delimiter` parameter to read or write non-comma-separated formats such as Tab-Separated Values (`.tsv`):

```python
import csv
from pathlib import Path

tsv_path = Path("metrics.tsv")
with tsv_path.open(mode="w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f, delimiter="\t")
    writer.writerow(["module", "duration_sec"])
    writer.writerow(["file_io", 12.4])
```

### 2. Quoting Constants (`quoting` Parameter)

| Constant | Behavior |
| :--- | :--- |
| `csv.QUOTE_MINIMAL` (default) | Quotes fields only when they contain special characters (`delimiter`, `quotechar`, or newlines) |
| `csv.QUOTE_ALL` | Encloses **every** field in quotes regardless of content |
| `csv.QUOTE_NONNUMERIC` | Quotes all non-numeric fields on write; converts unquoted fields to `float` on read |
| `csv.QUOTE_NONE` | Never quotes fields; escapes delimiters with `escapechar` (raises `csv.Error` if `escapechar` is unset) |

```python
import csv
from pathlib import Path

with Path("quoted_export.csv").open(mode="w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f, quoting=csv.QUOTE_ALL)
    writer.writerow(["101", "Chennai, India", "Active"])
    # Writes: "101","Chennai, India","Active"
```

### 3. Dialects and `csv.Sniffer`
Python includes built-in formatting presets called **dialects** (`"excel"`, `"excel-tab"`, `"unix"`), and provides **`csv.Sniffer`** to auto-detect delimiters and headers from sample text:

```python
import csv
from pathlib import Path

sample_path = Path("unknown_format.csv")
with sample_path.open(mode="r", encoding="utf-8", newline="") as f:
    sample = f.read(1024)
    f.seek(0)  # Rewind file pointer before reading rows

    sniffer = csv.Sniffer()
    dialect = sniffer.sniff(sample)
    has_header = sniffer.has_header(sample)

    reader = csv.reader(f, dialect)
    if has_header:
        header = next(reader)
    for row in reader:
        print(row)
```

## 5. Practical Considerations and Edge Cases

1. **Explicit Type Casting:** `csv.reader` and `csv.DictReader` always return string values (`"42"`, `"True"`, `""`). Convert numeric, boolean, and date fields explicitly during iteration.
2. **Excel UTF-8 BOM (`encoding="utf-8-sig"`):** Files exported from Microsoft Excel as "CSV UTF-8" often start with a Byte Order Mark (`\ufeff`), which silently corrupts the first header key (e.g., `"\ufeffid"` instead of `"id"`). Open such files with **`encoding="utf-8-sig"`** to strip the BOM automatically.
3. **Exception Handling (`csv.Error`):** Malformed CSV structures (such as unclosed quotes or unexpected NUL bytes) raise **`csv.Error`**.

```python
import csv
from pathlib import Path

try:
    with Path("excel_export.csv").open(mode="r", encoding="utf-8-sig", newline="") as f:
        for row in csv.DictReader(f):
            print(row)
except csv.Error as err:
    print(f"CSV parsing error: {err}")
```

## 6. Quick Reference

| Class / Function / Option | Purpose | Key Notes |
| :--- | :--- | :--- |
| `open(..., newline="")` | Required file-opening option for CSV I/O | Prevents blank lines on Windows and preserves multiline fields |
| `csv.reader(f, ...)` | Iterates over CSV rows as `list[str]` | Use `next(reader, None)` to consume the header row |
| `csv.writer(f, ...)` | Writes sequences (`list`/`tuple`) as CSV rows | Supports `.writerow(row)` and `.writerows(rows)` |
| `csv.DictReader(f, ...)` | Iterates over CSV rows as `dict[str, str]` | Uses first row as keys unless `fieldnames` is provided |
| `csv.DictWriter(f, fieldnames, ...)` | Writes dictionaries as CSV rows | Call `.writeheader()` before `.writerow()` / `.writerows()` |
| `delimiter=","` | Column separator character | Set to `"\t"` for TSV or `";"` for semicolon-delimited files |
| `quoting=csv.QUOTE_MINIMAL` | Controls when fields are wrapped in quotes | Alternatives: `QUOTE_ALL`, `QUOTE_NONNUMERIC`, `QUOTE_NONE` |
| `encoding="utf-8-sig"` | Strips leading UTF-8 BOM on read | Prevents `\ufeff` from polluting the first column name |
