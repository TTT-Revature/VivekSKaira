# Opening, Reading, and Writing Files

## 1. Overview
File handling allows Python programs to persist data on disk beyond the lifetime of a running process and to read external data such as logs, configuration files, and datasets.

* **File Object (Stream):** Calling Python's built-in `open()` function returns a file object that provides methods to read, write, and navigate file contents.
* **Text vs. Binary Files:**
  * **Text mode (`'t'`, default):** Reads and writes `str` objects, automatically translating platform line endings (`\r\n` on Windows to `\n` in Python) and decoding/encoding characters using a text encoding such as UTF-8.
  * **Binary mode (`'b'`):** Reads and writes raw `bytes` objects with no encoding translation—used for images, PDFs, audio, executables, and serialized files.

---

## 2. Opening Files (`open()`) and File Modes

### Syntax
```python
file_object = open(file_path, mode="r", encoding="utf-8")
```
*(Best Practice: Always pass `encoding="utf-8"` explicitly when working with text files so your code behaves identically across Windows, macOS, and Linux.)*

### Standard File Modes

| Mode | Name | File Must Exist? | Pointer Start | Behavior |
| :--- | :--- | :--- | :--- | :--- |
| `'r'` | Read (default) | Yes (`FileNotFoundError` if missing) | Beginning | Opens file for reading only |
| `'w'` | Write | No (creates new file) | Beginning | **Truncates (erases)** existing content if file exists |
| `'a'` | Append | No (creates new file) | End | Preserves existing content; writes new data at the end |
| `'x'` | Exclusive Create | Must **not** exist (`FileExistsError`) | Beginning | Creates a new file and opens it for writing; fails if it already exists |
| `'r+'` | Read & Write | Yes (`FileNotFoundError` if missing) | Beginning | Reads and overwrites existing content without truncating first |
| `'w+'` | Write & Read | No (creates new file) | Beginning | Truncates existing file, then allows both writing and reading |
| `'a+'` | Append & Read | No (creates new file) | End | Appends to the end; requires `.seek(0)` before reading from the start |

*(Combine any primary mode with `'b'` for binary mode—for example, `'rb'`, `'wb'`, `'ab'`—and omit the `encoding` argument in binary mode.)*

## 3. Closing Files and the `with` Statement (Context Manager)
Open files consume operating system file descriptors, and buffered writes may not be flushed to disk until the file is closed.

### Manual `close()` vs. `with` Statement
* **Manual `try-finally`:** Requires explicitly calling `f.close()` in a `finally` block so the file closes even if an error occurs.
* **`with` Statement (Recommended):** Uses Python's context manager protocol to close the file automatically as soon as the indented block exits—even if an exception is raised inside the block.

```python
# Recommended: Context manager guarantees automatic file closure
with open("notes.txt", mode="r", encoding="utf-8") as file:
    content = file.read()

print(file.closed)  # True
```

## 4. Reading Files
Python provides four primary ways to read data from an open text file:

### 1. `.read([size])` — Read Entire File or Fixed Chunk
Reads the entire remaining file as a single `str` (or up to `size` characters if `size` is specified):
```python
with open("notes.txt", mode="r", encoding="utf-8") as f:
    full_text = f.read()
    print(full_text)
```

### 2. `.readline()` — Read One Line at a Time
Reads a single line up to and including the trailing newline character (`\n`). Returns an empty string `""` when the end of the file (EOF) is reached:
```python
with open("notes.txt", mode="r", encoding="utf-8") as f:
    first_line = f.readline().rstrip("\n")
    second_line = f.readline().rstrip("\n")
    print(first_line, "|", second_line)
```

### 3. `.readlines()` — Read All Lines into a List
Reads all remaining lines into a `list[str]`, keeping the `\n` character at the end of each line:
```python
with open("notes.txt", mode="r", encoding="utf-8") as f:
    lines = f.readlines()
    print(lines)  # ['Line 1\n', 'Line 2\n', 'Line 3\n']
```

### 4. Iterating Directly Over the File Object (Best Practice for Large Files)
A file object is its own line iterator. Looping directly over `f` reads **one line at a time** into memory rather than loading the entire file at once:
```python
with open("server.log", mode="r", encoding="utf-8") as f:
    for line_num, line in enumerate(f, start=1):
        clean_line = line.rstrip("\n")
        if "ERROR" in clean_line:
            print(f"Line {line_num}: {clean_line}")
```

## 5. Writing and Appending to Files

### 1. Writing New Content (`'w'`) with `.write()`
Opens the file for writing, **erasing any previous contents**, and writes strings to the file. `.write()` returns the number of characters written and **does not automatically add a newline (`\n`)**:
```python
with open("report.txt", mode="w", encoding="utf-8") as f:
    chars_written = f.write("Module: File Handling\n")
    f.write("Status: Completed\n")
    print(f"Wrote {chars_written} characters on line 1.")
```

### 2. Writing Multiple Strings with `.writelines()`
Accepts an iterable of strings (such as a `list` or generator) and writes them sequentially. You must include `\n` at the end of each string yourself:
```python
topics = ["Lists\n", "Tuples\n", "Sets\n", "Dictionaries\n"]

with open("syllabus.txt", mode="w", encoding="utf-8") as f:
    f.writelines(topics)
```

### 3. Appending to an Existing File (`'a'`)
Opens the file and positions the write cursor at the **very end**, preserving existing data:
```python
with open("syllabus.txt", mode="a", encoding="utf-8") as f:
    f.write("Functions\n")
    f.write("File Handling\n")
```

### 4. Safe File Creation (`'x'`)
Creates the file only if it does not already exist, preventing accidental overwrites:
```python
try:
    with open("config.txt", mode="x", encoding="utf-8") as f:
        f.write("ENV=production\n")
except FileExistsError:
    print("config.txt already exists; skipping creation.")
```

## 6. Navigating the File Cursor (`.tell()` and `.seek()`)
Python tracks the current read/write position in an open file using a file pointer (cursor):

* **`.tell()`:** Returns the current cursor position as an integer byte offset from the start of the file.
* **`.seek(offset, whence=0)`:** Moves the cursor to a new position (`whence=0` measures from the start of the file; `f.seek(0)` rewinds to the beginning).

```python
with open("demo.txt", mode="w+", encoding="utf-8") as f:
    f.write("Python File I/O")
    print("Position after write:", f.tell())  # 15

    # Rewind pointer to the start before reading
    f.seek(0)
    print("Position after seek(0):", f.tell())  # 0
    print("Content:", f.read())                 # 'Python File I/O'
```

## 7. Common File Handling Exceptions

| Exception | Cause |
| :--- | :--- |
| `FileNotFoundError` | Trying to open a non-existent file in `'r'` or `'r+'` mode |
| `FileExistsError` | Trying to open an existing file in `'x'` (exclusive creation) mode |
| `PermissionError` | Insufficient OS permissions to read/write the file, or file is locked |
| `IsADirectoryError` | Passing a directory path to `open()` instead of a file path |
| `UnicodeDecodeError` | Reading a file with an incompatible text encoding (e.g., reading binary or Latin-1 data as UTF-8) |
| `io.UnsupportedOperation` | Calling `.write()` on a read-only (`'r'`) file or `.read()` on a write-only (`'w'`) file |

## 8. Quick Reference

| Method / Construct | Description | Returns |
| :--- | :--- | :--- |
| `with open(path, mode, encoding="utf-8") as f:` | Opens a file safely and closes it automatically on block exit | File object (`TextIOWrapper` / `BufferedReader`) |
| `f.read([size])` | Reads entire file (or up to `size` characters/bytes) | `str` (or `bytes` in `'b'` mode) |
| `f.readline()` | Reads a single line including trailing `\n` | `str` (`""` at EOF) |
| `f.readlines()` | Reads all remaining lines into a list | `list[str]` |
| `for line in f:` | Lazily iterates through file line by line | Yields `str` per iteration |
| `f.write(text)` | Writes a string (or `bytes`) at the current cursor position | `int` (number of characters/bytes written) |
| `f.writelines(lines)` | Writes every string from an iterable sequentially | `None` |
| `f.tell()` | Returns current cursor byte offset | `int` |
| `f.seek(0)` | Moves cursor back to the beginning of the file | `int` (new position) |
