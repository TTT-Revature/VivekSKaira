# Stacks: Concepts, Operations, and Implementation

## 1. Overview
A **stack** is a linear abstract data type (ADT) that enforces a strict **LIFO (Last-In, First-Out)** access order: the most recently inserted element is always the first element to be removed.

* **Single-End Access:**
  Unlike arrays or general linked lists, a stack restricts all insertions and deletions to a single designated end called the **top**. Elements in the middle or at the bottom cannot be accessed directly without first popping the elements above them.
* **Visual Representation:**
  ```text
        push(30)        pop() -> 30
           |                 ^
           v                 |
      +---------+       +---------+
  top |   30    |  -->  |   20    | <-- new top
      +---------+       +---------+
      |   20    |       |   10    |
      +---------+       +---------+
      |   10    |       +---------+
      +---------+
  ```
* **Core Applications in Computer Science:**
  * **Function Call Stack:** Tracks active function frames, local variables, and return addresses during execution and recursion.
  * **Undo / Redo Histories:** Editors push state snapshots or reversible commands onto an undo stack.
  * **Expression Parsing & Evaluation:** Converts infix expressions (`(a + b) * c`) to postfix (Reverse Polish Notation) and evaluates arithmetic expressions.
  * **Syntax Validation:** Checks balanced parentheses, brackets, and HTML/XML tags.
  * **Graph & Tree Traversal:** Powers iterative Depth-First Search (DFS) and backtracking algorithms.

## 2. Core Stack Operations and Complexities
Assume $n$ is the number of elements currently stored in the stack:

| Operation | Description | Time Complexity | Auxiliary Space | Boundary Condition |
| :--- | :--- | :--- | :--- | :--- |
| **`push(item)`** | Inserts `item` onto the top of the stack | $\Theta(1)$ (amortized for dynamic array) | $O(1)$ | Raises **Stack Overflow** if bounded capacity is full |
| **`pop()`** | Removes and returns the top element | $\Theta(1)$ | $O(1)$ | Raises **Stack Underflow** if the stack is empty |
| **`peek()` / `top()`** | Returns the top element without removing it | $\Theta(1)$ | $O(1)$ | Raises **Stack Underflow** if the stack is empty |
| **`is_empty()`** | Returns `True` if `size == 0`, else `False` | $\Theta(1)$ | $O(1)$ | None |
| **`size()` / `__len__()`** | Returns the total count of elements in the stack | $\Theta(1)$ | $O(1)$ | None |

## 3. Stack Implementations in Python
Stacks can be backed by either a **contiguous array** (`list` or `collections.deque`) or a **singly linked list**.

### 1. Array-Backed Stack (`list` Wrapper)
Using the end (tail) of a Python `list` as the top of the stack provides $O(1)$ amortized `append()` and $O(1)$ `pop()` with high CPU cache locality:

```python
from typing import Generic, TypeVar

T = TypeVar("T")


class StackUnderflowError(Exception):
    """Raised when attempting to pop or peek from an empty stack."""


class ArrayStack(Generic[T]):
    """LIFO stack backed by a Python dynamic array (list)."""

    def __init__(self) -> None:
        self._items: list[T] = []

    def push(self, item: T) -> None:
        """Push an element onto the top of the stack: O(1) amortized."""
        self._items.append(item)

    def pop(self) -> T:
        """Remove and return the top element: O(1)."""
        if self.is_empty():
            raise StackUnderflowError("Cannot pop from an empty stack")
        return self._items.pop()

    def peek(self) -> T:
        """Return the top element without removing it: O(1)."""
        if self.is_empty():
            raise StackUnderflowError("Cannot peek into an empty stack")
        return self._items[-1]

    def is_empty(self) -> bool:
        return len(self._items) == 0

    def __len__(self) -> int:
        return len(self._items)

    def __repr__(self) -> str:
        return f"ArrayStack({self._items!r})"
```

### 2. Deque-Backed Stack (`collections.deque`)
**`collections.deque`** is implemented in C as a doubly-linked list of fixed-size memory blocks. Unlike `list`, it guarantees **strict worst-case $\Theta(1)$** `append()` and `pop()` on every single operation without occasional $O(n)$ buffer reallocations:

```python
from collections import deque
from typing import Generic, TypeVar

T = TypeVar("T")


class DequeStack(Generic[T]):
    """LIFO stack backed by collections.deque for strict worst-case O(1) operations."""

    def __init__(self) -> None:
        self._items: deque[T] = deque()

    def push(self, item: T) -> None:
        self._items.append(item)

    def pop(self) -> T:
        if not self._items:
            raise StackUnderflowError("Cannot pop from an empty stack")
        return self._items.pop()

    def peek(self) -> T:
        if not self._items:
            raise StackUnderflowError("Cannot peek into an empty stack")
        return self._items[-1]

    def is_empty(self) -> bool:
        return len(self._items) == 0

    def __len__(self) -> int:
        return len(self._items)
```

### 3. Linked-List-Backed Stack
A singly linked list implements a stack by treating the **`head`** node as the **top** of the stack. Both `push` and `pop` execute in strict worst-case $\Theta(1)$ time with zero wasted capacity:

```python
from __future__ import annotations
from dataclasses import dataclass
from typing import Generic, TypeVar

T = TypeVar("T")


@dataclass
class _Node(Generic[T]):
    value: T
    next: _Node[T] | None = None


class LinkedStack(Generic[T]):
    """LIFO stack backed by a singly linked list with head as top."""

    def __init__(self) -> None:
        self._top: _Node[T] | None = None
        self._size: int = 0

    def push(self, item: T) -> None:
        """Insert a new node at the head (top): strict O(1) time."""
        self._top = _Node(value=item, next=self._top)
        self._size += 1

    def pop(self) -> T:
        """Remove and return the head (top) node's value: strict O(1) time."""
        if self._top is None:
            raise StackUnderflowError("Cannot pop from an empty stack")
        value = self._top.value
        self._top = self._top.next
        self._size -= 1
        return value

    def peek(self) -> T:
        """Inspect the top node's value without unlinking: strict O(1) time."""
        if self._top is None:
            raise StackUnderflowError("Cannot peek into an empty stack")
        return self._top.value

    def is_empty(self) -> bool:
        return self._top is None

    def __len__(self) -> int:
        return self._size
```

### Implementation Trade-Off Comparison

| Implementation | `push` Time | `pop` Time | Memory Overhead | Key Trade-Off |
| :--- | :--- | :--- | :--- | :--- |
| **Python `list`** | $O(1)$ amortized ($O(n)$ on resize) | $\Theta(1)$ | Low (contiguous pointers + modest over-allocation) | Fastest in practice for most Python code due to cache locality |
| **`collections.deque`** | **$\Theta(1)$ worst-case** | **$\Theta(1)$ worst-case** | Low-Moderate (block headers) | Eliminates dynamic array resize spikes; thread-safe atomic `append`/`pop` |
| **Singly Linked List** | **$\Theta(1)$ worst-case** | **$\Theta(1)$ worst-case** | High (extra `_Node` object + `next` pointer per item) | Exact memory proportional to active elements; higher per-node allocation cost |

## 4. Classic Stack Problem-Solving Patterns

### 1. Balanced Parentheses / Delimiter Matching
Push expected closing brackets onto the stack whenever an opening bracket appears, and verify that each closing bracket matches the top of the stack:

```python
def is_balanced_brackets(expression: str) -> bool:
    """
    Validate nested delimiters '()', '[]', '{}'.
    Time: O(n) | Auxiliary Space: O(n)
    """
    matching_close = {"(": ")", "[": "]", "{": "}"}
    expected_closers: list[str] = []

    for ch in expression:
        if ch in matching_close:
            expected_closers.append(matching_close[ch])
        elif ch in {")", "]", "}"}:
            if not expected_closers or expected_closers.pop() != ch:
                return False

    return len(expected_closers) == 0
```

### 2. Postfix (Reverse Polish Notation) Evaluation
Operands are pushed onto the stack; when an operator is encountered, the top two operands are popped (`right` first, then `left`), evaluated, and pushed back:

```python
def evaluate_rpn(tokens: list[str]) -> int:
    """
    Evaluate an arithmetic expression in Reverse Polish Notation.
    Example: ["2", "1", "+", "3", "*"] -> ((2 + 1) * 3) = 9
    Time: O(n) | Auxiliary Space: O(n)
    """
    stack: list[int] = []
    operators = {"+", "-", "*", "/"}

    for token in tokens:
        if token not in operators:
            stack.append(int(token))
        else:
            right = stack.pop()
            left = stack.pop()
            if token == "+":
                stack.append(left + right)
            elif token == "-":
                stack.append(left - right)
            elif token == "*":
                stack.append(left * right)
            else:
                # Truncate division toward zero
                stack.append(int(left / right))

    return stack.pop()
```

### 3. Monotonic Stack (Next Greater Element)
A **monotonic stack** maintains elements in strictly increasing or decreasing order from bottom to top. Each element is pushed once and popped at most once, solving "next greater/smaller element" problems in **$O(n)$ time** instead of $O(n^2)$:

```python
def next_greater_elements(nums: list[int]) -> list[int]:
    """
    For each element in `nums`, find the first element to its right that is strictly greater,
    or -1 if none exists.
    Time: O(n) (each index pushed and popped at most once) | Auxiliary Space: O(n)
    """
    result = [-1] * len(nums)
    index_stack: list[int] = []  # Stores indices whose values are monotonically decreasing

    for idx, current_val in enumerate(nums):
        while index_stack and current_val > nums[index_stack[-1]]:
            prev_idx = index_stack.pop()
            result[prev_idx] = current_val
        index_stack.append(idx)

    return result


if __name__ == "__main__":
    print("Balanced '[({})]':", is_balanced_brackets("[({})]"))          # True
    print("Balanced '([)]':  ", is_balanced_brackets("([)]"))            # False
    print("RPN Result:       ", evaluate_rpn(["4", "13", "5", "/", "+"]))  # 6
    print("Next Greater:     ", next_greater_elements([2, 1, 2, 4, 3]))  # [4, 2, 4, -1, -1]
```

## 5. Common Pitfalls and Best Practices

1. **Using Index `0` (`insert(0, x)` and `pop(0)`) as the Stack Top on a `list`:**
   Inserting or popping at index `0` shifts all $n$ elements in memory ($O(n)$ per operation), degrading an $O(n)$ stack algorithm into **$O(n^2)$**. Always use the **tail** of the `list` (`append()` and `pop()`).
2. **Popping or Peeking Without Checking `if stack:`:**
   Calling `stack.pop()` or `stack[-1]` on an empty list raises `IndexError: pop from empty list`. Always guard pops and peeks with `if not stack:` (or raise a domain-specific `StackUnderflowError`).
3. **Reversing Operand Order in Binary Expressions (`left - right` vs. `right - left`):**
   Because a stack is LIFO, the **first** popped operand is the **right-hand operand** (`b`) and the **second** popped operand is the **left-hand operand** (`a`). Writing `stack.pop() - stack.pop()` computes `b - a` instead of `a - b`.
4. **Assuming Nested `while` Loops Inside a Monotonic Stack Are $O(n^2)$:**
   Even though a monotonic stack contains a `while` loop nested inside a `for` loop, every index is pushed **once** and popped **at most once** across the entire run—yielding **$O(n)$ total operations** (amortized $O(1)$ per step).
5. **Using Legacy `queue.LifoQueue` for Single-Threaded Algorithms:**
   `queue.LifoQueue` acquires thread locks on every `put()` and `get()`, adding unnecessary synchronization overhead in single-threaded DSA code. Reserve `LifoQueue` for multi-threaded producer-consumer workflows and use `list` or `collections.deque` for single-threaded stacks.

## 6. Quick Reference

| Concept / Method | Key Detail / Complexity |
| :--- | :--- |
| **Access Discipline** | **LIFO** (Last-In, First-Out) — all updates happen at `top` |
| **Core Operations** | `push(x)`, `pop()`, `peek()`, `is_empty()`, `__len__()` — all **$O(1)$** |
| **Python `list` Stack** | `stack.append(x)` (push), `stack.pop()` (pop), `stack[-1]` (peek) |
| **Python `deque` Stack** | `collections.deque` — strict worst-case $\Theta(1)$ push/pop without resize spikes |
| **Linked Stack** | Singly linked list where `head` is `top` — strict $\Theta(1)$ push/pop |
| **Monotonic Stack** | Maintains sorted invariant on stack; solves Next Greater/Smaller in **$O(n)$** |
| **Recursion Replacement** | Any recursive DFS/backtracking algorithm can be converted to an iterative `while` loop using an explicit stack |
