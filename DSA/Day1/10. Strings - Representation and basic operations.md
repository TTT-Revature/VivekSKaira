# Strings: Representation and Basic Operations

## 1. Overview
A **string** is an ordered sequence of characters used to represent text, identifiers, serialized data, and symbolic patterns. In Data Structures and Algorithms (DSA), strings behave conceptually like arrays of characters, with distinct memory-encoding rules and immutability guarantees in modern languages.

* **Key Characteristics:**
  * **Sequential & Zero-Indexed:** Individual characters are accessed by integer positions from `0` to `n - 1`.
  * **Immutable in Python (and Java / Go / Rust `str`):** Once created in memory, a Python `str` object cannot be modified in place. Any operation that appears to alter a string—such as concatenation, slicing, or `.replace()`—allocates and returns a **new string object**.
  * **Hashable:** Because Python strings are immutable, their hash value is cached upon first computation, allowing $O(1)$ average-case use as `dict` keys and `set` elements.

## 2. Character Encoding and Memory Representation

### 1. Character Sets and Encodings
Computers store text as integers mapped through standardized character encodings:

| Standard | Bit Width / Layout | Scope & Key Properties |
| :--- | :--- | :--- |
| **ASCII** | 7-bit (`0` to `127`, stored in 1 byte) | Covers English letters (`A-Z` = `65-90`, `a-z` = `97-122`), digits (`0-9` = `48-57`), punctuation, and control characters |
| **Unicode** | Abstract code points (`U+0000` to `U+10FFFF`) | Assigns a unique integer (**code point**) to over 150,000 characters across all writing systems and symbols |
| **UTF-8** | Variable-length (`1` to `4` bytes per character) | Dominant web/file encoding; 100% backward-compatible with 1-byte ASCII; uses 2–4 bytes for non-ASCII characters |
| **UTF-16 / UTF-32** | 2 or 4 bytes / fixed 4 bytes | Fixed-width UTF-32 allows direct indexing by code point but wastes memory on ASCII-heavy text |

### 2. CPython's Internal Representation (PEP 393)
Unlike languages that store every string as variable-width UTF-8 bytes in memory (which makes `s[i]` an $O(n)$ scan), CPython uses **Flexible String Representation**:
* When a `str` is created, Python inspects the largest Unicode code point in that string and stores its characters in a **contiguous fixed-width array**:
  * **1 byte per character (Latin-1 / ASCII):** All code points $\le \text{U+00FF}$.
  * **2 bytes per character (UCS-2):** Largest code point $\le \text{U+FFFF}$.
  * **4 bytes per character (UCS-4):** Largest code point $> \text{U+FFFF}$.
* **Result:** Every character slot has an identical byte width, preserving **$O(1)$ random-access indexing (`s[i]`)** while minimizing RAM for ASCII text.

### 3. Converting Between Characters, Code Points, and Bytes
```python
# Character <-> Unicode Code Point (int)
print(ord("A"), ord("a"), ord("0"))   # 65 97 48
print(chr(65), chr(97), chr(8364))    # 'A' 'a' '€'

# String (Unicode) <-> Raw Bytes (UTF-8)
text = "café"
encoded_bytes = text.encode("utf-8")  # b'caf\xc3\xa9' (5 bytes for 4 characters)
decoded_text = encoded_bytes.decode("utf-8")
print(f"Characters: {len(text)} | UTF-8 bytes: {len(encoded_bytes)} | Decoded: {decoded_text}")
```

## 3. Core String Operations and Complexities
Let $n = \text{len}(s)$ and $m = \text{len}(\text{sub})$:

| Operation | Python Syntax | Time Complexity | Auxiliary Space | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **Length** | `len(s)` | $\Theta(1)$ | $O(1)$ | Stored directly in the object header |
| **Index Access** | `s[i]` | $\Theta(1)$ | $O(1)$ | Direct offset lookup in contiguous character array |
| **Slicing ($k$ chars)** | `s[start:end]` | $\Theta(k)$ | $O(k)$ | Allocates a new string copying $k = \text{end} - \text{start}$ characters |
| **Concatenation** | `s1 + s2` | $\Theta(n + m)$ | $O(n + m)$ | Allocates a new string and copies both operands |
| **Repetition** | `s * k` | $\Theta(n \cdot k)$ | $O(n \cdot k)$ | Allocates a new string of length $n \cdot k$ |
| **Equality / Ordering** | `s1 == s2`, `s1 < s2` | $O(\min(n, m))$ | $O(1)$ | Compares character code points left-to-right; stops at first mismatch |
| **Substring Search** | `sub in s`, `s.find(sub)` | $O(n \cdot m)$ worst | $O(1)$ | CPython uses an optimized hybrid Two-Way / Boyer-Moore search ($O(n)$ typical) |
| **Join Iterable** | `"".join(parts)` | $\Theta(N)$ | $O(N)$ | Two-pass pre-allocation where $N$ is total output characters |
| **Split** | `s.split(sep)` | $\Theta(n)$ | $O(n)$ | Scans string once and allocates a list of substring objects |
| **Replace** | `s.replace(old, new)` | $\Theta(n + \text{output\_len})$ | $O(\text{output\_len})$ | Scans for occurrences and builds a new string |
| **Case / Trim** | `s.lower()`, `s.strip()` | $\Theta(n)$ | $O(n)$ | Returns a newly allocated transformed string |

## 4. String Immutability and Efficient String Building
Because strings cannot be mutated in place, appending characters one by one with `+` or `+=` inside a loop forces Python to allocate a progressively larger copy on every iteration:

* **Naive Concatenation in a Loop ($O(n^2)$ Worst-Case Time):**
  Copying $1 + 2 + 3 + \dots + n = \frac{n(n + 1)}{2}$ characters degrades to **$\Theta(n^2)$** when the string cannot be resized in place (for example, when another reference exists).
* **List Accumulation + `"".join()` ($\Theta(n)$ Time, $\Theta(n)$ Space):**
  Append character chunks to a Python `list` in $O(1)$ amortized time each, then call `"".join(parts)` once at the end. `str.join()` computes the exact final size in a first pass and copies all characters in a single second pass.

```python
def filter_alphanumeric_slow(raw: str) -> str:
    """Quadratic worst-case pattern: creates a new string object per character."""
    result = ""
    for ch in raw:
        if ch.isalnum():
            result += ch
    return result


def filter_alphanumeric_fast(raw: str) -> str:
    """Linear O(n) pattern: collects characters in a list and joins once."""
    chars: list[str] = []
    for ch in raw:
        if ch.isalnum():
            chars.append(ch)
    return "".join(chars)
```

## 5. Fundamental String Manipulation Patterns in Python

### 1. Character Frequency Counting (Hash Map vs. Fixed Alphabet Array)
* **General Unicode Text:** Use `collections.Counter(s)` or a `dict[str, int]` ($O(n)$ time, $O(k)$ space where $k$ is unique characters).
* **Lowercase English Letters (`'a'`–`'z'`):** Map each character to index `ord(ch) - ord('a')` in a fixed 26-element list ($O(n)$ time, **$O(1)$ auxiliary space**).

```python
from collections import Counter


def are_anagrams(first: str, second: str) -> bool:
    """
    Check whether two strings contain identical character frequencies.
    Time: O(n) | Auxiliary Space: O(1) for fixed alphabet (or O(k) for general Unicode)
    """
    if len(first) != len(second):
        return False
    return Counter(first) == Counter(second)


def first_unique_char_index(s: str) -> int:
    """
    Return the index of the first non-repeating lowercase ASCII character, or -1.
    Time: O(n) | Auxiliary Space: O(1) (fixed 26-slot array)
    """
    counts = [0] * 26
    base = ord("a")

    for ch in s:
        counts[ord(ch) - base] += 1

    for idx, ch in enumerate(s):
        if counts[ord(ch) - base] == 1:
            return idx

    return -1
```

### 2. Two-Pointer Palindrome Verification ($O(n)$ Time, $O(1)$ Space)
Instead of reversing the entire string with `s[::-1]` (which allocates $O(n)$ extra memory), compare characters inward from both ends:

```python
def is_valid_palindrome(text: str) -> bool:
    """
    Check if `text` reads the same forward and backward ignoring non-alphanumeric chars and case.
    Time: O(n) | Auxiliary Space: O(1)
    """
    left, right = 0, len(text) - 1

    while left < right:
        while left < right and not text[left].isalnum():
            left += 1
        while left < right and not text[right].isalnum():
            right -= 1

        if text[left].lower() != text[right].lower():
            return False

        left += 1
        right -= 1

    return True


if __name__ == "__main__":
    print("Clean alphanumeric:", filter_alphanumeric_fast("Revature_FDE-2026!"))
    print("Are anagrams:      ", are_anagrams("listen", "silent"))
    print("First unique idx:  ", first_unique_char_index("leetcode"))
    print("Valid palindrome:  ", is_valid_palindrome("A man, a plan, a canal: Panama"))
```

## 6. Common Pitfalls and Best Practices

1. **Attempting In-Place Character Assignment (`s[i] = 'x'`):**
   Strings in Python are immutable; assigning to an index raises **`TypeError: 'str' object does not support item assignment`**. Convert to `list(s)` first when multiple in-place index swaps are required, then convert back via `"".join(char_list)`.
2. **Building Large Strings with Repeated `+` or `+=` in Loops:**
   Always accumulate fragments in a `list` and call `"".join(fragments)` once—especially inside `while` loops or recursive builders—to guarantee $O(n)$ time complexity.
3. **Confusing `len(s)` with Byte Size on Disk or Network:**
   `len("héllo")` returns `5` (number of Unicode code points), whereas `len("héllo".encode("utf-8"))` returns `6` bytes. Always specify encoding explicitly (`encoding="utf-8"`) when reading/writing files or measuring payload sizes.
4. **Creating Repeated Substring Slices (`s[1:]`) in Recursion or Loops:**
   Slicing a string of length $n$ copies $k$ characters ($O(k)$ time and space). Pass integer index bounds (`left`, `right`) to helper functions instead of passing sliced substrings.
5. **Forgetting ASCII Offset Arithmetic (`ord` / `chr`):**
   Using `ord(ch) - ord('a')` maps `'a'..'z'` cleanly to `0..25`, and `ord(ch) - ord('0')` converts digit characters `'0'..'9'` to integer values `0..9` without allocating temporary strings.

## 7. Quick Reference

| Concept / Method | Behavior & Complexity |
| :--- | :--- |
| **Immutability** | Python `str` cannot be modified in place; transformations return new objects |
| **PEP 393 Representation** | Contiguous 1-byte, 2-byte, or 4-byte fixed-width array $\implies O(1)$ indexing `s[i]` |
| `ord(ch)` / `chr(code)` | Converts single character $\leftrightarrow$ integer Unicode code point in $O(1)$ |
| `s.encode("utf-8")` / `b.decode("utf-8")` | Converts between `str` and `bytes` in $\Theta(n)$ |
| `s[start:end]` | Substring slice of length $k$ in $\Theta(k)$ time and $\Theta(k)$ space |
| `"".join(parts)` | Concatenates iterable of strings in optimal $\Theta(N)$ time and space |
| `s.find(sub)` / `sub in s` | Substring search ($O(n)$ typical, $O(n \cdot m)$ theoretical worst case, $O(1)$ space) |
| **Frequency Counting** | `collections.Counter(s)` or `[0] * 26` array in $\Theta(n)$ time |
