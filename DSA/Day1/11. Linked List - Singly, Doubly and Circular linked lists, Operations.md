# Linked Lists: Singly, Doubly, and Circular Linked Lists

## 1. Overview
A **linked list** is a linear data structure composed of individual elements called **nodes**, where each node stores a data value along with one or more references (**pointers**) linking it to neighboring nodes in memory.

* **Non-Contiguous Memory Architecture:**
  Unlike arrays—which store elements in a single contiguous memory block—linked list nodes can reside anywhere on the heap. Order is maintained exclusively through explicit object references rather than physical adjacency.
* **Linked List vs. Dynamic Array (Python `list`):**

| Feature | Linked List | Dynamic Array (Python `list`) |
| :--- | :--- | :--- |
| **Memory Allocation** | Non-contiguous heap nodes allocated on demand | Contiguous block of pointers (over-allocated capacity) |
| **Random Access (`get(i)`)** | $O(n)$ (must traverse sequentially from head) | **$O(1)$** (direct offset calculation) |
| **Insert / Delete at Head** | **$O(1)$** (pointer reassignment only) | $O(n)$ (must shift all subsequent elements) |
| **Insert / Delete at Known Node** | **$O(1)$** (no element shifting required) | $O(n)$ (must shift trailing elements) |
| **Resizing Overhead** | None (grows/shrinks one node at a time) | Occasional $O(n)$ buffer reallocation on capacity expansion |
| **Memory Overhead per Element** | Higher (stores 1 or 2 extra pointer references per node) | Lower (stores 1 pointer slot per element) |
| **CPU Cache Locality** | Poor (nodes scattered across heap addresses) | High (consecutive addresses maximize cache hits) |

## 2. Types of Linked Lists

### 1. Singly Linked List (SLL)
Each node contains two fields: **`data`** and **`next`** (a reference to the following node). Traversal moves strictly in **one direction** from `head` to `tail` (whose `next` pointer is `None`).

```text
head
 |
 v
[ 10 | next ] ---> [ 20 | next ] ---> [ 30 | next ] ---> None
                                        ^
                                        |
                                       tail
```

### 2. Doubly Linked List (DLL)
Each node contains three fields: **`prev`** (reference to the preceding node), **`data`**, and **`next`** (reference to the following node). Traversal works in **both directions** (`head` to `tail` and `tail` to `head`), and deleting an arbitrary node takes $O(1)$ time given a direct reference to that node.

```text
          head                                                 tail
           |                                                    |
           v                                                    v
None <--- [ prev | 10 | next ] <---> [ prev | 20 | next ] <---> [ prev | 30 | next ] ---> None
```

### 3. Circular Linked List (CLL)
The `next` pointer of the final node (`tail`) points back to the first node (`head`) instead of `None`, forming a closed ring with no `None` terminators:
* **Circular Singly Linked List:** `tail.next` points to `head`. Maintaining a single reference to `tail` provides $O(1)$ access to both the tail (`tail`) and the head (`tail.next`).
* **Circular Doubly Linked List:** `tail.next` points to `head` **and** `head.prev` points to `tail`.
* **Common Use Cases:** Round-robin CPU/task scheduling, ring buffers, multiplayer turn rotation, and circular playlist navigation.

```text
  +----------------------------------------------------------+
  |                                                          |
  v                                                          |
[ 10 | next ] ---> [ 20 | next ] ---> [ 30 | next ] ---------+
                                        ^
                                        |
                                       tail  (tail.next is head)
```

## 3. Core Operations and Complexity Comparison
Assume $n$ is the number of nodes currently in the list:

| Operation | Singly Linked List (with `tail`) | Doubly Linked List (with `tail`) | Circular Singly Linked List (with `tail`) |
| :--- | :--- | :--- | :--- |
| **Access by Index (`get(i)`)** | $\Theta(n)$ | $\Theta(n)$ (can start from closer end) | $\Theta(n)$ |
| **Search by Value (`find(val)`)** | $\Theta(n)$ | $\Theta(n)$ | $\Theta(n)$ |
| **Insert at Head (`prepend`)** | $\Theta(1)$ | $\Theta(1)$ | $\Theta(1)$ |
| **Insert at Tail (`append`)** | $\Theta(1)$ ($\Theta(n)$ without `tail`) | $\Theta(1)$ | $\Theta(1)$ |
| **Insert After Given Node** | $\Theta(1)$ | $\Theta(1)$ | $\Theta(1)$ |
| **Delete at Head (`pop_left`)** | $\Theta(1)$ | $\Theta(1)$ | $\Theta(1)$ |
| **Delete at Tail (`pop`)** | $\Theta(n)$ (must find node before `tail`) | $\Theta(1)$ (via `tail.prev`) | $\Theta(n)$ (must find node before `tail`) |
| **Delete Given Node Reference** | $\Theta(n)$ (needs predecessor) | $\Theta(1)$ (via `node.prev`) | $\Theta(n)$ (needs predecessor) |
| **Auxiliary Space (per operation)** | $O(1)$ | $O(1)$ | $O(1)$ |

## 4. Python Implementation: Singly Linked List

```python
from __future__ import annotations
from dataclasses import dataclass
from typing import Generic, Iterator, TypeVar

T = TypeVar("T")


@dataclass
class SinglyNode(Generic[T]):
    data: T
    next: SinglyNode[T] | None = None


class SinglyLinkedList(Generic[T]):
    """Singly linked list maintaining both head and tail references."""

    def __init__(self) -> None:
        self.head: SinglyNode[T] | None = None
        self.tail: SinglyNode[T] | None = None
        self._size: int = 0

    def __len__(self) -> int:
        return self._size

    def __iter__(self) -> Iterator[T]:
        current = self.head
        while current is not None:
            yield current.data
            current = current.next

    def prepend(self, value: T) -> None:
        """Insert a new node at the head: O(1) time, O(1) space."""
        new_node = SinglyNode(data=value, next=self.head)
        self.head = new_node
        if self.tail is None:
            self.tail = new_node
        self._size += 1

    def append(self, value: T) -> None:
        """Insert a new node at the tail: O(1) time, O(1) space."""
        new_node = SinglyNode(data=value)
        if self.tail is None:
            self.head = self.tail = new_node
        else:
            self.tail.next = new_node
            self.tail = new_node
        self._size += 1

    def delete_first(self, target: T) -> bool:
        """Remove the first node matching `target`: O(n) time, O(1) space."""
        prev: SinglyNode[T] | None = None
        current = self.head

        while current is not None:
            if current.data == target:
                if prev is None:
                    self.head = current.next
                else:
                    prev.next = current.next

                if current is self.tail:
                    self.tail = prev

                self._size -= 1
                return True

            prev = current
            current = current.next

        return False

    def reverse_in_place(self) -> None:
        """Reverse node links in a single pass: O(n) time, O(1) auxiliary space."""
        prev: SinglyNode[T] | None = None
        current = self.head
        self.tail = self.head

        while current is not None:
            next_node = current.next  # Save next reference before overwriting
            current.next = prev       # Reverse pointer
            prev = current            # Advance prev
            current = next_node       # Advance current

        self.head = prev
```

## 5. Python Implementation: Doubly Linked List (with Sentinel Nodes)
Using dummy **`head` and `tail` sentinel nodes** eliminates special-case `None` checks when inserting into an empty list or deleting the first/last real node:

```python
from __future__ import annotations
from dataclasses import dataclass
from typing import Generic, Iterator, TypeVar

T = TypeVar("T")


@dataclass
class DoublyNode(Generic[T]):
    data: T | None = None
    prev: DoublyNode[T] | None = None
    next: DoublyNode[T] | None = None


class DoublyLinkedList(Generic[T]):
    """Doubly linked list using dummy head and tail sentinel nodes."""

    def __init__(self) -> None:
        self._head_sentinel: DoublyNode[T] = DoublyNode()
        self._tail_sentinel: DoublyNode[T] = DoublyNode()
        self._head_sentinel.next = self._tail_sentinel
        self._tail_sentinel.prev = self._head_sentinel
        self._size: int = 0

    def __len__(self) -> int:
        return self._size

    def __iter__(self) -> Iterator[T]:
        current = self._head_sentinel.next
        while current is not None and current is not self._tail_sentinel:
            assert current.data is not None
            yield current.data
            current = current.next

    def _insert_between(
        self, value: T, predecessor: DoublyNode[T], successor: DoublyNode[T]
    ) -> DoublyNode[T]:
        """Insert a new node between two adjacent nodes in O(1) time."""
        new_node = DoublyNode(data=value, prev=predecessor, next=successor)
        predecessor.next = new_node
        successor.prev = new_node
        self._size += 1
        return new_node

    def remove_node(self, node: DoublyNode[T]) -> T:
        """Unlink and remove a known node reference in O(1) time."""
        if node is self._head_sentinel or node is self._tail_sentinel:
            raise ValueError("Cannot remove sentinel nodes")
        assert node.prev is not None and node.next is not None and node.data is not None

        node.prev.next = node.next
        node.next.prev = node.prev
        node.prev = node.next = None
        self._size -= 1
        return node.data

    def prepend(self, value: T) -> DoublyNode[T]:
        """Add element at front in O(1) time."""
        assert self._head_sentinel.next is not None
        return self._insert_between(value, self._head_sentinel, self._head_sentinel.next)

    def append(self, value: T) -> DoublyNode[T]:
        """Add element at back in O(1) time."""
        assert self._tail_sentinel.prev is not None
        return self._insert_between(value, self._tail_sentinel.prev, self._tail_sentinel)

    def pop_left(self) -> T:
        """Remove and return front element in O(1) time."""
        if self._size == 0 or self._head_sentinel.next is None:
            raise IndexError("pop_left from empty DoublyLinkedList")
        return self.remove_node(self._head_sentinel.next)

    def pop(self) -> T:
        """Remove and return back element in O(1) time."""
        if self._size == 0 or self._tail_sentinel.prev is None:
            raise IndexError("pop from empty DoublyLinkedList")
        return self.remove_node(self._tail_sentinel.prev)
```

## 6. Python Implementation: Circular Singly Linked List

```python
from __future__ import annotations
from dataclasses import dataclass
from typing import Generic, TypeVar

T = TypeVar("T")


@dataclass
class CircularNode(Generic[T]):
    data: T
    next: CircularNode[T] | None = None


class CircularSinglyLinkedList(Generic[T]):
    """Circular singly linked list storing only a `tail` reference."""

    def __init__(self) -> None:
        self.tail: CircularNode[T] | None = None
        self._size: int = 0

    def __len__(self) -> int:
        return self._size

    def prepend(self, value: T) -> None:
        """Insert at head (tail.next) in O(1) time."""
        new_node = CircularNode(data=value)
        if self.tail is None:
            new_node.next = new_node
            self.tail = new_node
        else:
            new_node.next = self.tail.next
            self.tail.next = new_node
        self._size += 1

    def append(self, value: T) -> None:
        """Insert at tail in O(1) time."""
        self.prepend(value)
        assert self.tail is not None
        self.tail = self.tail.next

    def rotate(self) -> None:
        """Advance head to the next node in O(1) time (round-robin step)."""
        if self.tail is not None:
            self.tail = self.tail.next

    def to_list(self) -> list[T]:
        """Traverse ring once and collect elements: O(n) time, O(n) space."""
        if self.tail is None or self.tail.next is None:
            return []

        result: list[T] = []
        head = self.tail.next
        current = head
        while True:
            result.append(current.data)
            assert current.next is not None
            current = current.next
            if current is head:
                break
        return result


if __name__ == "__main__":
    # Singly Linked List Demo
    sll = SinglyLinkedList[int]()
    for num in [10, 20, 30]:
        sll.append(num)
    sll.prepend(5)
    sll.reverse_in_place()
    print("Reversed SLL:", list(sll))  # [30, 20, 10, 5]

    # Doubly Linked List Demo
    dll = DoublyLinkedList[str]()
    dll.append("B")
    dll.prepend("A")
    dll.append("C")
    print("DLL pop_left:", dll.pop_left(), "| DLL pop:", dll.pop(), "| Remaining:", list(dll))

    # Circular Linked List Demo
    cll = CircularSinglyLinkedList[str]()
    for worker in ["Worker-1", "Worker-2", "Worker-3"]:
        cll.append(worker)
    cll.rotate()
    print("Circular ring after 1 rotation:", cll.to_list())  # ['Worker-2', 'Worker-3', 'Worker-1']
```

## 7. Common Pitfalls and Best Practices

1. **Overwriting a `next` Pointer Before Saving It:**
   During insertion or in-place reversal, writing `current.next = new_node` before saving `old_next = current.next` orphans the remainder of the linked list and triggers garbage collection of lost nodes. Always link `new_node.next = current.next` **first**, then update `current.next = new_node`.
2. **Dereferencing `None` (`AttributeError: 'NoneType' object has no attribute 'next'`):**
   Always verify `current is not None` before reading `current.next` or `current.data`, especially in fast-pointer loops (`while fast is not None and fast.next is not None:`).
3. **Infinite Loops When Traversing a Circular Linked List:**
   A circular linked list contains no `None` pointer. Writing `while current is not None:` causes an infinite loop. Track the starting node (`head = tail.next`) and terminate when `current is head` after visiting the first node.
4. **Skipping Dummy Sentinel Nodes in Complex Pointer Manipulations:**
   Problems that modify the `head` node (such as deleting the head, partitioning, or merging two sorted lists) become error-prone when handled with separate `if head is None:` branches. Create a temporary **`dummy = SinglyNode(0, head)`** node and return `dummy.next` at the end.
5. **Reimplementing a Linked List Manually When `collections.deque` Fits:**
   In production Python code, when you need a FIFO queue or double-ended queue with $O(1)$ operations at both ends, use **`collections.deque`**, which is implemented in C as a doubly-linked list of fixed-size blocks with far lower memory overhead and faster execution than pure-Python node objects.

## 8. Quick Reference

| Linked List Variant | Node Structure | Traversal Direction | Key Advantage |
| :--- | :--- | :--- | :--- |
| **Singly Linked List** | `(data, next)` | Forward only (`head` $\rightarrow$ `tail` $\rightarrow$ `None`) | Lowest pointer memory per node; $O(1)$ head insertion/deletion |
| **Doubly Linked List** | `(prev, data, next)` | Bidirectional (`head` $\leftrightarrow$ `tail`) | $O(1)$ deletion of any known node; $O(1)$ tail deletion |
| **Circular Singly Linked List** | `(data, next)` with `tail.next = head` | Forward cyclic ring | Single `tail` pointer gives $O(1)$ access to both head and tail |
| **Circular Doubly Linked List** | `(prev, data, next)` in closed ring | Bidirectional cyclic ring | Constant-time insertion/deletion/rotation from any node |

| Classic Linked List Technique | Time / Space | When to Use |
| :--- | :--- | :--- |
| **Dummy Sentinel Node** | $O(1)$ extra space | Simplifies edge cases when `head` itself may be inserted or deleted |
| **Fast & Slow Pointers (Floyd's)** | $O(n)$ time, $O(1)$ space | Finding middle node, detecting cycles, locating cycle entry point |
| **In-Place Three-Pointer Reversal** | $O(n)$ time, $O(1)$ space | Reversing an entire list or a sublist (`prev`, `curr`, `next_node`) |
