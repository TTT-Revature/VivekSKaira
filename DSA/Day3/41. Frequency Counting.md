# Frequency Counting

## 1. Overview
**Frequency Counting** is an algorithmic pattern that tallies how many times each distinct element appears in a sequence, string, or data stream. By precomputing element multiplicities into an $O(1)$-lookup structure (such as a hash map or fixed-size direct-address array), algorithms eliminate repeated linear scans—reducing naive **$O(n^2)$** nested loops or **$O(n \log n)$** sorting solutions down to **$\Theta(n)$ single-pass** runtimes.

### Core Pattern Pipeline
```text
Input Sequence:  [ "a", "b", "a", "c", "a", "b" ]
                        |
                        v   Single Pass: O(n)
Frequency Table: { "a": 3, "b": 2, "c": 1 }
                        |
                        +---> O(1) Query: freq["a"] -> 3
                        +---> O(1) Query: freq["d"] -> 0
```

* **Where Frequency Counting Applies:**
  * **Equality & Permutation Checks:** Anagrams, array permutations, multiset equality.
  * **Uniqueness & Duplicates:** First non-repeating character, duplicate detection, majority element ($> \lfloor n / 2 \rfloor$).
  * **Top-$k$ & Mode Queries:** Most frequent elements, character histograms, bucket sorting by frequency.
  * **Prefix-Sum & Sliding-Window Invariants:** Subarray sum equals $K$, minimum window substring, longest substring with at most $K$ distinct characters.

## 2. Choosing the Right Frequency Container

Depending on key types, value ranges, and memory constraints, three data structures are used to store frequencies:

| Container Strategy | Best When | Time Complexity (Build) | Auxiliary Space | Key Advantages & Trade-Offs |
| :--- | :--- | :--- | :--- | :--- |
| **Hash Map (`dict`, `defaultdict`, `Counter`)** | Keys are arbitrary hashables (`str`, large `int`, `tuple`) or sparse | **$\Theta(n)$** expected | **$\Theta(k)$** ($k$ = unique keys) | Most flexible; handles negative numbers, huge integers, and Unicode text; slight hashing overhead |
| **Fixed-Size Array (Direct-Address Table)** | Keys come from a small, dense, known range (e.g., `'a'..'z'`, `0..255`) | **$\Theta(n)$** deterministic | **$\Theta(M)$** ($M$ = domain size, e.g., $26$) | Fastest wall-clock speed; zero hash collisions; contiguous CPU cache access; fails if domain $M$ is large |
| **Sort + Adjacent Scan** | Keys are unhashable or $O(1)$ extra space is strictly required | **$\Theta(n \log n)$** | **$O(1)$** (in-place sort) | Slower than hashing ($O(n \log n)$ vs. $O(n)$) and mutates input order, but uses zero extra memory |

### Direct-Address Index Mapping Formulas
When using a fixed-size array for bounded character or integer domains:
* **Lowercase English Letters (`'a'` to `'z'`):** `index = ord(ch) - ord('a')` (array size `26`).
* **Uppercase English Letters (`'A'` to `'Z'`):** `index = ord(ch) - ord('A')` (array size `26`).
* **Extended ASCII Characters:** `index = ord(ch)` (array size `128` or `256`).
* **Bounded Integers in `[low, high]`:** `index = val - low` (array size `high - low + 1`).

## 3. Step-by-Step Visual Traces

### 1. Two-Pass Frequency Scan (First Unique Character in `"abacabad"`)
```text
Pass 1 — Build Frequency Map:
  Index:  0   1   2   3   4   5   6   7
  Chars: 'a' 'b' 'a' 'c' 'a' 'b' 'a' 'd'
  Counts: {'a': 4, 'b': 2, 'c': 1, 'd': 1}

Pass 2 — Scan Left-to-Right for First Char with Count == 1:
  i = 0 ('a'): count = 4 (skip)
  i = 1 ('b'): count = 2 (skip)
  i = 2 ('a'): count = 4 (skip)
  i = 3 ('c'): count = 1 -> MATCH! Return index 3 ('c')
```

### 2. Prefix-Sum Frequency Map (`Subarray Sum Equals K`, `nums = [1, 2, 1, 3]`, `k = 3`)
At any index $j$ with running sum $S_j$, a subarray `(i + 1 .. j)` sums to $K$ if and only if a prior prefix had sum $S_i = S_j - K$:

```text
Initial State: prefix_counts = {0: 1}, running_sum = 0, total = 0

Step 1 (num = 1):
  running_sum = 1 | need = 1 - 3 = -2 (count: 0) -> total = 0
  record sum 1    -> prefix_counts = {0: 1, 1: 1}

Step 2 (num = 2):
  running_sum = 3 | need = 3 - 3 = 0  (count: 1) -> total = 1   (subarray [1, 2])
  record sum 3    -> prefix_counts = {0: 1, 1: 1, 3: 1}

Step 3 (num = 1):
  running_sum = 4 | need = 4 - 3 = 1  (count: 1) -> total = 2   (subarray [2, 1])
  record sum 4    -> prefix_counts = {0: 1, 1: 1, 3: 1, 4: 1}

Step 4 (num = 3):
  running_sum = 7 | need = 7 - 3 = 4  (count: 1) -> total = 3   (subarray [3])
  record sum 7    -> prefix_counts = {0: 1, 1: 1, 3: 1, 4: 1, 7: 1}

Result: 3 subarrays sum to 3
```

## 4. Time and Space Complexity Analysis
Assume $n$ is the input length and $k$ is the number of distinct elements ($k \le n$):

| Operation / Algorithmic Pattern | Time Complexity | Auxiliary Space | Notes |
| :--- | :--- | :--- | :--- |
| **Build Frequency Map (`Counter(items)`)** | $\Theta(n)$ average | $\Theta(k)$ | Single pass over all $n$ elements |
| **Query / Increment / Decrement** | $\Theta(1)$ average | $O(1)$ | Hash table or direct array index lookup |
| **Top-$k$ Frequent (Bucket Sort)** | **$\Theta(n)$** | $\Theta(n)$ | Indexes elements into frequency buckets `0..n` |
| **Top-$k$ Frequent (Min-Heap / `most_common(k)`)** | $\Theta(n + k \log k)$ or $O(n \log k)$ | $\Theta(k)$ | Better when $k \ll n$ and streaming memory matters |
| **Subarray Sum Equals $K$ (Prefix Map)** | **$\Theta(n)$** | $\Theta(n)$ | Works with negative numbers (unlike sliding window) |
| **Fixed-Window Anagram Search** | **$\Theta(n)$** | $O(\vert{}\Sigma\vert{})$ | $O(1)$ space when alphabet size $\vert{}\Sigma\vert{} = 26$ |

## 5. Python Implementations

### 1. Four Idiomatic Ways to Build a Frequency Table
```python
from collections import Counter, defaultdict
from collections.abc import Iterable
from typing import TypeVar

T = TypeVar("T")


def count_with_dict(items: Iterable[T]) -> dict[T, int]:
    """Standard dictionary using dict.get() — zero imports required."""
    counts: dict[T, int] = {}
    for item in items:
        counts[item] = counts.get(item, 0) + 1
    return counts


def count_with_defaultdict(items: Iterable[T]) -> defaultdict[T, int]:
    """Using defaultdict(int) to eliminate explicit missing-key checks."""
    counts: defaultdict[T, int] = defaultdict(int)
    for item in items:
        counts[item] += 1
    return counts


def count_with_counter(items: Iterable[T]) -> Counter[T]:
    """Using C-optimized collections.Counter (returns 0 for missing keys)."""
    return Counter(items)


def count_lowercase_ascii(text: str) -> list[int]:
    """
    Fixed 26-slot frequency array for lowercase 'a'..'z'.
    Time: Theta(n) | Auxiliary Space: O(1) (fixed 26 integers)
    """
    counts = [0] * 26
    base = ord("a")
    for ch in text:
        counts[ord(ch) - base] += 1
    return counts
```

### 2. Essential DSA Problem Patterns
```python
def first_unique_char_index(text: str) -> int:
    """
    Return the index of the first non-repeating character, or -1 if none exists.
    Time: Theta(n) | Auxiliary Space: O(k) (at most alphabet size)
    """
    counts = Counter(text)
    for idx, ch in enumerate(text):
        if counts[ch] == 1:
            return idx
    return -1


def top_k_frequent(nums: list[int], k: int) -> list[int]:
    """
    Return the `k` most frequent integers in Theta(n) time using Bucket Sort.
    Time: Theta(n) | Auxiliary Space: Theta(n)
    """
    counts = Counter(nums)
    # Frequency of any element is bounded between 1 and len(nums)
    buckets: list[list[int]] = [[] for _ in range(len(nums) + 1)]
    for num, freq in counts.items():
        buckets[freq].append(num)

    result: list[int] = []
    for freq in range(len(buckets) - 1, 0, -1):
        for num in buckets[freq]:
            result.append(num)
            if len(result) == k:
                return result
    return result


def subarray_sum_equals_k(nums: list[int], k: int) -> int:
    """
    Count contiguous subarrays whose elements sum to `k` (supports negative values).
    Time: Theta(n) | Auxiliary Space: Theta(n)
    """
    prefix_counts: defaultdict[int, int] = defaultdict(int)
    prefix_counts[0] = 1  # Empty prefix sum before index 0

    running_sum = 0
    matching_subarrays = 0

    for num in nums:
        running_sum += num
        matching_subarrays += prefix_counts[running_sum - k]
        prefix_counts[running_sum] += 1

    return matching_subarrays


def find_all_anagram_indices(text: str, pattern: str) -> list[int]:
    """
    Find all start indices of `pattern`'s anagrams inside `text` using a fixed sliding window.
    Time: Theta(n) | Auxiliary Space: O(|Sigma|)
    """
    n, m = len(text), len(pattern)
    if m > n:
        return []

    target = Counter(pattern)
    window: Counter[str] = Counter(text[:m])
    indices: list[int] = [0] if window == target else []

    for right in range(m, n):
        # Add incoming character on the right
        window[text[right]] += 1

        # Remove outgoing character on the left and prune zero counts
        left_char = text[right - m]
        window[left_char] -= 1
        if window[left_char] == 0:
            del window[left_char]

        if window == target:
            indices.append(right - m + 1)

    return indices


if __name__ == "__main__":
    print("First unique index:", first_unique_char_index("abacabad"))
    print("Top 2 frequent:    ", top_k_frequent([1, 1, 1, 2, 2, 3], k=2))
    print("Subarrays sum = 3: ", subarray_sum_equals_k([1, 2, 1, 3], k=3))
    print("Anagram indices:   ", find_all_anagram_indices("cbaebabacd", "abc"))
```

## 6. Common Pitfalls and Best Practices

1. **Calling `seq.count(x)` Inside a Loop ($O(n^2)$ Trap):**
   Python's `list.count(x)` and `str.count(x)` scan the entire sequence in $O(n)$ time on every call. Calling `items.count(x)` inside a `for x in items:` loop turns a linear problem into **$O(n^2)$**; always precompute counts once with `Counter(items)`.
2. **Leaving Zero-Count Keys in a Sliding-Window Frequency Map:**
   When shrinking a sliding window, decrementing `window[ch] -= 1` leaves `ch: 0` in the dictionary. That breaks `len(window)` (distinct element count) and `window == target` comparisons (`Counter({'a': 0}) != Counter()`). Always execute **`if window[ch] == 0: del window[ch]`**.
3. **Confusing `Counter` Subtraction (`c1 - c2`) with `c1.subtract(c2)`:**
   `c1 - c2` returns a new `Counter` containing **only keys with strictly positive counts** (`> 0`), whereas the in-place method `c1.subtract(c2)` retains zero and negative counts.
4. **Forgetting `prefix_counts[0] = 1` in Prefix-Sum Frequency Problems:**
   Without initializing `prefix_counts[0] = 1`, any valid subarray starting at index `0` (where `running_sum == k`, so `running_sum - k == 0`) will be missed.
5. **Using a `dict` When a 26-Element Array Suffices (or Vice Versa):**
   For tight inner loops over lowercase English letters (`'a'..'z'`), a 26-element `list[int]` avoids hashing and object allocation overhead. Conversely, never use a fixed array if inputs can contain arbitrary Unicode characters or unbounded integers.

## 7. Quick Reference

| Concept / Tool | Key Detail |
| :--- | :--- |
| **Core Purpose** | Tallies element multiplicities in $\Theta(n)$ time to answer membership/count queries in $\Theta(1)$ |
| **Python Standard Tools** | `collections.Counter`, `collections.defaultdict(int)`, `dict.get(k, 0) + 1` |
| **Useful `Counter` Methods** | `c.most_common(k)`, `c.total()`, multiset intersection `c1 & c2`, union `c1 \| c2` |
| **Top-$k$ Frequent Pattern** | Bucket Sort over frequencies `1..n` achieves **$\Theta(n)$** worst-case time |
| **Prefix-Sum Pattern** | `prefix_counts[running_sum - k]` counts subarrays summing to $K$ in **$\Theta(n)$** time |
| **Sliding-Window Rule** | Delete keys when their frequency drops to `0` so `len(window)` and `window == target` stay exact |
