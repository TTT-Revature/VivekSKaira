# Deduplication

## 1. Overview
**Deduplication** is the process of identifying and removing duplicate occurrences of elements from a collection, sequence, or data stream so that each unique item appears only once (or at most $k$ times in generalized variants).

Choosing the optimal deduplication algorithm depends on three design constraints:
1. **Order Preservation:** Must the original first-seen order be preserved, or is arbitrary / sorted order acceptable?
2. **Memory Model:** Can you allocate $O(n)$ auxiliary memory for a hash structure, or must deduplication happen **in-place** in $O(1)$ extra space?
3. **Element Hashability:** Are elements immutable and hashable (`int`, `str`, `tuple`), or unhashable (`dict`, `list`)?

### Strategy Selection Decision Flow
```text
                        [ Input Collection ]
                                 |
               Is input already sorted (or sortable in-place)?
                      /                         \
                    Yes                          No
                    /                             \
        [ Two-Pointer In-Place ]         Is element / key hashable?
        Time: O(n) | Space: O(1)            /                 \
                                          Yes                  No
                                          /                     \
                            Need original order?       [ Canonical Key / Sort ]
                                /          \            Convert to tuple/JSON key
                              Yes           No          or sort with custom key
                              /              \
                  [ dict.fromkeys() ]   [ list(set(x)) ]
                  Time: Theta(n)        Time: Theta(n)
                  Space: Theta(n)       Space: Theta(n)
```

## 2. Core Deduplication Strategies

| Strategy | Preserves Order? | Time Complexity | Auxiliary Space | Hashable Required? | Best Use Case |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Unordered Hash Set (`list(set(items))`)** | **No** | **$\Theta(n)$** avg | $\Theta(k)$ | Yes | Fastest deduplication when output order does not matter |
| **Order-Preserving Hash Set (`dict.fromkeys` / `seen`)** | **Yes** (first-seen) | **$\Theta(n)$** avg | $\Theta(k)$ | Yes | General-purpose sequence deduplication preserving original order |
| **Key-Selector Hash Set (`seen_keys`)** | **Yes** (first-seen) | **$\Theta(n)$** avg | $\Theta(k)$ | Key only | Deduplicating records, objects, or `dict` items by a specific field (e.g., `user["id"]`) |
| **Pre-Sorted Two-Pointer Scan** | **Yes** (sorted) | **$\Theta(n)$** | **$O(1)$** | No | In-place compaction of an already-sorted array with zero extra memory |
| **Sort + Two-Pointer Scan** | **No** (sorts data) | **$\Theta(n \log n)$** | **$O(1)$** | No | Unhashable or memory-constrained inputs where sorting is permitted |
| **Nested Loop Scan** | **Yes** | **$O(n^2)$** | **$O(1)$** | No | Tiny lists ($n \lt 20$) of unhashable objects without a canonical key |
| **Bloom Filter (Probabilistic)** | **Yes** (streaming) | **$O(1)$** per item | **$O(m)$ bits** | Yes | High-throughput streams where tiny false-positive rates are acceptable |

*(Here $n$ is total input length and $k$ is the number of unique elements, $k \le n$.)*

## 3. Step-by-Step Visual Traces

### 1. Order-Preserving Hash Set (`[4, 2, 4, 1, 2, 3]`)
We maintain a `seen` hash set for $O(1)$ membership checks and an `output` list for first-seen order:

```text
Input: [ 4, 2, 4, 1, 2, 3 ]

Step 1: item = 4 -> not in seen -> seen = {4},          output = [4]
Step 2: item = 2 -> not in seen -> seen = {4, 2},       output = [4, 2]
Step 3: item = 4 -> IN seen     -> skip                 output = [4, 2]
Step 4: item = 1 -> not in seen -> seen = {4, 2, 1},    output = [4, 2, 1]
Step 5: item = 2 -> IN seen     -> skip                 output = [4, 2, 1]
Step 6: item = 3 -> not in seen -> seen = {4, 2, 1, 3}, output = [4, 2, 1, 3]

Final Result: [ 4, 2, 1, 3 ]
```

### 2. In-Place Two-Pointer Compaction on a Sorted Array (`[1, 1, 2, 2, 2, 3]`)
For a sorted array, all duplicates sit adjacently. A slow pointer `write` tracks the next free slot for a unique element, while a fast pointer `read` scans forward:

```text
Initial: [ 1, 1, 2, 2, 2, 3 ]   write = 1 (index 0 is always unique)

read = 1: arr[1] (1) == arr[write - 1] (1) -> duplicate -> advance read
          [ 1, 1, 2, 2, 2, 3 ]
               ^w ^r

read = 2: arr[2] (2) != arr[write - 1] (1) -> unique! -> arr[1] = 2, write = 2
          [ 1, 2, 2, 2, 2, 3 ]
                  ^w ^r

read = 3: arr[3] (2) == arr[write - 1] (2) -> duplicate -> advance read
read = 4: arr[4] (2) == arr[write - 1] (2) -> duplicate -> advance read
          [ 1, 2, 2, 2, 2, 3 ]
                  ^w       ^r

read = 5: arr[5] (3) != arr[write - 1] (2) -> unique! -> arr[2] = 3, write = 3
          [ 1, 2, 3 | 2, 2, 3 ]
                     ^w (unique count = 3)

Truncate suffix arr[3:]: [ 1, 2, 3 ]
```

## 4. Time and Space Complexity Analysis

| Method / Implementation | Best Case | Average Case | Worst Case | Auxiliary Space |
| :--- | :--- | :--- | :--- | :--- |
| **`list(dict.fromkeys(items))`** | $\Theta(n)$ | **$\Theta(n)$** | $O(n^2)$ (hash collision) | $\Theta(k)$ |
| **Explicit `seen` Set + Output List** | $\Theta(n)$ | **$\Theta(n)$** | $O(n^2)$ (hash collision) | $\Theta(k)$ |
| **Sorted Array Two-Pointer (`in-place`)** | $\Theta(n)$ | **$\Theta(n)$** | **$\Theta(n)$** | **$O(1)$** |
| **Unsorted Array `sort()` + Two-Pointer** | $\Omega(n)$ (Timsort) | **$\Theta(n \log n)$** | **$O(n \log n)$** | $O(n)$ (Timsort buffer) |
| **Brute-Force (`if x not in res`)** | $\Theta(n)$ (all same) | $\Theta(n \cdot k)$ | **$O(n^2)$** (all unique) | $\Theta(k)$ |

## 5. Python Implementations

### 1. Order-Preserving Deduplication (Built-in Idiom & Key-Selector Variant)
Since Python 3.7+, `dict` preserves insertion order, making `list(dict.fromkeys(items))` the fastest C-level idiom for hashable elements:

```python
from collections.abc import Callable, Hashable, Iterable
from typing import TypeVar

T = TypeVar("T")
H = TypeVar("H", bound=Hashable)


def deduplicate_fast(items: Iterable[H]) -> list[H]:
    """
    Remove duplicates while preserving first-seen order using C-optimized dict.fromkeys.
    Time: Theta(n) average | Auxiliary Space: Theta(k)
    """
    return list(dict.fromkeys(items))


def deduplicate_by_key(
    items: Iterable[T],
    key: Callable[[T], Hashable],
) -> list[T]:
    """
    Deduplicate arbitrary (even unhashable) objects by projecting each item
    onto a hashable key, keeping the first occurrence of each key.
    Time: Theta(n) average | Auxiliary Space: Theta(k)
    """
    seen_keys: set[Hashable] = set()
    unique_items: list[T] = []

    for item in items:
        item_key = key(item)
        if item_key not in seen_keys:
            seen_keys.add(item_key)
            unique_items.append(item)

    return unique_items
```

### 2. In-Place Two-Pointer Deduplication on Sorted Lists (At Most $1$ or $m$ Copies)
```python
def deduplicate_sorted_in_place(sorted_items: list[T], max_occurrences: int = 1) -> int:
    """
    Compact a sorted list in-place so each unique value appears at most `max_occurrences` times.
    Truncates trailing elements and returns the new length.
    Time: Theta(n) | Auxiliary Space: O(1)
    """
    if max_occurrences < 1:
        raise ValueError("max_occurrences must be >= 1")

    n = len(sorted_items)
    if n <= max_occurrences:
        return n

    write = max_occurrences
    for read in range(max_occurrences, n):
        # Compare against the element `max_occurrences` slots behind `write`
        if sorted_items[read] != sorted_items[write - max_occurrences]:
            sorted_items[write] = sorted_items[read]
            write += 1

    del sorted_items[write:]
    return write
```

### 3. Deduplicating Unhashable Nested Dictionaries / Lists
When records have no single primary key and contain unhashable nested structures (`dict`, `list`), serialize each record into a deterministic canonical `str` via `json.dumps(..., sort_keys=True)`:

```python
import json
from typing import Any


def deduplicate_records(records: Iterable[dict[str, Any]]) -> list[dict[str, Any]]:
    """
    Deduplicate a sequence of unhashable dictionaries by full structural equality,
    preserving first-seen order.
    Time: Theta(n * S) where S is serialized record size | Auxiliary Space: Theta(n * S)
    """
    return deduplicate_by_key(
        records,
        key=lambda rec: json.dumps(rec, sort_keys=True, separators=(",", ":")),
    )


if __name__ == "__main__":
    nums = [4, 2, 4, 1, 2, 3, 1]
    print("Order-preserved:", deduplicate_fast(nums))

    users = [
        {"id": 101, "name": "Alice"},
        {"id": 102, "name": "Bob"},
        {"id": 101, "name": "Alice (Updated)"},
    ]
    print("Deduplicated by user ID:", deduplicate_by_key(users, key=lambda u: u["id"]))

    sorted_nums = [1, 1, 1, 2, 2, 3, 4, 4]
    new_len = deduplicate_sorted_in_place(sorted_nums, max_occurrences=1)
    print("In-place sorted unique:", sorted_nums, "| Length:", new_len)

    raw_events = [{"a": 1, "b": 2}, {"b": 2, "a": 1}, {"a": 2, "b": 3}]
    print("Deduplicated JSON records:", deduplicate_records(raw_events))
```

## 6. Common Pitfalls and Best Practices

1. **Using `list(set(items))` When Sequence Order Matters:**
   `set` does not preserve insertion order; converting `list(set(items))` scrambles element order arbitrarily across runs due to randomized string hash salts. Use **`list(dict.fromkeys(items))`** whenever order must be preserved.
2. **Checking `if x not in result_list:` Inside a Loop ($O(n^2)$ Trap):**
   Because `x in list` performs a linear scan on every iteration, building a deduplicated list without an accompanying `set` degrades from $\Theta(n)$ to **$O(n^2)$**. Always pair the output `list` with a `seen` `set`.
3. **Mutating a List While Iterating Over It (`items.remove(x)`):**
   Calling `items.remove(x)` inside a `for x in items:` loop shifts subsequent elements left, causing the iterator to **skip adjacent elements** and turning runtime into **$O(n^2)$**. Build a new list or use a read/write two-pointer pass instead.
4. **Forgetting to Truncate the Tail After In-Place Two-Pointer Compaction:**
   In-place two-pointer algorithms overwrite prefixes `arr[0 : write]` but leave stale duplicate values in `arr[write : n]`. Always truncate with **`del arr[write:]`** (or slice `arr[:write]`) unless the caller strictly consumes only the returned length `write`.
5. **Floating-Point `NaN` Identity vs. Equality Quirks:**
   In IEEE-754 floating-point arithmetic, `float("nan") == float("nan")` evaluates to `False`. If two distinct `NaN` objects appear in a list, `dict.fromkeys` treats them as distinct keys unless normalized beforehand (e.g., `math.isnan(x)`).

## 7. Quick Reference

| Task / Scenario | Recommended Python Solution | Time | Space |
| :--- | :--- | :--- | :--- |
| **Preserve order (hashable items)** | `list(dict.fromkeys(items))` | $\Theta(n)$ | $\Theta(k)$ |
| **Order irrelevant (hashable items)** | `list(set(items))` | $\Theta(n)$ | $\Theta(k)$ |
| **Deduplicate objects/dicts by field** | `seen = set()` tracking `key(item)` | $\Theta(n)$ | $\Theta(k)$ |
| **Sorted array, zero extra memory** | Two-pointer `write` / `read` + `del arr[write:]` | $\Theta(n)$ | $O(1)$ |
| **Keep last occurrence instead of first** | Reverse input $\to$ `dict.fromkeys` $\to$ reverse back | $\Theta(n)$ | $\Theta(k)$ |
| **Unhashable nested dicts/lists** | Key via `json.dumps(item, sort_keys=True)` | $\Theta(n)$ | $\Theta(n)$ |
