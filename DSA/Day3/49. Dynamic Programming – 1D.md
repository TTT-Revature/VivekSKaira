# Dynamic Programming: 1D

## 1. Overview
**Dynamic Programming (DP)** is an optimization and counting paradigm that solves complex problems by breaking them into smaller, **overlapping subproblems** and caching each subproblem's result so it is computed only once. In **1D Dynamic Programming**, every subproblem state is uniquely identified by a **single index or scalar parameter** (`dp[i]`), allowing solutions to be stored in a one-dimensional array (or collapsed into a few rolling variables).

### Why Naive Recursion Explodes vs. 1D DP Collapsing
Consider computing `climb(4)` where each step advances by $1$ or $2$ stairs (`ways(n) = ways(n - 1) + ways(n - 2)`):

```text
Naive Recursion Tree (Exponential O(2^n)):        1D DP Dependency DAG (Linear Theta(n)):
                 climb(4)
                /        \                        dp[0] ---> dp[1] ---> dp[2] ---> dp[3] ---> dp[4]
           climb(3)      climb(2)                   |          ^          ^          ^          ^
           /      \       /     \                   +----------+          |          |          |
      climb(2)  climb(1) climb(1) climb(0)                     +----------+          |          |
       /    \                                                             +----------+          |
  climb(1) climb(0)   <-- Repeated subtrees!                                         +----------+
```

### Two Fundamental Requirements for Dynamic Programming
1. **Overlapping Subproblems:** A recursive breakdown visits the exact same subproblem states multiple times. Caching those states eliminates exponential recomputation.
2. **Optimal Substructure:** An optimal solution to state $i$ can be constructed directly from optimal solutions to smaller subproblems ($j \lt i$).

### Top-Down Memoization vs. Bottom-Up Tabulation

| Dimension | Top-Down (Memoization) | Bottom-Up (Tabulation) | Space-Optimized Tabulation |
| :--- | :--- | :--- | :--- |
| **Execution Direction** | Starts at target `n` and recurses down to base cases | Starts at base cases (`0, 1`) and iterates up to `n` | Iterates bottom-up while keeping only recent states |
| **Implementation Style** | Recursive function + `@cache` / `dict` | Iterative `for` loop filling a 1D `dp` list | Iterative `for` loop with scalar variables (`prev1, prev2`) |
| **States Evaluated** | Only reachable subproblems | All subproblems in `0 .. n` | All subproblems in `0 .. n` |
| **Call-Stack Risk** | Hits Python `RecursionError` if depth $\ge 1000$ | **None** (purely iterative) | **None** (purely iterative) |
| **Auxiliary Space** | $\Theta(n)$ cache + $\Theta(n)$ call stack | $\Theta(n)$ table | **$O(1)$** when window of dependencies is constant |

## 2. The 4-Step 1D DP Design Framework and Archetypes

### The 4-Step Design Framework
1. **Define the State (`dp[i]`):** State precisely in plain English what `dp[i]` represents (for example, *"the minimum coins needed to make amount `i`"* or *"the length of the longest increasing subsequence ending strictly at index `i`"*).
2. **Formulate the Transition (Recurrence Relation):** Write the equation relating `dp[i]` to earlier states (`dp[i - 1]`, `dp[i - 2]`, `dp[i - c]`, or `dp[j]` for $j \lt i$).
3. **Set Base Cases:** Initialize boundary entries (`dp[0]`, `dp[1]`) so every recurrence step reads valid, initialized values.
4. **Determine Iteration Order and Space Reduction:** Iterate in an order where all dependencies of `dp[i]` are already solved. If `dp[i]` depends only on a fixed number of preceding states (e.g., `i - 1` and `i - 2`), replace the array with $O(1)$ variables.

### Five Core 1D DP Archetypes

| Archetype | State Definition (`dp[i]`) | Typical Recurrence Transition | Time | Classic Problems |
| :--- | :--- | :--- | :--- | :--- |
| **1. Linear Prefix / Fibonacci** | Optimal value or count for prefix `0 .. i` | `dp[i] = f(dp[i - 1], dp[i - 2])` | $\Theta(n)$ | Climbing Stairs, House Robber, Decode Ways |
| **2. Contiguous Kadane-Style** | Best subarray metric **ending at `i`** | `dp[i] = max(nums[i], dp[i - 1] + nums[i])` | $\Theta(n)$ | Maximum Subarray, Maximum Product Subarray |
| **3. Unbounded Target / Coin** | Optimal cost or count to reach target `i` | `dp[i] = min(dp[i - c] + 1)` over all $c \le i$ | $\Theta(n \cdot C)$ | Coin Change, Combination Sum IV, Perfect Squares |
| **4. Subsequence Ending at `i`** | Best subsequence length **ending at `i`** | `dp[i] = 1 + max(dp[j])` for $j \lt i$ if valid | $\Theta(n^2)$ | Longest Increasing Subsequence (LIS), Max Chain |
| **5. Prefix Segmentation** | Boolean: can `s[0 : i]` be segmented? | `dp[i] = any(dp[j] and s[j:i] in words)` | $\Theta(n^2)$ | Word Break, Palindrome Partitioning II |

## 3. Step-by-Step Visual Traces

### 1. House Robber (`nums = [2, 7, 9, 3, 1]`) — Rolling Variable Optimization
At house `i`, you either **skip** house `i` (keeping `dp[i - 1]`) or **rob** house `i` (adding `nums[i]` to `dp[i - 2]`):

$$\text{dp}[i] = \max(\text{dp}[i - 1],\; \text{dp}[i - 2] + \text{nums}[i])$$

```text
Index i:        0      1      2      3      4
nums[i]:        2      7      9      3      1
------------------------------------------------
Base i = 0:    [2]                                -> dp[0] = 2
Base i = 1:     2     [7]                         -> dp[1] = max(2, 7) = 7
Step i = 2:     2      7    [11]                  -> dp[2] = max(7, 2 + 9)  = 11
Step i = 3:     2      7     11    [11]           -> dp[3] = max(11, 7 + 3) = 11
Step i = 4:     2      7     11     11    [12]    -> dp[4] = max(11, 11 + 1) = 12

Rolling Variables (O(1) space):
  Start: prev2 = 2, prev1 = 7
  i = 2: curr = max(7, 2 + 9)  = 11  -> prev2 = 7,  prev1 = 11
  i = 3: curr = max(11, 7 + 3) = 11  -> prev2 = 11, prev1 = 11
  i = 4: curr = max(11, 11 + 1)= 12  -> prev2 = 11, prev1 = 12  (Answer: 12)
```

### 2. Coin Change (`coins = [1, 3, 4]`, `amount = 6`) — Why 1D DP Beats Greedy
Greedy picks `4 + 1 + 1 = 3` coins, whereas 1D DP evaluates every coin `c` at every sub-amount `a`:

$$\text{dp}[a] = \min_{c \in \text{coins},\; c \le a} \left(\text{dp}[a - c] + 1\right)$$

```text
Amount a:       0     1     2     3     4     5     6
Initial dp:   [ 0,  inf,  inf,  inf,  inf,  inf,  inf ]

a = 1: coin 1 -> dp[0] + 1 = 1                        -> dp[1] = 1
a = 2: coin 1 -> dp[1] + 1 = 2                        -> dp[2] = 2
a = 3: coin 1 -> dp[2] + 1 = 3 | coin 3 -> dp[0] + 1 = 1 -> dp[3] = 1
a = 4: coin 1 -> dp[3] + 1 = 2 | coin 3 -> dp[1] + 1 = 2
       coin 4 -> dp[0] + 1 = 1                        -> dp[4] = 1
a = 5: coin 1 -> dp[4] + 1 = 2 | coin 3 -> dp[2] + 1 = 3
       coin 4 -> dp[1] + 1 = 2                        -> dp[5] = 2
a = 6: coin 1 -> dp[5] + 1 = 3 | coin 3 -> dp[3] + 1 = 2
       coin 4 -> dp[2] + 1 = 3                        -> dp[6] = 2  (coins: 3 + 3)

Final Table:  [ 0,    1,    2,    1,    1,    2,    2 ] -> Answer: 2
```

## 4. Time and Space Complexity Analysis

| Problem | Naive Recursion | Top-Down Memoized | Bottom-Up 1D Table | Space-Optimized |
| :--- | :--- | :--- | :--- | :--- |
| **Climbing Stairs ($n$ steps)** | $O(2^n)$ | $\Theta(n)$ time \| $\Theta(n)$ space | $\Theta(n)$ time \| $\Theta(n)$ space | **$\Theta(n)$ time \| $O(1)$ space** |
| **House Robber ($n$ houses)** | $O(2^n)$ | $\Theta(n)$ time \| $\Theta(n)$ space | $\Theta(n)$ time \| $\Theta(n)$ space | **$\Theta(n)$ time \| $O(1)$ space** |
| **Maximum Subarray (Kadane's)** | $O(n^2)$ | $\Theta(n)$ time \| $\Theta(n)$ space | $\Theta(n)$ time \| $\Theta(n)$ space | **$\Theta(n)$ time \| $O(1)$ space** |
| **Coin Change (Amount $A$, $C$ coins)** | $O(C^A)$ | $\Theta(A \cdot C)$ time \| $\Theta(A)$ space | **$\Theta(A \cdot C)$ time \| $\Theta(A)$ space** | Cannot reduce below $\Theta(A)$ |
| **Longest Increasing Subsequence** | $O(2^n)$ | $\Theta(n^2)$ time \| $\Theta(n)$ space | $\Theta(n^2)$ time \| $\Theta(n)$ space | **$\Theta(n \log n)$** via binary search |
| **Word Break (Length $n$, Dict $W$)** | $O(2^n)$ | $O(n^2)$ time \| $\Theta(n)$ space | **$O(n^2)$ time \| $\Theta(n)$ space** | Cannot reduce below $\Theta(n)$ |

## 5. Practical Python Implementations

### 1. Top-Down Memoization vs. Space-Optimized Bottom-Up (`House Robber`)
```python
from functools import cache


def rob_houses_memoized(nums: list[int]) -> int:
    """
    Top-down 1D DP using functools.cache.
    Time: Theta(n) | Auxiliary Space: Theta(n) (cache + recursion stack)
    """
    @cache
    def best_from(index: int) -> int:
        if index >= len(nums):
            return 0
        rob_current = nums[index] + best_from(index + 2)
        skip_current = best_from(index + 1)
        return max(rob_current, skip_current)

    return best_from(0)


def rob_houses_optimized(nums: list[int]) -> int:
    """
    Space-optimized bottom-up 1D DP using two rolling variables.
    Time: Theta(n) | Auxiliary Space: O(1)
    """
    prev2 = 0  # Represents dp[i - 2]
    prev1 = 0  # Represents dp[i - 1]

    for amount in nums:
        current = max(prev1, prev2 + amount)
        prev2 = prev1
        prev1 = current

    return prev1
```

### 2. Kadane's Algorithm (`Maximum Subarray Sum`)
```python
def max_subarray_sum(nums: list[int]) -> int:
    """
    Find the largest sum of any non-empty contiguous subarray.
    State meaning: `current_max` = max subarray sum ending strictly at the current index.
    Time: Theta(n) | Auxiliary Space: O(1)
    """
    if not nums:
        raise ValueError("nums must be non-empty")

    current_max = nums[0]
    global_max = nums[0]

    for value in nums[1:]:
        current_max = max(value, current_max + value)
        if current_max > global_max:
            global_max = current_max

    return global_max
```

### 3. Coin Change (`Minimum Coins to Make Target Amount`)
```python
def coin_change_min_coins(coins: list[int], amount: int) -> int:
    """
    Return the fewest coins needed to sum to `amount`, or -1 if impossible.
    Uses `amount + 1` as an integer sentinel for unreachable amounts.
    Time: Theta(amount * len(coins)) | Auxiliary Space: Theta(amount)
    """
    if amount == 0:
        return 0

    unreachable = amount + 1
    dp = [unreachable] * (amount + 1)
    dp[0] = 0

    for current_amount in range(1, amount + 1):
        for coin in coins:
            if coin <= current_amount:
                candidate = dp[current_amount - coin] + 1
                if candidate < dp[current_amount]:
                    dp[current_amount] = candidate

    return -1 if dp[amount] == unreachable else dp[amount]
```

### 4. Longest Increasing Subsequence (`O(n^2)` 1D DP and `O(n log n)` Binary Search)
```python
from bisect import bisect_left


def length_of_lis_dp(nums: list[int]) -> int:
    """
    Standard 1D DP: `dp[i]` = length of longest strictly increasing subsequence ending at `i`.
    Time: Theta(n^2) | Auxiliary Space: Theta(n)
    """
    if not nums:
        return 0

    n = len(nums)
    dp = [1] * n

    for i in range(1, n):
        for j in range(i):
            if nums[j] < nums[i] and dp[j] + 1 > dp[i]:
                dp[i] = dp[j] + 1

    return max(dp)


def length_of_lis_binary_search(nums: list[int]) -> int:
    """
    Patience-sorting 1D optimization: `tails[k]` stores the smallest ending value
    of any strictly increasing subsequence of length `k + 1`.
    Time: Theta(n log n) | Auxiliary Space: Theta(n)
    """
    tails: list[int] = []
    for num in nums:
        pos = bisect_left(tails, num)
        if pos == len(tails):
            tails.append(num)
        else:
            tails[pos] = num
    return len(tails)


if __name__ == "__main__":
    houses = [2, 7, 9, 3, 1]
    print("House Robber (memoized): ", rob_houses_memoized(houses))
    print("House Robber (optimized):", rob_houses_optimized(houses))
    print("Max Subarray Sum:        ", max_subarray_sum([-2, 1, -3, 4, -1, 2, 1, -5, 4]))
    print("Coin Change (amount=6):  ", coin_change_min_coins([1, 3, 4], amount=6))
    seq = [10, 9, 2, 5, 3, 7, 101, 18]
    print("LIS length (O(n^2)):     ", length_of_lis_dp(seq))
    print("LIS length (O(n log n)): ", length_of_lis_binary_search(seq))
```

## 6. Common Pitfalls and Best Practices

1. **Confusing "Best Ending at `i`" with "Best in Prefix `0 .. i`":**
   In problems like **Longest Increasing Subsequence** or **Maximum Subarray**, `dp[i]` must represent the best valid subsequence/subarray **ending strictly at index `i`** so you know whether `nums[i]` can legally extend it. Because the optimal subsequence can end anywhere, the final answer is **`max(dp)`**, not `dp[-1]`.
2. **Hitting Python's Default Recursion Limit (`RecursionError`):**
   CPython caps recursion depth at `1000` frames by default. For inputs where $n \ge 1000$ (such as `amount = 10000` in Coin Change), top-down recursion raises `RecursionError`. Prefer iterative **bottom-up tabulation** for production code and large constraints.
3. **Passing Unhashable Lists to `@functools.cache` / `@lru_cache`:**
   `@cache` stores function arguments in a dictionary, so passing a `list` raises `TypeError: unhashable type: 'list'`. Parameterize recursive DP helpers by integer indices (`i`) rather than passing sliced sublists (`nums[i:]`), which also avoids $O(n)$ slice copies per call.
4. **Off-by-One Table Sizing (`n` vs. `n + 1`):**
   When `dp[0]` represents an empty prefix or zero target amount (`Word Break`, `Coin Change`, `Climbing Stairs`), allocate **`n + 1`** elements (`[0] * (n + 1)`) so `dp[n]` is valid. When `dp[i]` maps 1-to-1 to array element `nums[i]` (`House Robber`, `LIS`), allocate **`n`** elements.
5. **Optimizing Space Before Proving the Recurrence (or When Reconstructing Paths):**
   Always implement and verify the full 1D `dp` array first. Collapse to `prev1, prev2` only after the recurrence is verified, and retain the full `dp` table if you need to backtrack and reconstruct the actual chosen coins or subsequence elements.

## 7. Quick Reference

| Problem / Template | State `dp[i]` | Recurrence Relation | Base Case(s) | Optimal Complexity |
| :--- | :--- | :--- | :--- | :--- |
| **Climbing Stairs** | Ways to reach step `i` | `dp[i] = dp[i - 1] + dp[i - 2]` | `dp[0] = 1, dp[1] = 1` | $\Theta(n)$ time \| $O(1)$ space |
| **House Robber** | Max money from `0 .. i` | `dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])` | `dp[0] = nums[0]` | $\Theta(n)$ time \| $O(1)$ space |
| **Maximum Subarray** | Max subarray sum ending at `i` | `dp[i] = max(nums[i], dp[i - 1] + nums[i])` | `dp[0] = nums[0]` | $\Theta(n)$ time \| $O(1)$ space |
| **Coin Change** | Min coins for amount `i` | `dp[i] = min(dp[i - c] + 1)` for $c \le i$ | `dp[0] = 0` | $\Theta(A \cdot C)$ time \| $\Theta(A)$ space |
| **Longest Increasing Subseq.** | LIS length ending at `i` | `dp[i] = 1 + max(dp[j])` ($j \lt i, a_j \lt a_i$) | `dp[i] = 1` for all `i` | $\Theta(n \log n)$ time \| $\Theta(n)$ space |
| **Word Break** | Can `s[0 : i]` be segmented? | `dp[i] = any(dp[j] and s[j:i] in word_set)` | `dp[0] = True` | $O(n^2)$ time \| $\Theta(n)$ space |
