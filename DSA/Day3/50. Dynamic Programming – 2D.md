# Dynamic Programming: 2D

## 1. Overview
**2D Dynamic Programming** extends Dynamic Programming to problems whose subproblem states require **two independent parameters** `(i, j)`. Instead of a single linear array, subproblem solutions are organized in a two-dimensional matrix `dp[i][j]`—representing relationships such as two string prefixes, a `(row, col)` grid coordinate, an `(item_index, remaining_capacity)` budget, or a subarray range `[i, j]`.

### Three Canonical 2D Dependency Geometries
```text
1. Grid Pathfinding               2. Two-Sequence Alignment         3. 0/1 Knapsack Transition
   (Top & Left Neighbors)            (Top, Left & Diagonal)            (Previous Row Lookups)

   +-------+-------+                 +-------+-------+                 +-------+-----+-------+
   |       |  Top  |                 | Diag  |  Top  |                 | prev  | ... | prev  |
   +-------+-------+                 +-------+-------+                 | [w-wt]|     |  [w]  |
   | Left  | [r,c] |                 | Left  | [i,j] |                 +-------+-----+-------+
   +-------+-------+                 +-------+-------+                     \             |
                                                                            +-----> [i, w]
```

### 1D DP vs. 2D DP

| Dimension | 1D Dynamic Programming | 2D Dynamic Programming |
| :--- | :--- | :--- |
| **State Representation** | Single parameter `dp[i]` | Two parameters `dp[i][j]` |
| **Problem Signals** | Single sequence prefix, linear steps, single target amount | Comparing two strings, 2D grid traversal, item + capacity budget, subarray intervals `[i, j]` |
| **Typical Table Size** | $\Theta(n)$ | $\Theta(m \cdot n)$ or $\Theta(n^2)$ |
| **Typical Time Complexity** | $\Theta(n)$ or $\Theta(n^2)$ | $\Theta(m \cdot n)$ or $\Theta(n^3)$ (Interval DP) |
| **Space Compression** | Often reduces from $\Theta(n)$ to $O(1)$ | Often reduces from $\Theta(m \cdot n)$ to $\Theta(n)$ using 1 or 2 rolling rows |

## 2. Core 2D DP Archetypes

| Archetype | State Definition `dp[i][j]` | Transition Dependencies | Base Cases | Iteration Order |
| :--- | :--- | :--- | :--- | :--- |
| **1. Grid / Matrix Traversal** | Ways or min cost to reach cell `(i, j)` | `dp[i - 1][j]` (top) and `dp[i][j - 1]` (left) | First row `dp[0][j]` and first col `dp[i][0]` | Top-to-bottom, left-to-right |
| **2. Two-Sequence Alignment** | Optimal match/edit cost for `s1[0:i]` and `s2[0:j]` | `dp[i - 1][j - 1]`, `dp[i - 1][j]`, `dp[i][j - 1]` | Empty-string row `dp[0][j]` and col `dp[i][0]` | `i = 1 .. m`, `j = 1 .. n` |
| **3. Capacity / 0-1 Knapsack** | Max value using first `i` items with capacity `j` | `dp[i - 1][j]` (skip) and `dp[i - 1][j - wt] + val` (take) | `dp[0][j] = 0` (0 items), `dp[i][0] = 0` (0 capacity) | `i = 1 .. n`, `j = 0 .. W` |
| **4. Interval / Range DP** | Optimal score or cost for subarray `arr[i .. j]` | `dp[i + 1][j - 1]` or split `dp[i][k] + dp[k + 1][j]` | Diagonal `dp[i][i]` (subarrays of length $1$) | Increasing length `L = 2 .. n` (or `i` downward) |

## 3. Step-by-Step Visual Traces

### 1. Edit Distance (Levenshtein): Converting `"cat"` to `"cut"`
We allocate a `(m + 1) x (n + 1)` table where `dp[i][j]` is the minimum insertions, deletions, or replacements needed to convert `word1[0:i]` into `word2[0:j]`:
* **Match (`word1[i - 1] == word2[j - 1]`):** `dp[i][j] = dp[i - 1][j - 1]` (zero cost).
* **Mismatch (`word1[i - 1] != word2[j - 1]`):** `dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1])` (Delete, Insert, or Replace).

```text
          ""    c     u     t
        +-----+-----+-----+-----+
    ""  |  0  |  1  |  2  |  3  |   <-- Base row: j insertions from ""
        +-----+-----+-----+-----+
    c   |  1  | [0] |  1  |  2  |   c == c -> diagonal (0)
        +-----+-----+-----+-----+
    a   |  2  |  1  | [1] |  2  |   a != u -> 1 + min(1, 1, 0) = 1 (replace a -> u)
        +-----+-----+-----+-----+
    t   |  3  |  2  |  2  | [1] |   t == t -> diagonal (1)
        +-----+-----+-----+-----+

Answer at dp[3][3] = 1 operation (replace 'a' with 'u').
```

### 2. 0/1 Knapsack (`weights = [1, 3, 4]`, `values = [15, 20, 30]`, `capacity = 4`)
Each item `i` can be used **at most once**:

$$\text{dp}[i][w] = \max\left(\text{dp}[i - 1][w],\; \text{val}_i + \text{dp}[i - 1][w - \text{wt}_i]\right) \quad \text{for } \text{wt}_i \le w$$

```text
Capacity w:          0     1     2     3     4
------------------------------------------------
i = 0 (no items):  [ 0,    0,    0,    0,    0 ]
i = 1 (wt=1, v=15):[ 0,   15,   15,   15,   15 ]
i = 2 (wt=3, v=20):[ 0,   15,   15,   20,   35 ]   <- at w=4: max(15, 20 + dp[1][1]) = 35
i = 3 (wt=4, v=30):[ 0,   15,   15,   20,   35 ]   <- at w=4: max(35, 30 + dp[2][0]) = 35

Optimal Value at dp[3][4] = 35 (Item 1 + Item 2: total weight 1 + 3 = 4).
```

## 4. Time and Space Complexity Analysis
Assume sequences have lengths $m$ and $n$, grids have dimensions $R \times C$, and Knapsack has $N$ items and capacity $W$:

| Problem | Full 2D Time | Full 2D Space | Space-Optimized Space | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **Unique Paths / Min Path Sum** | $\Theta(R \cdot C)$ | $\Theta(R \cdot C)$ | **$\Theta(C)$** (1 rolling row) | Only reads `top` and `left` neighbors |
| **Longest Common Subsequence (LCS)** | $\Theta(m \cdot n)$ | $\Theta(m \cdot n)$ | **$\Theta(\min(m, n)) \text{}$** | Keep full table to reconstruct the LCS string |
| **Edit Distance (Levenshtein)** | $\Theta(m \cdot n)$ | $\Theta(m \cdot n)$ | **$\Theta(\min(m, n)) \text{}$** | Requires `prev_diag` variable when using 1 row |
| **0/1 Knapsack / Subset Sum** | $\Theta(N \cdot W)$ | $\Theta(N \cdot W)$ | **$\Theta(W)$** (1 row backward) | Pseudo-polynomial in capacity $W$ |
| **Longest Palindromic Subseq.** | $\Theta(n^2)$ | $\Theta(n^2)$ | **$\Theta(n)$** | Equivalent to `LCS(s, reversed(s))` |
| **Matrix Chain Multiplication** | $\Theta(n^3)$ | $\Theta(n^2)$ | Cannot reduce below $\Theta(n^2)$ | $O(n^2)$ intervals $\times$ $O(n)$ split points $k$ |
| **Reconstructing Path / Edits** | $\Theta(m + n)$ | $\Theta(m \cdot n)$ | Requires full 2D table | Walks backward from `dp[m][n]` to `dp[0][0]` |

## 5. Practical Python Implementations

### 1. Grid Traversal with Obstacles (Space-Optimized 1D Rolling Row)
```python
def unique_paths_with_obstacles(obstacle_grid: list[list[int]]) -> int:
    """
    Count paths from top-left (0, 0) to bottom-right (R - 1, C - 1) moving only
    right or down, where 1 marks an obstacle and 0 marks an open cell.
    Time: Theta(R * C) | Auxiliary Space: Theta(C)
    """
    if not obstacle_grid or not obstacle_grid[0] or obstacle_grid[0][0] == 1:
        return 0

    cols = len(obstacle_grid[0])
    dp = [0] * cols
    dp[0] = 1

    for row in obstacle_grid:
        for c in range(cols):
            if row[c] == 1:
                dp[c] = 0
            elif c > 0:
                dp[c] += dp[c - 1]

    return dp[-1]
```

### 2. Longest Common Subsequence (Full 2D Table + Subsequence Reconstruction)
```python
def longest_common_subsequence(text1: str, text2: str) -> tuple[int, str]:
    """
    Compute the length of the Longest Common Subsequence (LCS) and reconstruct
    one valid LCS string by walking backward through the full 2D DP table.
    Time: Theta(m * n) | Auxiliary Space: Theta(m * n)
    """
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])

    # Walk backward from (m, n) to recover the subsequence characters
    lcs_chars: list[str] = []
    i, j = m, n
    while i > 0 and j > 0:
        if text1[i - 1] == text2[j - 1]:
            lcs_chars.append(text1[i - 1])
            i -= 1
            j -= 1
        elif dp[i - 1][j] >= dp[i][j - 1]:
            i -= 1
        else:
            j -= 1

    lcs_chars.reverse()
    return dp[m][n], "".join(lcs_chars)
```

### 3. Edit Distance (Levenshtein Distance — Space-Optimized Two-Row DP)
```python
def min_edit_distance(word1: str, word2: str) -> int:
    """
    Compute minimum insertions, deletions, and replacements to transform word1 into word2.
    Stores only the previous and current DP rows to reduce space to Theta(min(m, n)).
    Time: Theta(m * n) | Auxiliary Space: Theta(min(m, n))
    """
    # Ensure word2 is the shorter string so the row width is minimized
    if len(word1) < len(word2):
        word1, word2 = word2, word1

    m, n = len(word1), len(word2)
    prev_row = list(range(n + 1))

    for i in range(1, m + 1):
        curr_row = [i] + [0] * n
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                curr_row[j] = prev_row[j - 1]
            else:
                curr_row[j] = 1 + min(
                    prev_row[j],      # Delete word1[i - 1]
                    curr_row[j - 1],  # Insert word2[j - 1]
                    prev_row[j - 1],  # Replace word1[i - 1] with word2[j - 1]
                )
        prev_row = curr_row

    return prev_row[n]
```

### 4. 0/1 Knapsack (Space-Optimized Backward 1D Compression)
```python
def knapsack_01(weights: list[int], values: list[int], capacity: int) -> int:
    """
    Maximize total value of items chosen at most once without exceeding `capacity`.
    Iterates capacity downward (`capacity` -> `wt`) so each item is used at most once.
    Time: Theta(N * capacity) | Auxiliary Space: Theta(capacity)
    """
    if len(weights) != len(values):
        raise ValueError("weights and values must have equal length")
    if capacity <= 0 or not weights:
        return 0

    dp = [0] * (capacity + 1)

    for wt, val in zip(weights, values):
        if wt > capacity:
            continue
        for w in range(capacity, wt - 1, -1):
            candidate = dp[w - wt] + val
            if candidate > dp[w]:
                dp[w] = candidate

    return dp[capacity]
```

## 6. Common Pitfalls and Best Practices

1. **Creating a 2D Table with `[[0] * cols] * rows` (Shared Row Aliasing):**
   Multiplying a list of lists duplicates references to the **exact same inner list object**, so assigning `dp[0][2] = 5` mutates `dp[r][2]` in every row `r`. Always allocate 2D tables using a list comprehension: **`[[0] * cols for _ in range(rows)]`**.
2. **Iterating Forward Instead of Backward in Space-Optimized 0/1 Knapsack:**
   When compressing 0/1 Knapsack to a single 1D array `dp[0..W]`, scanning `w` left-to-right (`wt .. W`) reads already-updated values from the *current* item's row—allowing the same item to be picked multiple times (Unbounded Knapsack). Always iterate **`range(W, wt - 1, -1)`** for 0/1 Knapsack, and `range(wt, W + 1)` only when unlimited reuse is intended.
3. **Off-by-One Indexing Between `(m + 1) x (n + 1)` Tables and 0-Indexed Strings:**
   In two-sequence DP, row `0` and column `0` represent empty prefixes `""`. Consequently, table cell `dp[i][j]` evaluates characters **`word1[i - 1]`** and **`word2[j - 1]`** (not `word1[i]` and `word2[j]`).
4. **Using Rolling-Row Space Optimization When Path Reconstruction Is Needed:**
   Compressing $\Theta(m \cdot n)$ space down to $\Theta(n)$ overwrites historical rows, making it impossible to trace back which decisions produced the optimal score. Keep the full 2D matrix whenever you need to return the actual path, edit sequence, or chosen items.
5. **Wrong Loop Order in Interval DP (`dp[i][j]`):**
   Because `dp[i][j]` depends on shorter inner intervals `dp[i + 1][j - 1]` or `dp[i][k] + dp[k + 1][j]`, standard top-to-bottom row loops read uncomputed cells. Always iterate by **increasing interval length** (`for length in range(2, n + 1):`) or iterate `i` **downward** from `n - 1` to `0`.

## 7. Quick Reference

| Pattern / Problem | Table Dimensions | Recurrence Relation | Optimal Space |
| :--- | :--- | :--- | :--- |
| **Grid Unique Paths** | `R x C` | `dp[r][c] = dp[r - 1][c] + dp[r][c - 1]` | $\Theta(C)$ |
| **Grid Min Path Sum** | `R x C` | `dp[r][c] = grid[r][c] + min(dp[r - 1][c], dp[r][c - 1])` | $\Theta(C)$ |
| **Longest Common Subseq.** | `(m + 1) x (n + 1)` | Match: `1 + dp[i - 1][j - 1]` \| Mismatch: `max(dp[i - 1][j], dp[i][j - 1])` | $\Theta(\min(m, n))$ |
| **Edit Distance** | `(m + 1) x (n + 1)` | Match: `dp[i - 1][j - 1]` \| Mismatch: `1 + min(top, left, diag)` | $\Theta(\min(m, n))$ |
| **0/1 Knapsack** | `(N + 1) x (W + 1)` | `dp[i][w] = max(dp[i - 1][w], val + dp[i - 1][w - wt])` | $\Theta(W)$ (backward) |
| **Interval DP (`[i, j]`)** | `n x n` | `dp[i][j] = opt_k(dp[i][k] + dp[k + 1][j] + cost(i, j))` | $\Theta(n^2)$ |
