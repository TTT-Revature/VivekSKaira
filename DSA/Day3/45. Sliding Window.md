# Sliding Window

## 1. Overview
The **Sliding Window** technique is an algorithmic pattern used to process **contiguous subarrays or substrings** of an array, list, or string. Instead of recomputing an aggregate (such as a sum, frequency count, or distinct-element set) from scratch for every possible subarray in $O(n \cdot k)$ or $O(n^2)$ time, a sliding window maintains a dynamic range `[left, right]` and updates its state incrementally in **$O(1)$ amortized time** as the boundaries move forward—achieving **$\Theta(n)$ single-pass** runtimes.

### Core Incremental Update Mechanism
```text
Array:  [  2,   1,   5,   1,   3,   2  ]     Window size k = 3
           ^---------^
          left      right   (Initial window sum = 2 + 1 + 5 = 8)

Slide right by 1 slot:
        [  2,   1,   5,   1,   3,   2  ]
           -    ^---------^
         drop  left      right   (New sum = 8 - nums[0] + nums[3] = 8 - 2 + 1 = 7)
```

### When Sliding Window Applies
1. **Contiguous Range Requirement:** The problem asks about a contiguous subarray or substring (not an arbitrary subsequence).
2. **Incremental State Transition:** Adding an element on the right (`nums[right]`) and removing an element on the left (`nums[left]`) updates the window's validity or score in $O(1)$ (or $O(\log k)$) time.
3. **Monotonic Window Property (for Variable Windows):** Expanding the window (`right += 1`) moves the state monotonically in one direction (e.g., sum increases for positive numbers, distinct character count increases), while shrinking (`left += 1`) moves it in the opposite direction.

## 2. Fixed-Size vs. Variable-Size Sliding Windows

### 1. Fixed-Size Sliding Window
The window length is locked at a constant size $k$ (`right - left + 1 == k`). Once the first window of size $k$ is formed, every step adds `arr[right]` and drops `arr[left]` simultaneously.
* **Canonical Template:**
  1. Build the initial state over indices `0 .. k - 1`.
  2. Loop `right` from `k` to `n - 1`: incorporate `arr[right]`, evict `arr[right - k]`, and update the best answer.
* **Classic Problems:** Maximum/minimum sum subarray of size $k$, moving average of a data stream, finding all anagrams of a pattern of length $k$, sliding window maximum.

### 2. Variable-Size (Dynamic) Sliding Window
The window expands and contracts dynamically to optimize window length (`max` or `min`) subject to a constraint:
* **Maximize Window Length (Longest Valid Subarray):**
  * Expand `right` on every iteration.
  * Shrink `left` (`while window_is_invalid:`) until the constraint is restored.
  * Record `max_len = max(max_len, right - left + 1)` **after** the `while` loop when the window is guaranteed valid.
* **Minimize Window Length (Shortest Valid Subarray):**
  * Expand `right` on every iteration.
  * Shrink `left` (`while window_is_valid:`) to tighten the window as much as possible, updating `min_len = min(min_len, right - left + 1)` **inside** the `while` loop before dropping `arr[left]`.

### Comparison of Sliding Window Variants

| Dimension | Fixed-Size Window | Variable-Size (Longest) | Variable-Size (Shortest) | Monotonic Deque Window |
| :--- | :--- | :--- | :--- | :--- |
| **Window Size** | Constant ($k$) | Dynamic (maximizes `right - left + 1`) | Dynamic (minimizes `right - left + 1`) | Constant ($k$) |
| **Shrink Trigger** | Always once `right >= k` | `while` condition is **violated** | `while` condition is **satisfied** | Drop indices `< right - k + 1` or dominated values |
| **Answer Update Point** | After each slide of size $k$ | **Outside** shrink loop (window valid) | **Inside** shrink loop (while still valid) | Front of deque (`dq[0]`) once `right >= k - 1` |
| **Typical State** | Running sum, count, hash map | Hash map / set of window items | Running sum, matched char count | `collections.deque` storing indices |

## 3. Step-by-Step Visual Traces

### 1. Fixed-Size Window: Maximum Sum of Size $k = 3$ (`nums = [2, 1, 5, 1, 3, 2]`)
```text
Initial Window [0..2]: [ 2, 1, 5 ] -> window_sum = 8, max_sum = 8

Step 1 (right = 3, in = 1, out = nums[0] = 2):
  window [1..3]: [ 1, 5, 1 ] -> window_sum = 8 - 2 + 1 = 7 -> max_sum = 8

Step 2 (right = 4, in = 3, out = nums[1] = 1):
  window [2..4]: [ 5, 1, 3 ] -> window_sum = 7 - 1 + 3 = 9 -> max_sum = 9

Step 3 (right = 5, in = 2, out = nums[2] = 5):
  window [3..5]: [ 1, 3, 2 ] -> window_sum = 9 - 5 + 2 = 6 -> max_sum = 9

Final Result: 9 (subarray [5, 1, 3])
```

### 2. Variable-Size Window: Longest Substring Without Repeating Characters (`s = "abcba"`)
Maintain `seen` set of characters currently inside `s[left : right + 1]`:

```text
Initial: left = 0, seen = {}, max_len = 0

right = 0 ('a'): 'a' not in seen -> seen = {'a'}          -> window "a"   (len = 1) -> max_len = 1
right = 1 ('b'): 'b' not in seen -> seen = {'a','b'}      -> window "ab"  (len = 2) -> max_len = 2
right = 2 ('c'): 'c' not in seen -> seen = {'a','b','c'}  -> window "abc" (len = 3) -> max_len = 3
right = 3 ('b'): 'b' IN seen! Shrink left until 'b' is evicted:
                 - remove s[0]='a', left = 1 -> seen = {'b','c'}
                 - remove s[1]='b', left = 2 -> seen = {'c'}
                 Now add 'b'     -> seen = {'c','b'}      -> window "cb"  (len = 2) -> max_len = 3
right = 4 ('a'): 'a' not in seen -> seen = {'c','b','a'}  -> window "cba" (len = 3) -> max_len = 3

Final Result: 3
```
Notice that both `left` and `right` only move forward from `0` to `n - 1`. Even with an inner `while` loop, each index is added at most once and removed at most once—yielding at most $2n$ total pointer operations ($\Theta(n)$).

## 4. Time and Space Complexity Analysis
Assume $n$ is the length of the input sequence, $k$ is the fixed window size, and $|\Sigma|$ is the character set size:

| Problem / Variant | Brute-Force Time | Sliding Window Time | Auxiliary Space | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **Max Sum Subarray of Size $k$** | $O(n \cdot k)$ | **$\Theta(n)$** | **$O(1)$** | Single scalar `window_sum` state |
| **Longest Substring Without Repeats** | $O(n^3)$ | **$\Theta(n)$** | $O(\min(n, |\Sigma|))$ | At most $2n$ character insertions/removals |
| **Longest Substring with $\le K$ Distinct** | $O(n^2)$ | **$\Theta(n)$** | $O(K)$ | Frequency map holds at most $K + 1$ keys |
| **Min Size Subarray Sum $\ge S$** | $O(n^2)$ | **$\Theta(n)$** | **$O(1)$** | Requires strictly positive elements (`nums[i] > 0`) |
| **Minimum Window Substring** | $O(n^2)$ | **$\Theta(n + m)$** | $O(|\Sigma|)$ | Tracks satisfied character count `formed == required` |
| **Sliding Window Maximum (Size $k$)** | $O(n \cdot k)$ | **$\Theta(n)$** | **$\Theta(k)$** | Monotonic decreasing deque of indices |

## 5. Practical Python Implementations

### 1. Fixed-Size Window: Maximum Subarray Sum of Size $k$
```python
def max_sum_subarray_fixed(nums: list[int], k: int) -> int:
    """
    Return the maximum sum of any contiguous subarray of length `k`.
    Time: Theta(n) | Auxiliary Space: O(1)
    """
    if k <= 0 or k > len(nums):
        raise ValueError("k must satisfy 1 <= k <= len(nums)")

    window_sum = sum(nums[:k])
    best_sum = window_sum

    for right in range(k, len(nums)):
        window_sum += nums[right] - nums[right - k]
        if window_sum > best_sum:
            best_sum = window_sum

    return best_sum
```

### 2. Variable-Size Window (Maximize): Longest Substring Without Repeating Characters
```python
def longest_unique_substring(text: str) -> int:
    """
    Return the length of the longest contiguous substring with all unique characters.
    Uses a last-seen index map to jump `left` directly past duplicates in O(1).
    Time: Theta(n) | Auxiliary Space: O(min(n, |Sigma|))
    """
    last_seen: dict[str, int] = {}
    left = 0
    best_len = 0

    for right, ch in enumerate(text):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1
        last_seen[ch] = right
        best_len = max(best_len, right - left + 1)

    return best_len
```

### 3. Variable-Size Window (Minimize): Shortest Subarray with Sum $\ge$ Target
```python
def min_subarray_len_at_least(nums: list[int], target: int) -> int:
    """
    Return the minimal length of a contiguous subarray of positive integers
    whose sum is >= `target`, or 0 if no such subarray exists.
    Time: Theta(n) | Auxiliary Space: O(1)
    """
    left = 0
    window_sum = 0
    min_len = len(nums) + 1

    for right, value in enumerate(nums):
        window_sum += value
        while window_sum >= target:
            min_len = min(min_len, right - left + 1)
            window_sum -= nums[left]
            left += 1

    return 0 if min_len > len(nums) else min_len
```

### 4. Monotonic Deque Window: Sliding Window Maximum
Because `max()` is not invertible when an element exits on the left, maintain a **monotonic decreasing deque** of indices so `dq[0]` always holds the index of the maximum element in the current window:

```python
from collections import deque


def sliding_window_maximum(nums: list[int], k: int) -> list[int]:
    """
    Return the maximum value in every contiguous window of size `k`.
    Time: Theta(n) (each index enters and leaves deque at most once) | Auxiliary Space: Theta(k)
    """
    if k <= 0 or k > len(nums):
        raise ValueError("k must satisfy 1 <= k <= len(nums)")

    dq: deque[int] = deque()  # Stores indices in strictly decreasing order of nums[idx]
    maximums: list[int] = []

    for right, value in enumerate(nums):
        # 1. Evict indices that have fallen outside the left boundary [right - k + 1, right]
        while dq and dq[0] < right - k + 1:
            dq.popleft()

        # 2. Pop smaller elements from the back; they can never be the max while `value` is present
        while dq and nums[dq[-1]] <= value:
            dq.pop()

        dq.append(right)

        # 3. Record window maximum once the first full window of size k is formed
        if right >= k - 1:
            maximums.append(nums[dq[0]])

    return maximums


if __name__ == "__main__":
    print("Max sum (k=3):         ", max_sum_subarray_fixed([2, 1, 5, 1, 3, 2], k=3))
    print("Longest unique substr: ", longest_unique_substring("abcabcbb"))
    print("Min len sum >= 7:      ", min_subarray_len_at_least([2, 3, 1, 2, 4, 3], target=7))
    print("Sliding window max:    ", sliding_window_maximum([1, 3, -1, -3, 5, 3, 6, 7], k=3))
```

## 6. Common Pitfalls and Best Practices

1. **Using Variable-Size Sum Windows When Negative Numbers Are Present:**
   Variable-size sum shrinking relies on **monotonicity** (removing elements reduces the sum; adding elements increases the sum). When negative numbers exist, shrinking `left` can actually *increase* the sum, causing the window to miss valid subarrays. For arrays with negative numbers, use **Prefix Sums + Hash Map** (or a **Monotonic Deque** over prefix sums) instead.
2. **Writing `if` Instead of `while` When Shrinking a Variable Window:**
   Dropping a single element from `left` is often insufficient to restore validity (for example, when skipping past a duplicate character in `"abcb"`). Always use a **`while`** loop to advance `left` until the window invariant holds again.
3. **Off-by-One Errors in Window Size (`right - left + 1`):**
   Because both `left` and `right` are inclusive indices, a window spanning `[left, right]` contains **`right - left + 1`** elements. When `left == right`, the window size is `1`, not `0`.
4. **Recomputing Window Aggregates Inside the Loop (`sum(nums[left:right+1])`):**
   Slicing and summing inside a `for` loop copies $k$ elements on every iteration, silently degrading a $\Theta(n)$ algorithm to **$O(n \cdot k)$**. Always maintain incremental state variables (`window_sum += incoming - outgoing`).
5. **Forgetting to Prune Zero-Count Entries in Frequency Maps:**
   When tracking distinct characters with `len(counts)`, decrementing `counts[nums[left]] -= 1` leaves keys with value `0` in the dictionary. Always delete zero-count keys (`if counts[x] == 0: del counts[x]`) so `len(counts)` accurately reflects the number of distinct active elements.

## 7. Quick Reference

| Concept / Pattern | Key Rule or Formula |
| :--- | :--- |
| **Window Boundaries** | Inclusive range `[left, right]`; current window length = `right - left + 1` |
| **Fixed Window Slide** | `state += incoming(nums[right]) - outgoing(nums[right - k])` |
| **Variable Longest Window** | Expand `right` $\to$ `while invalid: shrink left` $\to$ `best = max(best, right - left + 1)` |
| **Variable Shortest Window** | Expand `right` $\to$ `while valid: best = min(best, right - left + 1); shrink left` |
| **Negative Numbers Rule** | Variable-size sum windows fail with negative numbers; switch to **Prefix Sum + Hash Map** |
| **Window Min / Max** | Use a **monotonic `deque` of indices** (`dq[0]` is extremum; pop expired `< right - k + 1`) |
| **Complexity** | Time: **$\Theta(n)$** (each element visited at most twice) \| Space: **$O(1)$** to **$O(k)$** |
